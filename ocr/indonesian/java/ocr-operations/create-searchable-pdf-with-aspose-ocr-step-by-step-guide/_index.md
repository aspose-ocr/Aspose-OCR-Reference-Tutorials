# Buat PDF yang dapat dicari – tutorial pemrograman lengkap

Pernah membutuhkan untuk **membuat PDF yang dapat dicari** dari gambar yang dipindai tetapi tidak yakin harus mulai dari mana? Anda tidak sendirian. Dalam banyak alur kerja yang berfokus pada dokumen, PDF yang hanya berisi gambar saja adalah jalan buntu untuk pencarian dan pengindeksan.  

Kabar baiknya, dengan Aspose OCR Anda dapat **mengonversi PDF gambar yang dipindai** menjadi dokumen yang sepenuhnya dapat dicari hanya dengan beberapa baris kode Java. Tutorial ini memandu Anda melalui setiap langkah—menginisialisasi mesin OCR, mengonfigurasi pengaturan PDF kompresi tinggi, menyematkan lapisan teks tersembunyi, dan bahkan memilih bahasa OCR yang tepat.  

Pada akhir panduan ini Anda akan memiliki program yang dapat dijalankan yang menghasilkan PDF yang dapat dicari, sebuah file yang dapat Anda masukkan ke mesin pencari atau sistem manajemen dokumen mana pun tanpa masalah.

---

## Jawaban Cepat
- **Apa arti “searchable PDF”?** Itu menggabungkan lapisan gambar visual dengan lapisan teks tak terlihat yang dihasilkan oleh OCR.  
- **Perpustakaan mana yang menangani konversi?** Aspose OCR for Java.  
- **Bagaimana saya dapat menjaga ukuran file tetap kecil?** Gunakan `setCompressionLevel(9)` untuk PDF kompresi tinggi.  
- **Bisakah saya memproses dokumen non‑English?** Ya—atur nilai enum `RecognitionLanguage` yang sesuai.  
- **Apakah saya memerlukan lisensi untuk produksi?** Lisensi komersial Aspose OCR diperlukan untuk penggunaan di luar percobaan.

---

## Apa itu searchable PDF?
Searchable PDF adalah PDF yang berisi baik gambar yang dipindai asli maupun lapisan teks tak terlihat yang dapat dibaca mesin yang dihasilkan oleh OCR. Desain berlapis ganda ini memungkinkan pengguna memilih, menyalin, dan mengindeks teks sambil tetap melihat tampilan halaman asli.

---

## Mengapa menggunakan Aspose OCR untuk Java?
Aspose OCR mendukung **lebih dari 30 bahasa** dan dapat memproses **hingga 120 halaman per menit** pada CPU standar, menjadikannya salah satu mesin OCR Java tercepat. Penulis PDF bawaan juga menawarkan **sembilan tingkat kompresi**, memungkinkan Anda memperkecil dokumen yang dipindai besar hingga **80 %** tanpa kehilangan akurasi OCR.

---

## Prasyarat
- Java 17 (atau lebih baru) terpasang dan dikonfigurasi.  
- JAR Aspose OCR untuk Java ditambahkan ke classpath proyek Anda.  
- File gambar yang dipindai (PNG, JPEG, atau TIFF) yang ingin Anda ubah menjadi searchable PDF.

## Bagaimana Aspose OCR membuat searchable PDF?
Muat gambar sumber, aktifkan mode searchable‑PDF, atur tingkat kompresi yang diinginkan, pilih bahasa OCR, dan beri tahu mesin untuk menyimpan hasilnya sebagai PDF. API menangani pekerjaan berat: menjalankan OCR, membuat lapisan teks tersembunyi, dan menulis PDF akhir dalam satu langkah.

---

## Mengonversi PDF gambar yang dipindai menggunakan Aspose OCR

**Mesin Aspose OCR** adalah komponen inti yang membaca gambar, melakukan pengenalan karakter optik, dan menghasilkan output dalam berbagai format.  

Langkah-langkah berikut menggambarkan alur konversi:

- Panggil `setCreateSearchablePdf(true)` untuk memberi instruksi pada mesin agar menyematkan lapisan teks tersembunyi.  
- Gunakan `setCompressionLevel(9)` untuk menghasilkan output **high compression PDF**, mengurangi ukuran file secara dramatis.  
- Tentukan `RecognitionLanguage.ENGLISH` (atau bahasa lain) untuk **set OCR language** demi akurasi optimal.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Mengapa ini berhasil:**  
- `setCreateSearchablePdf(true)` memberi tahu Aspose untuk menghasilkan lapisan teks tersembunyi, memenuhi persyaratan **embed text layer PDF**.  
- `setCompressionLevel(9)` memindahkan file ke rentang **high compression PDF**, memperkecil ukuran akhir tanpa mengorbankan akurasi OCR.  
- Argumen `RecognitionLanguage.ENGLISH` menunjukkan cara **set OCR language**; Anda dapat menggantinya dengan bahasa Prancis, Jerman, dll., tergantung pada materi sumber Anda.

---

## Pengaturan PDF kompresi tinggi

**CompressionLevel** mengontrol seberapa agresif penulis PDF mengurangi ukuran gambar dan aliran yang disematkan. Nilai berkisar dari 0 (tanpa kompresi) hingga 9 (kompresi maksimum).

Saat Anda mengatur level ke 9, Aspose OCR menerapkan **kompresi PNG lossless** untuk halaman dengan banyak teks dan **JPEG berkualitas tinggi** untuk konten foto, sering kali mengurangi ukuran file sebesar **70‑80 %** dibandingkan output yang tidak terkompresi.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Beberapa tips:

- **Gunakan format gambar lossless** (PNG) untuk pemindaian yang banyak teks; JPEG lebih baik untuk foto.  
- **Aktifkan font subsetting** jika Anda menyematkan font khusus—Aspose melakukan ini secara otomatis saat Anda membuat searchable PDF.  
- **Uji ukuran output** setelah setiap perubahan; terkadang kompresi level‑8 memberi Anda pengurangan ukuran 10 % dengan kehilangan kualitas yang dapat diabaikan dibandingkan level 9.

## Menyematkan lapisan teks PDF untuk kemampuan pencarian

Jika Anda melewatkan pemanggilan `setCreateSearchablePdf(true)`, file yang dihasilkan akan terlihat baik tetapi Anda tidak akan dapat mencari isinya. Lapisan teks tersembunyi dibuat dengan memetakan setiap karakter yang dikenali ke lokasinya pada halaman.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Hal yang perlu diwaspadai:**  

- **Dokumen campuran bahasa** – Anda mungkin perlu menjalankan OCR dua kali, sekali per bahasa, lalu menggabungkan lapisan teks.  
- **Tata letak kompleks** (tabel, multi‑kolom) – Aspose melakukan pekerjaan yang cukup baik, tetapi periksa kembali output dengan penampil PDF yang menampilkan teks tersembunyi (misalnya, mode “Edit PDF” Adobe Acrobat).

---

## Mengatur bahasa OCR untuk pengenalan yang akurat

**RecognitionLanguage** adalah enumerasi yang memberi tahu mesin OCR set karakter apa yang diharapkan, secara dramatis meningkatkan akurasi untuk skrip non‑Latin.

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Kapan mengubah bahasa:**  

- Dokumen berisi **skrip non‑Latin** (Cyrillic, Arab) – beralih ke `RecognitionLanguage` yang sesuai.  
- Halaman dengan bahasa campuran – Anda dapat memanggil `recognizeImageAndSave` dua kali, masing‑masing dengan bahasa yang berbeda, lalu menggabungkan PDF.

## Menjalankan contoh lengkap

Berikut adalah program lengkap yang siap dijalankan. Ganti jalur placeholder dengan lokasi file yang sebenarnya, pastikan JAR Aspose OCR berada di classpath Anda, dan jalankan.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Output yang diharapkan:** Saat Anda menjalankan program, konsol mencetak:

```
Searchable PDF created.
```

Buka `searchable.pdf` di penampil PDF apa pun, coba pilih teks, dan Anda akan melihat lapisan tak terlihat beraksi. Anda telah berhasil **membuat searchable pdf** dari gambar yang dipindai.

## Masalah umum dan solusi

- **Memory‑out‑of‑bounds pada file besar** – aktifkan mode streaming dengan memanggil `OcrEngine.setUseStream(true)`.  
- **Deteksi bahasa yang salah** – secara eksplisit atur `RecognitionLanguage` alih-alih mengandalkan deteksi otomatis.  
- **Pemindaian buram** – pra‑proses gambar dengan Aspose Imaging untuk meningkatkan kontras sebelum OCR.

## Pertanyaan yang sering diajukan

**Q: Bisakah saya memproses batch seluruh folder gambar?**  
A: Ya. Iterasi melalui file, panggil konfigurasi OCR yang sama untuk masing‑masing, dan gabungkan PDF yang dihasilkan dengan `PdfDocument.merge()`.

**Q: Apakah Aspose OCR mendukung input PDF secara langsung?**  
A: Ya. Gunakan `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` dan atur `setCreateSearchablePdf(true)`.

**Q: Bagaimana cara menangani PDF yang dilindungi kata sandi?**  
A: Berikan kata sandi ke `OcrEngine.setPassword("yourPassword")` sebelum memanggil metode OCR.

**Q: Berapa ukuran file maksimum yang dapat ditangani Aspose OCR?**  
A: Mesin dapat memproses PDF hingga **2 GB** ketika streaming diaktifkan, terbatas hanya oleh RAM yang tersedia.

**Q: Apakah lisensi komersial diperlukan untuk penggunaan produksi?**  
A: Ya. Lisensi percobaan berfungsi untuk evaluasi, tetapi lisensi penuh menghapus watermark evaluasi dan membuka semua fitur.

- Gunakan `setCreateSearchablePdf(true)` untuk **embed text layer PDF**.
