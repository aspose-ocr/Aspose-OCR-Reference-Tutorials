# Cara mengekstrak teks dari gambar menggunakan Aspose.OCR untuk .NET

## Pendahuluan

Jika Anda perlu **extract text from image** file dengan cepat dan dapat diandalkan, Aspose.OCR untuk .NET adalah pilihan yang solid. Dalam tutorial ini kami akan menjelaskan cara menyiapkan pustaka, mengonfigurasi opsi pengenalan, dan mengambil hasil OCR lengkap—termasuk output multibahasa dan data tata letak. Pada akhir tutorial Anda akan tahu cara **extract text from image** file, cara **recognize text from image** dalam berbagai bahasa, dan di mana menemukan dokumentasi resmi Aspose OCR untuk eksplorasi lebih mendalam.

## Jawaban Cepat

- **What does “extract text from image” mean?** Itu merujuk pada pengambilan karakter yang dapat dibaca yang dideteksi oleh mesin OCR di dalam sebuah gambar.  
- **Which library should I use?** Aspose.OCR untuk .NET menawarkan API yang sederhana, dukungan multibahasa, dan **aspose ocr trial** yang dapat Anda coba secara langsung.  
- **Do I need a license?** Versi percobaan gratis tersedia; lisensi diperlukan untuk penggunaan produksi.  
- **What .NET versions are supported?** .NET Framework 4.5+ dan .NET Core/5/6+.  
- **Can I improve OCR accuracy?** Ya—dengan memilih bahasa yang tepat dan menyesuaikan DPI Anda dapat **improve ocr accuracy**.

## Apa arti “extract text from image”?

Extract text from image berarti mengubah representasi visual karakter di dalam bitmap menjadi string Unicode yang dapat diedit dan dicari. Proses ini bergantung pada mesin OCR yang menganalisis pola piksel, mengidentifikasi glif, dan menyusunnya menjadi kata dan kalimat. Mesin Aspose.OCR mendukung lebih dari 50 bahasa dan dapat menghasilkan teks biasa, JSON, atau XML, memudahkan memasukkan hasil ke dalam alur kerja selanjutnya.

## Mengapa menggunakan Aspose.OCR untuk tugas ini?

Aspose.OCR mendukung **50+ languages** dan dapat memproses **multi‑hundred‑page image batches** tanpa memuat seluruh file ke memori, memberikan kinerja hingga **3 × faster** dibandingkan banyak alternatif open‑source. API hanya memerlukan beberapa baris kode, dan pra‑pemrosesan bawaan (binarisasi, penghilangan noise) membantu **improve OCR accuracy** hingga **30 %** pada pemindaian yang berisik.

## Bagaimana Aspose.OCR meningkatkan akurasi OCR?

Aspose.OCR meningkatkan akurasi OCR dengan secara otomatis menerapkan langkah pra‑pemrosesan gambar seperti binarisasi, perataan, dan pengurangan noise sebelum pengenalan. Anda juga dapat secara manual mengatur DPI (dots per inch) ke nilai antara 150 dan 300; DPI yang lebih tinggi mempertahankan detail yang lebih halus, sementara DPI yang lebih rendah mempercepat pemrosesan. Untuk dokumen dengan skrip campuran, mengaktifkan mode multibahasa memastikan mesin memilih model bahasa terbaik untuk setiap wilayah, sehingga meningkatkan presisi.

## Cara mengatur bahasa OCR di Aspose.OCR?

Anda mengatur bahasa OCR dengan menetapkan kode ISO‑639‑1 yang diinginkan ke properti `settings.Language` sebelum memanggil `engine.Recognize()`. Misalnya, gunakan `"en"` untuk bahasa Inggris, `"fr"` untuk bahasa Prancis, atau daftar dipisahkan koma seperti `"en,es"` untuk mengaktifkan deteksi simultan teks bahasa Inggris dan Spanyol. Memilih bahasa yang tepat menghilangkan pemeriksaan model bahasa yang tidak perlu, mengurangi waktu pemrosesan rata‑rata sebesar **15 %**.

## Cara mendapatkan lisensi Aspose OCR?

Beli lisensi permanen atau sementara dari toko Aspose, kemudian letakkan file lisensi (`Aspose.OCR.lic`) di folder root aplikasi Anda. Muat lisensi pada runtime dengan `License license = new License(); license.SetLicense("Aspose.OCR.lic");`. Lisensi sementara 30‑hari tersedia untuk evaluasi dan dapat diminta melalui portal Aspose tanpa informasi kartu kredit.

## Impor namespace

Dalam aplikasi .NET Anda, mulailah dengan mengimpor namespace yang diperlukan:

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.IO;
using Aspose.OCR;
```

## Langkah 1: siapkan direktori dokumen Anda

Tentukan folder yang berisi gambar yang ingin Anda proses:

```csharp
string dataDir = "Your Document Directory";
```

## Langkah 2: inisialisasi Aspose.OCR

Buat instance dari mesin OCR:

```csharp
AsposeOcr api = new AsposeOcr();
```

## Langkah 3: tentukan path gambar

Tunjuk file gambar yang tepat yang ingin Anda kenali:

```csharp
string fullPath = dataDir + "sample.png";
```

## Langkah 4: konfigurasikan pengaturan pengenalan

Sesuaikan pengaturan agar cocok dengan skenario Anda—apakah Anda memerlukan perilaku default atau opsi khusus seperti pemilihan bahasa untuk pengenalan teks multibahasa:

```csharp
RecognitionSettings settings = new RecognitionSettings
{
    // Specify your recognition settings here
    // Example: Language = Language.English | Language.Spanish
};
```

## Langkah 5: lakukan pengenalan gambar

Jalankan proses OCR dan tangkap hasilnya:

```csharp
RecognitionResult result = api.RecognizeImage(fullPath, settings);
```

## Langkah 6: cetak hasil pengenalan

Tampilkan output pengenalan lengkap, yang mencakup teks yang diekstrak, informasi tata letak, representasi JSON, dan peringatan apa pun:

```csharp
PrintRecognitionResult(result);
```

## Masalah umum dan solusi

| Issue | Reason | Fix |
|-------|--------|-----|
| **No text returned** | Path gambar salah atau format tidak didukung | Verifikasi `fullPath` dan pastikan gambar merupakan tipe yang didukung (PNG, JPEG, BMP). |
| **Incorrect language detection** | Pengaturan bahasa default mungkin tidak cocok dengan gambar | Atur `settings.Language` ke bahasa yang sesuai untuk meningkatkan akurasi. |
| **Performance slowdown on large images** | Gambar beresolusi tinggi meningkatkan waktu pemrosesan | Ubah ukuran gambar sebelum pengenalan atau sesuaikan `settings.Dpi` ke nilai yang lebih rendah. |
| **Low accuracy on scanned documents** | Gambar hasil pemindaian mungkin mengandung noise | Gunakan langkah pra‑pemrosesan seperti binarisasi atau terapkan `settings.Preprocess = true` untuk **improve ocr accuracy**. |
| **Need to handle a scanned PDF** | PDF harus dikonversi menjadi gambar terlebih dahulu | **Convert scanned image** halaman ke PNG/JPEG menggunakan pustaka PDF‑to‑image, lalu berikan setiap gambar ke Aspose.OCR. |
