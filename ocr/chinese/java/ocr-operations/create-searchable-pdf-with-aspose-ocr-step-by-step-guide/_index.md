# 创建可搜索 PDF – 完整编程教程

是否曾经需要从扫描图像创建**可搜索 PDF**文件，却不知从何入手？你并不孤单。在许多文档密集的工作流中，纯图像的 PDF 对搜索和索引来说是死路。  

好消息是，使用 Aspose OCR，您只需几行 Java 代码即可**将扫描图像 PDF 转换**为完整的可搜索文档。本教程将逐步演示每一步——初始化 OCR 引擎、配置高压缩 PDF 设置、嵌入隐藏文本层，甚至选择合适的 OCR 语言。  

阅读本指南后，您将拥有一个可运行的程序，能够生成可搜索的 PDF 文件，您可以毫无障碍地将其投入任何搜索引擎或文档管理系统。

---

## 快速答案
- **“searchable PDF” 是什么意思？** 它将可视的图像层与 OCR 生成的不可见文本层相结合。  
- **哪个库负责转换？** Aspose OCR for Java。  
- **如何保持文件大小较小？** 使用 `setCompressionLevel(9)` 以实现高压缩 PDF。  
- **我可以处理非英文文档吗？** 可以——设置相应的 `RecognitionLanguage` 枚举值。  
- **生产环境是否需要许可证？** 非试用使用需要商业 Aspose OCR 许可证。

## 什么是可搜索 PDF？
可搜索 PDF 是一种 PDF，既包含原始扫描图像，又包含由 OCR 生成的不可见、机器可读的文本层。这种双层设计使用户能够选择、复制和索引文本，同时仍然看到原始页面的外观。

## 为什么使用 Aspose OCR for Java？
Aspose OCR 支持**30 多种语言**，并且在标准 CPU 上每分钟可处理**高达 120 页**，使其成为最快的 Java OCR 引擎之一。其内置的 PDF 写入器还提供**九个压缩级别**，让您在不损失 OCR 精度的情况下将大型扫描文档压缩高达**80 %**。

## 先决条件
- 已安装并配置 Java 17（或更高版本）。  
- 已将 Aspose OCR for Java JAR 添加到项目的 classpath 中。  
- 一张您想转换为可搜索 PDF 的扫描图像文件（PNG、JPEG 或 TIFF）。  

## Aspose OCR 如何创建可搜索 PDF？
加载源图像，启用 searchable‑PDF 模式，设置所需的压缩级别，选择 OCR 语言，然后指示引擎将结果保存为 PDF。API 负责繁重的工作：它执行 OCR，创建隐藏文本层，并一次性写入最终的 PDF。

## 使用 Aspose OCR 转换扫描图像 PDF
**Aspose OCR 引擎** 是读取图像、执行光学字符识别并以多种格式生成输出的核心组件。  

以下步骤展示了转换流程：

- 调用 `setCreateSearchablePdf(true)` 以指示引擎嵌入隐藏文本层。  
- 使用 `setCompressionLevel(9)` 实现**高压缩 PDF**输出，显著减小文件大小。  
- 指定 `RecognitionLanguage.ENGLISH`（或其他语言）以**设置 OCR 语言**，获得最佳准确度。

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**为什么这样有效：**  
- `setCreateSearchablePdf(true)` 告诉 Aspose 生成隐藏文本层，满足 **embed text layer PDF** 的要求。  
- `setCompressionLevel(9)` 将文件推入 **high compression PDF** 范围，在不牺牲 OCR 精度的情况下缩小最终大小。  
- `RecognitionLanguage.ENGLISH` 参数展示了如何**设置 OCR 语言**；您可以根据源材料将其替换为法语、德语等。

## 高压缩 PDF 设置
**CompressionLevel** 控制 PDF 写入器对嵌入图像和流的压缩力度。取值范围从 0 （无压缩）到 9 （最大压缩）。  

当您将级别设为 9 时，Aspose OCR 对文本密集的页面使用**无损 PNG 压缩**，对摄影内容使用**高质量 JPEG**，通常相比未压缩的输出可将文件大小削减 **70‑80 %**。

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

几点提示：

- **使用无损图像格式**（PNG）进行文本密集的扫描；JPEG 更适合照片。  
- **启用字体子集化**，如果嵌入自定义字体——在创建可搜索 PDF 时，Aspose 会自动完成此操作。  
- **在每次更改后测试输出大小**；有时 8 级压缩即可实现约 10 % 的大小减小，且相较于 9 级几乎没有质量损失。

## 嵌入文本层 PDF 以实现可搜索性
如果跳过 `setCreateSearchablePdf(true)` 调用，生成的文件外观正常，但您将无法搜索其内容。隐藏文本层是通过将每个识别字符映射到页面上的位置而创建的。  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**需要注意的事项：**  

- **混合语言文档**——可能需要对每种语言分别运行 OCR 两次，然后合并文本层。  
- **复杂布局**（表格、多列）——Aspose 表现尚可，但请使用能够显示隐藏文本的 PDF 查看器（例如 Adobe Acrobat 的“编辑 PDF”模式）再次确认输出。

## 设置 OCR 语言以获得准确识别
**RecognitionLanguage** 是一个枚举，告诉 OCR 引擎应期待哪种字符集，显著提升对非拉丁文字的识别准确度。  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**何时更改语言：**  

- 文档包含**非拉丁文字**（西里尔文、阿拉伯文）——切换到相应的 `RecognitionLanguage`。  
- 混合语言页面——您可以两次调用 `recognizeImageAndSave`，每次使用不同的语言，然后合并 PDF。

## 运行完整示例
下面是完整的可直接运行的程序。请将占位符路径替换为实际文件位置，确保 Aspose OCR JAR 已在 classpath 中，然后执行。

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**预期输出：** 当您运行程序时，控制台会打印：

```
Searchable PDF created.
```

在任意 PDF 查看器中打开 `searchable.pdf`，尝试选择文本，您将看到隐藏层的实际效果。您已成功**从扫描图像创建可搜索 PDF**。

## 常见问题及解决方案
- **大文件内存溢出**——通过调用 `OcrEngine.setUseStream(true)` 启用流式模式。  
- **语言检测不正确**——显式设置 `RecognitionLanguage`，而不是依赖自动检测。  
- **扫描模糊**——在 OCR 之前使用 Aspose Imaging 对图像进行预处理以提高对比度。

## 常见问答
**Q: 我可以批量处理整个文件夹的图像吗？**  
A: 可以。遍历文件，对每个文件调用相同的 OCR 配置，并使用 `PdfDocument.merge()` 将生成的 PDF 合并。

**Q: Aspose OCR 是否直接支持 PDF 输入？**  
A: 支持。使用 `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` 并设置 `setCreateSearchablePdf(true)`。

**Q: 我该如何处理受密码保护的 PDF？**  
A: 在调用 OCR 方法之前，将密码传递给 `OcrEngine.setPassword("yourPassword")`。

**Q: Aspose OCR 能处理的最大文件大小是多少？**  
A: 启用流式模式时，引擎可处理高达 **2 GB** 的 PDF，受限于可用内存。

**Q: 生产环境是否需要商业许可证？**  
A: 是的。试用许可证可用于评估，但完整许可证会去除评估水印并解锁所有功能。

## 结论
我们已经涵盖了使用 Aspose OCR **创建可搜索 PDF** 所需的全部内容：

- 初始化 OCR 引擎。  
- 通过将 PNG/JPEG 输入 `recognizeImageAndSave` 来**转换扫描图像 PDF**。  
- 使用 `setCreateSearchablePdf(true)` **嵌入文本层 PDF**。  
- 应用 `setCompressionLevel(9)` 以获得**高压缩 PDF**，保持轻量。  
- 选择合适的 `RecognitionLanguage` 来**设置 OCR 语言**，以获得最高准确度。

从这里您可以尝试批量处理、不同语言，甚至将多页扫描合并为单个可搜索 PDF。同样的模式适用于西班牙语、日语等其他语言——只需更换 `RecognitionLanguage` 枚举即可。
