# सर्चेबल PDF बनाएं – पूर्ण प्रोग्रामिंग ट्यूटोरियल

क्या आपको कभी स्कैन किए गए चित्रों से **create searchable PDF** फ़ाइलें बनानी पड़ी हों लेकिन शुरू करने के बारे में अनिश्चित रहे हों? आप अकेले नहीं हैं। कई दस्तावेज‑भारी कार्यप्रवाहों में, केवल छवि‑पर्याप्त PDF खोज और अनुक्रमण के लिए एक बंद रास्ता है।  

अच्छी खबर यह है कि Aspose OCR के साथ आप **convert scanned image PDF** को कुछ ही Java लाइनों में पूरी तरह सर्चेबल दस्तावेज़ में बदल सकते हैं। यह ट्यूटोरियल आपको हर चरण से ले जाता है—OCR इंजन को इनिशियलाइज़ करना, हाई कम्प्रेशन PDF सेटिंग्स कॉन्फ़िगर करना, एक छिपी टेक्स्ट लेयर एम्बेड करना, और सही OCR भाषा चुनना।  

इस गाइड के अंत तक आपके पास एक रन करने योग्य प्रोग्राम होगा जो एक सर्चेबल PDF उत्पन्न करता है, एक फ़ाइल जिसे आप बिना किसी समस्या के किसी भी सर्च इंजन या दस्तावेज़ प्रबंधन प्रणाली में डाल सकते हैं।

## त्वरित उत्तर
- **What does “searchable PDF” mean?** यह एक दृश्य छवि लेयर को OCR द्वारा उत्पन्न एक अदृश्य टेक्स्ट लेयर के साथ मिलाता है।  
- **Which library handles the conversion?** Aspose OCR for Java.  
- **How can I keep the file size small?** हाई कम्प्रेशन PDF के लिए `setCompressionLevel(9)` का उपयोग करें।  
- **Can I process non‑English documents?** हाँ—उपयुक्त `RecognitionLanguage` enum मान सेट करें।  
- **Do I need a license for production?** गैर‑ट्रायल उपयोग के लिए एक व्यावसायिक Aspose OCR लाइसेंस आवश्यक है।

## सर्चेबल PDF क्या है?
एक सर्चेबल PDF वह PDF है जिसमें मूल स्कैन की गई छवि और OCR द्वारा उत्पन्न एक अदृश्य, मशीन‑पठनीय टेक्स्ट लेयर दोनों होते हैं। यह द्वि‑लेयर डिज़ाइन उपयोगकर्ताओं को टेक्स्ट को चयन, कॉपी और अनुक्रमित करने की अनुमति देता है जबकि वे अभी भी मूल पृष्ठ की उपस्थिति देखते हैं।

## Aspose OCR का उपयोग करके स्कैन की गई इमेज PDF को बदलें

**Aspose OCR engine** वह मुख्य घटक है जो छवियों को पढ़ता है, ऑप्टिकल कैरेक्टर रिकग्निशन करता है, और विभिन्न फ़ॉर्मेट में आउटपुट उत्पन्न करता है।  

निम्नलिखित चरण परिवर्तन प्रवाह को दर्शाते हैं:

- इंजन को छिपी टेक्स्ट लेयर एम्बेड करने के लिए `setCreateSearchablePdf(true)` कॉल करें।  
- फ़ाइल आकार को नाटकीय रूप से घटाने के लिए **high compression PDF** आउटपुट प्राप्त करने हेतु `setCompressionLevel(9)` उपयोग करें।  
- इष्टतम सटीकता के लिए **set OCR language** हेतु `RecognitionLanguage.ENGLISH` (या कोई अन्य भाषा) निर्दिष्ट करें।  

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**यह क्यों काम करता है:**  
- `setCreateSearchablePdf(true)` Aspose को छिपी टेक्स्ट लेयर उत्पन्न करने के लिए बताता है, जिससे **embed text layer PDF** आवश्यकता पूरी होती है।  
- `setCompressionLevel(9)` फ़ाइल को **high compression PDF** रेंज में ले जाता है, अंतिम आकार को घटाता है बिना OCR सटीकता का बलिदान किए।  
- `RecognitionLanguage.ENGLISH` तर्क दिखाता है कि **set OCR language** कैसे किया जाता है; आप इसे फ़्रेंच, जर्मन आदि के लिए बदल सकते हैं, आपके स्रोत सामग्री के आधार पर।

## हाई कम्प्रेशन PDF सेटिंग्स

**CompressionLevel** नियंत्रित करता है कि PDF राइटर एम्बेडेड इमेज और स्ट्रीम्स का आकार कितनी तीव्रता से घटाता है। मान 0 (कोई कम्प्रेशन नहीं) से 9 (अधिकतम कम्प्रेशन) तक होते हैं।  

जब आप लेवल को 9 सेट करते हैं, तो Aspose OCR टेक्स्ट‑भारी पृष्ठों के लिए **lossless PNG compression** और फ़ोटोग्राफ़िक कंटेंट के लिए **high‑quality JPEG** लागू करता है, जिससे अक्सर अनकम्प्रेस्ड आउटपुट की तुलना में फ़ाइल आकार **70‑80 %** तक घट जाता है।  

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

कुछ सुझाव:
- **lossless इमेज फ़ॉर्मेट** (PNG) का उपयोग टेक्स्ट‑भारी स्कैन के लिए करें; फ़ोटो के लिए JPEG बेहतर है।  
- यदि आप कस्टम फ़ॉन्ट एम्बेड करते हैं तो **फ़ॉन्ट सबसेटिंग सक्षम करें**—Aspose यह स्वचालित रूप से करता है जब आप सर्चेबल PDF बनाते हैं।  
- प्रत्येक परिवर्तन के बाद **आउटपुट आकार परीक्षण** करें; कभी‑कभी लेवल‑8 कम्प्रेशन आपको लेवल‑9 की तुलना में 10 % आकार घटाव देता है, गुणवत्ता हानि नगण्य रहती है।

## सर्चेबिलिटी के लिए टेक्स्ट लेयर PDF एम्बेड करें

यदि आप `setCreateSearchablePdf(true)` कॉल को छोड़ देते हैं, तो परिणामी फ़ाइल ठीक दिखेगी लेकिन आप उसकी सामग्री को खोज नहीं पाएंगे। छिपी टेक्स्ट लेयर प्रत्येक पहचाने गए अक्षर को पृष्ठ पर उसकी स्थिति से मैप करके बनाई जाती है।  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**ध्यान रखने योग्य बातें:**  
- **मिश्रित‑भाषा दस्तावेज़** – आपको प्रत्येक भाषा के लिए OCR दो बार चलाना पड़ सकता है, फिर टेक्स्ट लेयर को मर्ज करना होगा।  
- **जटिल लेआउट** (टेबल, मल्टी‑कॉलम) – Aspose एक ठीक काम करता है, लेकिन आउटपुट को ऐसे PDF व्यूअर से दोबारा जांचें जो छिपा टेक्स्ट दिखाता है (जैसे Adobe Acrobat का “Edit PDF” मोड)।

## सटीक पहचान के लिए OCR भाषा सेट करें

**RecognitionLanguage** एक एन्ह्यूमरेशन है जो OCR इंजन को बताता है कि कौन सा कैरेक्टर सेट अपेक्षित है, जिससे गैर‑लैटिन स्क्रिप्ट्स की सटीकता में नाटकीय सुधार होता है।  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**भाषा कब बदलें:**  
- दस्तावेज़ में **non‑Latin स्क्रिप्ट** (Cyrillic, Arabic) हों – उपयुक्त `RecognitionLanguage` पर स्विच करें।  
- मिश्रित भाषा पृष्ठ – आप `recognizeImageAndSave` को दो बार कॉल कर सकते हैं, प्रत्येक बार अलग भाषा के साथ, और फिर PDFs को मर्ज करें।

## पूर्ण उदाहरण चलाना

नीचे पूरा, तैयार‑चलाने योग्य प्रोग्राम दिया गया है। प्लेसहोल्डर पाथ को वास्तविक फ़ाइल स्थानों से बदलें, सुनिश्चित करें कि Aspose OCR JAR आपके क्लासपाथ में है, और निष्पादित करें।

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**अपेक्षित आउटपुट:** जब आप प्रोग्राम चलाते हैं, कंसोल प्रिंट करता है:

```
Searchable PDF created.
```

`searchable.pdf` को किसी भी PDF व्यूअर में खोलें, टेक्स्ट चयन करने की कोशिश करें, और आप कार्रवाई में अदृश्य लेयर देखेंगे। आपने सफलतापूर्वक स्कैन की गई छवि से **create searchable pdf** बना लिया है।

## अक्सर पूछे जाने वाले प्रश्न
**Q: क्या मैं इमेज की पूरी फ़ोल्डर को बैच‑प्रोसेस कर सकता हूँ?**  
A: हाँ। फ़ाइलों पर इटरिटेट करें, प्रत्येक के लिए समान OCR कॉन्फ़िगरेशन कॉल करें, और `PdfDocument.merge()` के साथ परिणामी PDFs को जोड़ें।  

**Q: क्या Aspose OCR सीधे PDF इनपुट का समर्थन करता है?**  
A: हां। `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` उपयोग करें और `setCreateSearchablePdf(true)` सेट करें।  

**Q: मैं पासवर्ड‑सुरक्षित PDFs को कैसे संभालूँ?**  
A: OCR मेथड को कॉल करने से पहले पासवर्ड को `OcrEngine.setPassword("yourPassword")` में पास करें।  

**Q: Aspose OCR अधिकतम किस फ़ाइल आकार को संभाल सकता है?**  
A: स्ट्रीमिंग सक्षम होने पर इंजन **2 GB** तक के PDFs प्रोसेस कर सकता है, केवल उपलब्ध RAM द्वारा सीमित।  

**Q: क्या उत्पादन उपयोग के लिए व्यावसायिक लाइसेंस आवश्यक है?**  
A: हाँ। ट्रायल लाइसेंस मूल्यांकन के लिए काम करता है, लेकिन पूर्ण लाइसेंस मूल्यांकन वॉटरमार्क हटाता है और सभी फीचर अनलॉक करता है।

## निष्कर्ष
हमने Aspose OCR का उपयोग करके **create searchable PDF** फ़ाइलें बनाने के लिए आवश्यक सभी चीज़ें कवर कर ली हैं:
- OCR इंजन को इनिशियलाइज़ करें।  
- **Convert scanned image PDF** को PNG/JPEG को `recognizeImageAndSave` में फीड करके बदलें।  
- `setCreateSearchablePdf(true)` का उपयोग करके **embed text layer PDF** करें।  
- हल्का रहने वाला **high compression PDF** प्राप्त करने के लिए `setCompressionLevel(9)` लागू करें।  
- अधिकतम सटीकता के लिए **set OCR language** हेतु सही `RecognitionLanguage` चुनें।  

अब आप बैच प्रोसेसिंग, विभिन्न भाषाओं के साथ प्रयोग कर सकते हैं, या कई स्कैन किए गए पृष्ठों को एक सिंगल सर्चेबल PDF में संयोजित कर सकते हैं। वही पैटर्न स्पेनिश या जापानी जैसी अन्य भाषाओं के लिए भी काम करता है—बस `RecognitionLanguage` एन्ह्यूम को बदलें।  

यदि आपको कोई समस्या आती है तो टिप्पणी छोड़ने में संकोच न करें, और कोडिंग का आनंद लें!
