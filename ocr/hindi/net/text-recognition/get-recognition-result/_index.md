# Aspose.OCR for .NET का उपयोग करके छवि से टेक्स्ट निकालने का तरीका

## परिचय

यदि आपको **extract text from image** फ़ाइलें तेज़ी और भरोसेमंद तरीके से चाहिए, तो Aspose.OCR for .NET एक ठोस विकल्प है। इस ट्यूटोरियल में हम लाइब्रेरी सेटअप, रिकग्निशन विकल्पों को कॉन्फ़िगर करने, और पूर्ण OCR परिणाम—जिसमें बहुभाषी आउटपुट और लेआउट डेटा शामिल है—को प्राप्त करने की प्रक्रिया देखेंगे। अंत तक आप जानेंगे कि कैसे **extract text from image** फ़ाइलें निकालें, विभिन्न भाषाओं में **recognize text from image** कैसे करें, और गहन अन्वेषण के लिए आधिकारिक Aspose OCR दस्तावेज़ कहाँ मिलेंगे।

## त्वरित उत्तर
- **What does “extract text from image” mean?** यह एक OCR इंजन द्वारा छवि के भीतर पहचाने गए पठनीय अक्षरों को प्राप्त करने को दर्शाता है।  
- **Which library should I use?** Aspose.OCR for .NET एक सरल API, बहुभाषी समर्थन, और एक **aspose ocr trial** प्रदान करता है जिसे आप तुरंत आज़मा सकते हैं।  
- **Do I need a license?** एक मुफ्त ट्रायल उपलब्ध है; उत्पादन उपयोग के लिए लाइसेंस आवश्यक है।  
- **What .NET versions are supported?** .NET Framework 4.5+ और .NET Core/5/6+ समर्थित हैं।  
- **Can I improve OCR accuracy?** हाँ—सही भाषा चुनकर और DPI समायोजित करके आप **improve ocr accuracy** कर सकते हैं।

## “extract text from image” का क्या मतलब है?

Extract text from image का अर्थ है बिटमैप के भीतर अक्षरों के दृश्य प्रतिनिधित्व को संपादन योग्य, खोज योग्य Unicode स्ट्रिंग्स में बदलना। यह प्रक्रिया एक OCR इंजन पर निर्भर करती है जो पिक्सेल पैटर्न का विश्लेषण करता है, glyphs की पहचान करता है, और उन्हें शब्दों व वाक्यों में जोड़ता है। Aspose.OCR का इंजन 50 से अधिक भाषाओं का समर्थन करता है और plain text, JSON, या XML के रूप में आउटपुट दे सकता है, जिससे परिणामों को डाउनस्ट्रीम वर्कफ़्लो में आसानी से फीड किया जा सकता है।

## इस कार्य के लिए Aspose.OCR का उपयोग क्यों करें?

Aspose.OCR **50+ languages** का समर्थन करता है और **multi‑hundred‑page image batches** को पूरी फ़ाइल को मेमोरी में लोड किए बिना प्रोसेस कर सकता है, कई ओपन‑सोर्स विकल्पों की तुलना में **3 × तेज़** प्रदर्शन प्रदान करता है। API को केवल कुछ लाइनों के कोड की आवश्यकता होती है, और बिल्ट‑इन प्री‑प्रोसेसिंग (binarization, noise removal) **improve OCR accuracy** को शोरयुक्त स्कैन पर **30 %** तक बढ़ाने में मदद करता है।

## Aspose.OCR OCR सटीकता को कैसे सुधारता है?

Aspose.OCR OCR सटीकता को स्वचालित रूप से बिनैराइज़ेशन, डेस्क्यूइंग, और शोर घटाने जैसी इमेज प्री‑प्रोसेसिंग चरणों को पहचान से पहले लागू करके सुधारता है। आप DPI (dots per inch) को 150 से 300 के बीच मैन्युअली सेट भी कर सकते हैं; उच्च DPI बारीक विवरण को संरक्षित रखता है, जबकि कम DPI प्रोसेसिंग को तेज़ करता है। मिश्रित स्क्रिप्ट वाले दस्तावेज़ों के लिए, मल्टी‑लिंगुअल मोड को सक्षम करने से इंजन प्रत्येक क्षेत्र के लिए सबसे उपयुक्त भाषा मॉडल चुनता है, जिससे सटीकता और बढ़ती है।

## Aspose.OCR में OCR भाषा कैसे सेट करें?

आप OCR भाषा को `engine.Recognize()` को कॉल करने से पहले `settings.Language` प्रॉपर्टी में इच्छित ISO‑639‑1 कोड असाइन करके सेट करते हैं। उदाहरण के लिए, अंग्रेज़ी के लिए `"en"`, फ़्रेंच के लिए `"fr"` उपयोग करें, या `"en,es"` जैसी कॉमा‑सेपरेटेड सूची से अंग्रेज़ी और स्पेनिश टेक्स्ट का एक साथ पता लगाना सक्षम करें। सही भाषा चुनने से अनावश्यक भाषा‑मॉडल जांच समाप्त हो जाती है, जिससे औसतन प्रोसेसिंग समय **15 %** तक घटता है।

## Aspose OCR लाइसेंस कैसे प्राप्त करें?

Aspose स्टोर से स्थायी या अस्थायी लाइसेंस खरीदें, फिर लाइसेंस फ़ाइल (`Aspose.OCR.lic`) को अपने एप्लिकेशन की रूट फ़ोल्डर में रखें। इसे रन‑टाइम पर `License license = new License(); license.SetLicense("Aspose.OCR.lic");` के साथ लोड करें। मूल्यांकन के लिए 30‑दिन का अस्थायी लाइसेंस उपलब्ध है और इसे Aspose पोर्टल से बिना किसी क्रेडिट‑कार्ड जानकारी के अनुरोध किया जा सकता है।

using System;

## चरण 1: अपने दस्तावेज़ डायरेक्टरी सेट करें

उस फ़ोल्डर को निर्दिष्ट करें जिसमें वह छवि है जिसे आप प्रोसेस करना चाहते हैं:

```csharp
string dataDir = "Your Document Directory";
```

## चरण 2: Aspose.OCR को इनिशियलाइज़ करें

OCR इंजन का एक इंस्टेंस बनाएं:

```csharp
AsposeOcr api = new AsposeOcr();
```

## चरण 3: इमेज पाथ निर्दिष्ट करें

उस सटीक इमेज फ़ाइल की ओर इंगित करें जिसे आप पहचानना चाहते हैं:

```csharp
string fullPath = dataDir + "sample.png";
```

## चरण 4: रिकग्निशन सेटिंग्स कॉन्फ़िगर करें

सेटिंग्स को अपनी स्थिति के अनुसार समायोजित करें—चाहे आपको डिफ़ॉल्ट व्यवहार चाहिए या मल्टी‑लिंगुअल टेक्स्ट रिकग्निशन के लिए भाषा चयन जैसी कस्टम विकल्प:

```csharp
RecognitionSettings settings = new RecognitionSettings
{
    // Specify your recognition settings here
    // Example: Language = Language.English | Language.Spanish
};
```

## चरण 5: इमेज रिकग्निशन करें

OCR प्रक्रिया चलाएँ और परिणाम को कैप्चर करें:

```csharp
RecognitionResult result = api.RecognizeImage(fullPath, settings);
```

## चरण 6: रिकग्निशन परिणाम प्रिंट करें

पूरा रिकग्निशन आउटपुट दिखाएँ, जिसमें निकाला गया टेक्स्ट, लेआउट जानकारी, JSON प्रतिनिधित्व, और कोई भी चेतावनियाँ शामिल हैं:

```csharp
PrintRecognitionResult(result);
```
