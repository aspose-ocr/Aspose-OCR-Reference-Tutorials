# Crear PDF buscable – tutorial de programación completo

¿Alguna vez necesitaste **crear PDF buscable** a partir de imágenes escaneadas pero no sabías por dónde comenzar? No estás solo. En muchos flujos de trabajo con gran cantidad de documentos, un PDF que solo contiene imágenes es un callejón sin salida para la búsqueda y la indexación.  

La buena noticia es que con Aspose OCR puedes **convertir PDF de imagen escaneada** en un documento totalmente buscable con solo unas pocas líneas de Java. Este tutorial te guía paso a paso: inicializando el motor OCR, configurando ajustes de PDF de alta compresión, incrustando una capa de texto oculta y, incluso, eligiendo el idioma OCR correcto.  

Al final de esta guía tendrás un programa ejecutable que genera un PDF buscable, un archivo que puedes colocar en cualquier motor de búsqueda o sistema de gestión documental sin problemas.

---

## Respuestas rápidas
- **¿Qué significa “PDF buscable”?** Combina una capa visual de imagen con una capa de texto invisible generada por OCR.  
- **¿Qué biblioteca maneja la conversión?** Aspose OCR for Java.  
- **¿Cómo puedo mantener el tamaño del archivo pequeño?** Usa `setCompressionLevel(9)` para PDF de alta compresión.  
- **¿Puedo procesar documentos que no están en inglés?** Sí—establece el valor apropiado del enum `RecognitionLanguage`.  
- **¿Necesito una licencia para producción?** Se requiere una licencia comercial de Aspose OCR para uso que no sea de prueba.

---

## ¿Qué es un PDF buscable?
Un PDF buscable es un PDF que contiene tanto la imagen escaneada original como una capa de texto invisible y legible por máquina, producida por OCR. Este diseño de doble capa permite a los usuarios seleccionar, copiar e indexar el texto mientras siguen viendo la apariencia original de la página.

---

## ¿Por qué usar Aspose OCR para Java?
Aspose OCR soporta **más de 30 idiomas** y puede procesar **hasta 120 páginas por minuto** en una CPU estándar, lo que lo convierte en uno de los motores OCR Java más rápidos. Su escritor de PDF integrado también ofrece **nueve niveles de compresión**, permitiéndote reducir documentos escaneados grandes hasta en **un 80 %** sin perder precisión del OCR.

---

## Requisitos previos
- Java 17 (o posterior) instalado y configurado.  
- JAR de Aspose OCR for Java añadido al classpath de tu proyecto.  
- Un archivo de imagen escaneada (PNG, JPEG o TIFF) que deseas convertir en un PDF buscable.  

---

## ¿Cómo crea Aspose OCR un PDF buscable?
Carga la imagen fuente, habilita el modo searchable‑PDF, establece el nivel de compresión deseado, elige el idioma OCR y indica al motor que guarde el resultado como PDF. La API se encarga del trabajo pesado: ejecuta OCR, crea la capa de texto oculta y escribe el PDF final en una sola pasada.

---

## Convertir PDF de imagen escaneada usando Aspose OCR

**El motor Aspose OCR** es el componente central que lee imágenes, realiza reconocimiento óptico de caracteres y produce salida en varios formatos.  

Los siguientes pasos ilustran el flujo de conversión:

- Llama a `setCreateSearchablePdf(true)` para indicar al motor que incruste la capa de texto oculta.  
- Usa `setCompressionLevel(9)` para lograr una salida **PDF de alta compresión**, reduciendo el tamaño del archivo drásticamente.  
- Especifica `RecognitionLanguage.ENGLISH` (u otro idioma) para **establecer el idioma OCR** y obtener la máxima precisión.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Por qué funciona esto:**  
- `setCreateSearchablePdf(true)` indica a Aspose que genere la capa de texto oculta, cumpliendo el requisito de **PDF con capa de texto incrustada**.  
- `setCompressionLevel(9)` lleva el archivo al rango de **PDF de alta compresión**, reduciendo el tamaño final sin sacrificar la precisión del OCR.  
- El argumento `RecognitionLanguage.ENGLISH` muestra cómo **establecer el idioma OCR**; puedes cambiarlo por francés, alemán, etc., según tu material fuente.

---

## Configuraciones de PDF de alta compresión

**CompressionLevel** controla cuán agresivamente el escritor de PDF reduce el tamaño de imágenes y flujos incrustados. Los valores van de 0 (sin compresión) a 9 (compresión máxima).  

Cuando estableces el nivel en 9, Aspose OCR aplica **compresión PNG sin pérdida** para páginas con mucho texto y **JPEG de alta calidad** para contenido fotográfico, a menudo reduciendo el tamaño del archivo entre **un 70‑80 %** comparado con la salida sin comprimir.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Un par de consejos:

- **Utiliza formatos de imagen sin pérdida** (PNG) para escaneos con mucho texto; JPEG es mejor para fotos.  
- **Habilita la subconfiguración de fuentes** si incrustas fuentes personalizadas—Aspose lo hace automáticamente al crear un PDF buscable.  
- **Prueba el tamaño de salida** después de cada cambio; a veces una compresión de nivel 8 te brinda una reducción del 10 % del tamaño con una pérdida de calidad insignificante comparada con el nivel 9.

---

## Incrustar capa de texto PDF para buscabilidad

Si omites la llamada `setCreateSearchablePdf(true)`, el archivo resultante se verá bien pero no podrás buscar su contenido. La capa de texto oculta se crea asignando cada carácter reconocido a su ubicación en la página.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Qué vigilar:**  

- **Documentos multilingües** – puede que necesites ejecutar OCR dos veces, una por idioma, y luego combinar las capas de texto.  
- **Diseños complejos** (tablas, multicolumna) – Aspose hace un trabajo decente, pero verifica el resultado con un visor de PDF que muestre texto oculto (p. ej., el modo “Editar PDF” de Adobe Acrobat).

---

## Establecer el idioma OCR para un reconocimiento preciso

**RecognitionLanguage** es una enumeración que indica al motor OCR qué conjunto de caracteres esperar, mejorando drásticamente la precisión para scripts no latinos.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Cuándo cambiar el idioma:**  

- Los documentos contienen **scripts no latinos** (Cirílico, Árabe) – cambia al `RecognitionLanguage` apropiado.  
- Páginas con varios idiomas – puedes llamar a `recognizeImageAndSave` dos veces, cada vez con un idioma diferente, y luego combinar los PDFs.

## Ejecutando el ejemplo completo

A continuación se muestra el programa completo, listo para ejecutar. Reemplaza las rutas de marcador de posición con ubicaciones reales de archivos, asegura que el JAR de Aspose OCR esté en tu classpath y ejecuta.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Salida esperada:** Cuando ejecutes el programa, la consola muestra:

```
Searchable PDF created.
```

Abre `searchable.pdf` en cualquier visor de PDF, intenta seleccionar texto y verás la capa invisible en acción. Has creado exitosamente **PDF buscable** a partir de una imagen escaneada.

## Problemas comunes y soluciones

- **Memory‑out‑of‑bounds en archivos grandes** – habilita el modo de transmisión llamando a `OcrEngine.setUseStream(true)`.  
- **Detección de idioma incorrecta** – establece explícitamente `RecognitionLanguage` en lugar de confiar en la detección automática.  
- **Escaneos borrosos** – preprocesa las imágenes con Aspose Imaging para aumentar el contraste antes del OCR.

---

## Preguntas frecuentes

**Q: ¿Puedo procesar por lotes una carpeta completa de imágenes?**  
A: Sí. Itera sobre los archivos, llama a la misma configuración OCR para cada uno y concatena los PDFs resultantes con `PdfDocument.merge()`.

**Q: ¿Aspose OCR soporta entrada PDF directamente?**  
A: Sí. Usa `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` y establece `setCreateSearchablePdf(true)`.

**Q: ¿Cómo manejo PDFs protegidos con contraseña?**  
A: Pasa la contraseña a `OcrEngine.setPassword("yourPassword")` antes de invocar el método OCR.

**Q: ¿Cuál es el tamaño máximo de archivo que Aspose OCR puede manejar?**  
A: El motor puede procesar PDFs de hasta **2 GB** cuando el modo de transmisión está habilitado, limitado solo por la RAM disponible.

**Q: ¿Se requiere una licencia comercial para uso en producción?**  
A: Sí. Una licencia de prueba funciona para evaluación, pero una licencia completa elimina las marcas de agua de evaluación y desbloquea todas las funciones.

## Conclusión

Hemos cubierto todo lo que necesitas para **crear archivos PDF buscables** usando Aspose OCR:

- Inicializa el motor OCR.  
- **Convierte PDF de imagen escaneada** proporcionando un PNG/JPEG a `recognizeImageAndSave`.  
- Usa `setCreateSearchablePdf(true)` para **incrustar capa de texto PDF**.  
- Aplica `setCompressionLevel(9)` para un **PDF de alta compresión** que sigue siendo liviano.  
- Elige el `RecognitionLanguage` correcto para **establecer el idioma OCR** y obtener la máxima precisión.

Desde aquí puedes experimentar con procesamiento por lotes, diferentes idiomas, o incluso combinar varias páginas escaneadas en un solo PDF buscable. El mismo patrón funciona para otros idiomas como español o japonés—simplemente cambia el enum `RecognitionLanguage`.
