# Maak doorzoekbare PDF – volledige programmeertutorial

Heb je ooit **doorzoekbare PDF** bestanden moeten maken van gescande afbeeldingen maar wist je niet waar te beginnen? Je bent niet de enige. In veel document‑intensieve workflows is een gewone afbeelding‑enkel PDF een dood punt voor zoeken en indexeren.  

Het goede nieuws is dat je met Aspose OCR **gescande afbeelding PDF** kunt **converteren** naar een volledig doorzoekbaar document in slechts een paar regels Java. Deze tutorial leidt je door elke stap—het initialiseren van de OCR‑engine, het configureren van PDF‑instellingen met hoge compressie, het insluiten van een verborgen tekstlaag, en zelfs het kiezen van de juiste OCR‑taal.

Aan het einde van deze gids heb je een uitvoerbaar programma dat een doorzoekbare PDF produceert, een bestand dat je zonder problemen in elke zoekmachine of documentbeheersysteem kunt plaatsen.

---

## Snelle antwoorden
- **Wat betekent “searchable PDF”?** Het combineert een visuele afbeeldingslaag met een onzichtbare tekstlaag die door OCR wordt gegenereerd.  
- **Welke bibliotheek verwerkt de conversie?** Aspose OCR for Java.  
- **Hoe kan ik de bestandsgrootte klein houden?** Gebruik `setCompressionLevel(9)` voor een PDF met hoge compressie.  
- **Kan ik niet‑Engelse documenten verwerken?** Ja—stel de juiste `RecognitionLanguage` enum‑waarde in.  
- **Heb ik een licentie nodig voor productie?** Een commerciële Aspose OCR‑licentie is vereist voor gebruik buiten de proefversie.

---

## Wat is een doorzoekbare PDF?
Een doorzoekbare PDF is een PDF die zowel de originele gescande afbeelding als een onzichtbare, machinaal leesbare tekstlaag bevat die door OCR is geproduceerd. Dit dual‑layer‑ontwerp stelt gebruikers in staat tekst te selecteren, te kopiëren en te indexeren terwijl ze nog steeds de oorspronkelijke paginavormgeving zien.

---

## Waarom Aspose OCR voor Java gebruiken?
Aspose OCR ondersteunt **meer dan 30 talen** en kan **tot 120 pagina’s per minuut** verwerken op een standaard CPU, waardoor het een van de snelste Java OCR‑engines is. De ingebouwde PDF‑writer biedt bovendien **negen compressieniveaus**, zodat je grote gescande documenten kunt verkleinen tot **80 %** zonder OCR‑nauwkeurigheid te verliezen.

---

## Vereisten
- Java 17 (of later) geïnstalleerd en geconfigureerd.  
- Aspose OCR for Java JAR toegevoegd aan de classpath van je project.  
- Een gescand afbeeldingsbestand (PNG, JPEG of TIFF) dat je wilt omzetten naar een doorzoekbare PDF.  

---

## Hoe maakt Aspose OCR een doorzoekbare PDF?
Laad de bronafbeelding, schakel de doorzoekbare‑PDF‑modus in, stel het gewenste compressieniveau in, kies de OCR‑taal, en laat de engine het resultaat als PDF opslaan. De API doet het zware werk: OCR wordt uitgevoerd, de verborgen tekstlaag wordt aangemaakt en de uiteindelijke PDF wordt in één stap geschreven.

---

## Converteer gescande afbeelding PDF met Aspose OCR

**Aspose OCR engine** is de kerncomponent die afbeeldingen leest, optische tekenherkenning uitvoert en output produceert in verschillende formaten.  

De volgende stappen illustreren de conversiestroom:

- Roep `setCreateSearchablePdf(true)` aan om de engine te instrueren de verborgen tekstlaag in te sluiten.  
- Gebruik `setCompressionLevel(9)` om **PDF met hoge compressie** te verkrijgen, waardoor de bestandsgrootte sterk wordt verkleind.  
- Specificeer `RecognitionLanguage.ENGLISH` (of een andere taal) om **OCR‑taal in te stellen** voor optimale nauwkeurigheid.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Waarom dit werkt:**  
- `setCreateSearchablePdf(true)` vertelt Aspose om de verborgen tekstlaag te genereren, waardoor aan de **embed text layer PDF**‑vereiste wordt voldaan.  
- `setCompressionLevel(9)` duwt het bestand in het **high compression PDF**‑bereik, waardoor de uiteindelijke grootte wordt verkleind zonder de OCR‑nauwkeurigheid te verliezen.  
- Het argument `RecognitionLanguage.ENGLISH` laat zien hoe je **OCR‑taal instelt**; je kunt het vervangen door Frans, Duits, enz., afhankelijk van je bronmateriaal.

---

## Instellingen voor PDF met hoge compressie

**CompressionLevel** bepaalt hoe agressief de PDF‑writer de grootte van ingesloten afbeeldingen en streams verkleint. Waarden variëren van 0 (geen compressie) tot 9 (maximale compressie).  

Wanneer je het niveau op 9 zet, past Aspose OCR **verliesvrije PNG‑compressie** toe voor tekst‑zware pagina’s en **hoogwaardige JPEG** voor fotografische inhoud, waardoor de bestandsgrootte vaak met **70‑80 %** wordt verminderd ten opzichte van de ongecomprimeerde output.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Een paar tips:

- **Gebruik verliesvrije beeldformaten** (PNG) voor tekst‑zware scans; JPEG is beter voor foto’s.  
- **Schakel lettertype‑subsetten** in als je aangepaste lettertypen insluit—Aspose doet dit automatisch wanneer je een doorzoekbare PDF maakt.  
- **Test de uitvoergrootte** na elke wijziging; soms geeft compressie niveau 8 een reductie van 10 % met verwaarloosbaar kwaliteitsverlies vergeleken met niveau 9.

---

## PDF met tekstlaag insluiten voor doorzoekbaarheid

Als je de aanroep `setCreateSearchablePdf(true)` overslaat, ziet het resulterende bestand er prima uit, maar kun je de inhoud niet doorzoeken. De verborgen tekstlaag wordt gecreëerd door elk herkend teken te koppelen aan zijn positie op de pagina.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Waar je op moet letten:**  

- **Documenten met gemengde talen** – je moet OCR mogelijk twee keer uitvoeren, één keer per taal, en vervolgens de tekstlagen samenvoegen.  
- **Complexe lay-outs** (tabellen, meerdere kolommen) – Aspose doet een redelijk werk, maar controleer de output met een PDF‑viewer die verborgen tekst toont (bijv. Adobe Acrobat’s “Edit PDF”‑modus).

---

## OCR‑taal instellen voor nauwkeurige herkenning

**RecognitionLanguage** is een enumeratie die de OCR‑engine vertelt welke tekenset verwacht wordt, waardoor de nauwkeurigheid voor niet‑Latijnse scripts sterk verbetert.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Wanneer de taal te wijzigen:**  

- Documenten bevatten **niet‑Latijnse scripts** (Cyrillisch, Arabisch) – schakel over naar de juiste `RecognitionLanguage`.  
- Pagina’s met gemengde talen – je kunt `recognizeImageAndSave` twee keer aanroepen, elke keer met een andere taal, en vervolgens de PDF’s samenvoegen.

## Het volledige voorbeeld uitvoeren

Hieronder staat het volledige, kant‑klaar programma. Vervang de placeholder‑paden door echte bestandslocaties, zorg dat de Aspose OCR JAR op je classpath staat, en voer uit.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Verwachte output:** Wanneer je het programma uitvoert, print de console:

```
Searchable PDF created.
```

Open `searchable.pdf` in een PDF‑viewer, probeer tekst te selecteren, en je zult de onzichtbare laag in actie zien. Je hebt met succes **doorzoekbare pdf gemaakt** van een gescande afbeelding.

## Veelvoorkomende problemen en oplossingen

- **Memory‑out‑of‑bounds bij grote bestanden** – schakel streaming‑modus in door `OcrEngine.setUseStream(true)` aan te roepen.  
- **Onjuiste taaldetectie** – stel expliciet `RecognitionLanguage` in in plaats van te vertrouwen op automatische detectie.  
- **Vage scans** – pre‑process afbeeldingen met Aspose Imaging om het contrast te verhogen vóór OCR.

## Veelgestelde vragen

**Q: Kan ik een hele map met afbeeldingen batch‑verwerken?**  
A: Ja. Loop door de bestanden, roep dezelfde OCR‑configuratie voor elk aan, en concateneer de resulterende PDF’s met `PdfDocument.merge()`.

**Q: Ondersteunt Aspose OCR directe PDF‑invoer?**  
A: Ja. Gebruik `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` en stel `setCreateSearchablePdf(true)` in.

**Q: Hoe ga ik om met wachtwoord‑beveiligde PDF’s?**  
A: Geef het wachtwoord door aan `OcrEngine.setPassword("yourPassword")` voordat je de OCR‑methode aanroept.

**Q: Wat is de maximale bestandsgrootte die Aspose OCR aankan?**  
A: De engine kan PDF’s tot **2 GB** verwerken wanneer streaming is ingeschakeld, beperkt alleen door beschikbaar RAM.

**Q: Is een commerciële licentie vereist voor productiegebruik?**  
A: Ja. Een proeflicentie werkt voor evaluatie, maar een volledige licentie verwijdert proef‑watermerken en ontgrendelt alle functies.

## Conclusie

We hebben alles behandeld wat je nodig hebt om **doorzoekbare PDF** bestanden te **maken** met Aspose OCR:

- Initialiseert de OCR‑engine.  
- **Converteer gescande afbeelding PDF** door een PNG/JPEG aan `recognizeImageAndSave` te voeren.  
- Gebruik `setCreateSearchablePdf(true)` om **PDF met tekstlaag in te sluiten**.  
- Pas `setCompressionLevel(9)` toe voor een **PDF met hoge compressie** die lichtgewicht blijft.  
- Kies de juiste `RecognitionLanguage` om **OCR‑taal in te stellen** voor maximale nauwkeurigheid.

Vanaf hier kun je experimenteren met batch‑verwerking, verschillende talen, of zelfs meerdere gescande pagina’s combineren tot één doorzoekbare PDF. Hetzelfde patroon werkt voor andere talen zoals Spaans of Japans—vervang simpelweg de `RecognitionLanguage`‑enum.
