# كيفية استخراج النص من الصورة باستخدام Aspose.OCR لـ .NET

## مقدمة

إذا كنت بحاجة إلى **استخراج النص من الصورة** من الملفات بسرعة وموثوقية، فإن Aspose.OCR لـ .NET خيار قوي. في هذا البرنامج التعليمي سنستعرض إعداد المكتبة، وتكوين خيارات التعرف، واسترجاع نتيجة OCR الكاملة—بما في ذلك المخرجات متعددة اللغات وبيانات التخطيط. في النهاية ستعرف كيفية **استخراج النص من الصورة** من الملفات، وكيفية **التعرف على النص من الصورة** بلغات مختلفة، وأين يمكنك العثور على الوثائق الرسمية لـ Aspose OCR للمزيد من الاستكشاف.

## إجابات سريعة
- **ما معنى “استخراج النص من الصورة”؟** يشير إلى استرجاع الأحرف القابلة للقراءة التي يكتشفها محرك OCR داخل الصورة.  
- **أي مكتبة يجب أن أستخدمها؟** تقدم Aspose.OCR لـ .NET واجهة برمجة تطبيقات بسيطة، ودعمًا متعدد اللغات، و**إصدار تجريبي من aspose ocr** يمكنك تجربته فورًا.  
- **هل أحتاج إلى ترخيص؟** يتوفر إصدار تجريبي مجاني؛ الترخيص مطلوب للاستخدام في الإنتاج.  
- **ما إصدارات .NET المدعومة؟** .NET Framework 4.5+ و .NET Core/5/6+.  
- **هل يمكنني تحسين دقة OCR؟** نعم—باختيار اللغة الصحيحة وضبط DPI يمكنك **تحسين دقة OCR**.

## ما معنى “استخراج النص من الصورة”؟

يعني استخراج النص من الصورة تحويل التمثيل البصري للأحرف داخل صورة نقطية إلى سلاسل Unicode قابلة للتحرير والبحث. تعتمد العملية على محرك OCR يحلل أنماط البكسل، يحدد الرموز، ويجمعها لتكوين كلمات وجمل. يدعم محرك Aspose.OCR أكثر من 50 لغة ويمكنه إخراج نص عادي أو JSON أو XML، مما يسهل دمج النتائج في سير عمل لاحق.

## لماذا نستخدم Aspose.OCR لهذه المهمة؟

يدعم Aspose.OCR **أكثر من 50 لغة** ويمكنه معالجة **مجموعات صور مئات الصفحات** دون تحميل الملف بالكامل إلى الذاكرة، مما يحقق أداءً أسرع **بما يصل إلى 3 ×** مقارنة بالعديد من البدائل المفتوحة المصدر. تتطلب الواجهة البرمجية بضع أسطر من الشيفرة فقط، وتساعد المعالجة المسبقة المدمجة (التثليث، إزالة الضوضاء) على **تحسين دقة OCR** بنسبة تصل إلى **30 %** على المسحات الضوضائية.

## كيف يحسن Aspose.OCR دقة OCR؟

يحسن Aspose.OCR دقة OCR بتطبيق خطوات معالجة مسبقة تلقائيًا مثل التثليث، تصحيح الميل، وتقليل الضوضاء قبل التعرف. يمكنك أيضًا ضبط DPI يدويًا إلى قيمة بين 150 و300؛ DPI أعلى يحافظ على تفاصيل أدق، بينما DPI أقل يسرع المعالجة. بالنسبة للمستندات ذات النصوص المختلطة، يضمن تمكين الوضع متعدد اللغات اختيار النموذج اللغوي الأنسب لكل منطقة، مما يزيد الدقة.

## كيفية تعيين لغة OCR في Aspose.OCR؟

تعيّن لغة OCR عن طريق إسناد رمز ISO‑639‑1 المطلوب إلى الخاصية `settings.Language` قبل استدعاء `engine.Recognize()`. على سبيل المثال، استخدم `"en"` للإنجليزية، `"fr"` للفرنسية، أو قائمة مفصولة بفواصل مثل `"en,es"` لتمكين الكشف المتزامن عن النص الإنجليزي والإسباني. اختيار اللغة الصحيحة يلغي فحوصات النماذج اللغوية غير الضرورية، مما يقلل وقت المعالجة **بنسبة 15 %** في المتوسط.

## كيفية الحصول على ترخيص Aspose OCR؟

اشترِ ترخيصًا دائمًا أو مؤقتًا من متجر Aspose، ثم ضع ملف الترخيص (`Aspose.OCR.lic`) في مجلد جذر تطبيقك. حمّله في وقت التشغيل باستخدام `License license = new License(); license.SetLicense("Aspose.OCR.lic");`. يتوفر ترخيص مؤقت لمدة 30 يومًا للتقييم ويمكن طلبه من بوابة Aspose دون الحاجة إلى معلومات بطاقة ائتمان.

- **Aspose.OCR لـ .NET** – قم بتنزيل المكتبة من صفحة الإصدار الرسمية [Aspose.OCR .NET release page](https://releases.aspose.com/ocr/net/).  

## استيراد مساحات الأسماء

في تطبيق .NET الخاص بك، ابدأ باستيراد مساحات الأسماء المطلوبة:

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.IO;
using Aspose.OCR;
```

## الخطوة 1: إعداد دليل المستندات الخاص بك

حدد المجلد الذي يحتوي على الصورة التي تريد معالجتها:

```csharp
string dataDir = "Your Document Directory";
```

## الخطوة 2: تهيئة Aspose.OCR

إنشاء نسخة من محرك OCR:

```csharp
AsposeOcr api = new AsposeOcr();
```

## الخطوة 3: تحديد مسار الصورة

أشر إلى ملف الصورة المحدد الذي ترغب في التعرف عليه:

```csharp
string fullPath = dataDir + "sample.png";
```

## الخطوة 4: تكوين إعدادات التعرف

ضبط الإعدادات لتتناسب مع سيناريوك—سواء كنت تحتاج إلى السلوك الافتراضي أو خيارات مخصصة مثل اختيار اللغة للتعرف على النص متعدد اللغات:

```csharp
RecognitionSettings settings = new RecognitionSettings
{
    // Specify your recognition settings here
    // Example: Language = Language.English | Language.Spanish
};
```

## الخطوة 5: تنفيذ التعرف على الصورة

تشغيل عملية OCR والتقاط النتيجة:

```csharp
RecognitionResult result = api.RecognizeImage(fullPath, settings);
```

## الخطوة 6: طباعة نتيجة التعرف

عرض مخرجات التعرف الكاملة، التي تشمل النص المستخرج، معلومات التخطيط، تمثيل JSON، وأي تحذيرات:

```csharp
PrintRecognitionResult(result);
```

## المشكلات الشائعة والحلول

| المشكلة | السبب | الحل |
|-------|--------|-----|
| **لا نص مسترجع** | مسار الصورة غير صحيح أو تنسيق غير مدعوم | تحقق من `fullPath` وتأكد من أن الصورة من نوع مدعوم (PNG, JPEG, BMP). |
| **كشف لغة غير صحيح** | قد لا تتطابق إعدادات اللغة الافتراضية مع الصورة | اضبط `settings.Language` إلى اللغة(اللغات) المناسبة للحصول على دقة أفضل. |
| **تباطؤ الأداء على الصور الكبيرة** | الصور عالية الدقة تزيد من وقت المعالجة | قم بتغيير حجم الصورة قبل التعرف أو اضبط `settings.Dpi` إلى قيمة أقل. |
| **دقة منخفضة على المستندات الممسوحة** | قد تحتوي الصور الممسوحة على ضوضاء | استخدم خطوات ما قبل المعالجة مثل التثليث أو فعل `settings.Preprocess = true` لت **تحسين دقة OCR**. |
| **الحاجة إلى معالجة PDF ممسوح** | يجب تحويل PDF إلى صور أولاً | **حوّل صفحات PDF الممسوحة** إلى PNG/JPEG باستخدام مكتبة تحويل PDF إلى صورة، ثم مرر كل صورة إلى Aspose.OCR. |
