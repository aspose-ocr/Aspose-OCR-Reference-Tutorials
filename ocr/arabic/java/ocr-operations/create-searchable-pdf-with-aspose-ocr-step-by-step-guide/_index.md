# إنشاء PDF قابل للبحث – دليل برمجة كامل

هل احتجت يومًا إلى **create searchable PDF** من صور ممسوحة ضوئيًا لكنك لم تكن متأكدًا من أين تبدأ؟ لست وحدك. في العديد من سير العمل التي تعتمد على المستندات، يكون PDF الذي يحتوي فقط على صورة مجردة هو طريق مسدود للبحث والفهرسة.  

الخبر السار هو أنه مع Aspose OCR يمكنك **convert scanned image PDF** إلى مستند قابل للبحث بالكامل في بضع أسطر فقط من Java. يشرح هذا الدليل كل خطوة — تهيئة محرك OCR، تكوين إعدادات PDF ذات الضغط العالي، تضمين طبقة نص مخفية، وحتى اختيار لغة OCR المناسبة.  

في نهاية هذا الدليل ستحصل على برنامج قابل للتنفيذ ينتج PDF قابل للبحث، ملف يمكنك إدراجه في أي محرك بحث أو نظام إدارة مستندات دون أي مشاكل.

---

## إجابات سريعة
- **What does “searchable PDF” mean?** يجمع بين طبقة صورة بصرية وطبقة نص غير مرئية تم إنشاؤها بواسطة OCR.  
- **Which library handles the conversion?** Aspose OCR for Java.  
- **How can I keep the file size small?** استخدم `setCompressionLevel(9)` للحصول على PDF بضغط عالي.  
- **Can I process non‑English documents?** نعم — اضبط القيمة المناسبة لـ `RecognitionLanguage`.  
- **Do I need a license for production?** يلزم الحصول على ترخيص تجاري لـ Aspose OCR للاستخدام غير التجريبي.

## ما هو PDF القابل للبحث؟
PDF القابل للبحث هو PDF يحتوي على كل من الصورة الممسوحة الأصلية وطبقة نص غير مرئية قابلة للقراءة آليًا تم إنشاؤها بواسطة OCR. يتيح هذا التصميم ذو الطبقتين للمستخدمين تحديد النص، نسخه، وفهرسته مع الاستمرار في رؤية مظهر الصفحة الأصلي.

## لماذا تستخدم Aspose OCR for Java؟
Aspose OCR يدعم **over 30 languages** ويمكنه معالجة **up to 120 pages per minute** على معالج عادي، مما يجعله أحد أسرع محركات OCR للـ Java. كما أن كاتب PDF المدمج يقدم **nine levels of compression**، مما يتيح لك تقليل حجم المستندات الممسوحة الكبيرة بنسبة تصل إلى **80 %** دون فقدان دقة OCR.

## كيف يقوم Aspose OCR بإنشاء PDF قابل للبحث؟
حمّل صورة المصدر، فعّل وضع searchable‑PDF، اضبط مستوى الضغط المطلوب، اختر لغة OCR، وأخبر المحرك بحفظ النتيجة كملف PDF. يتولى الـ API كل العمل الشاق: ينفّذ OCR، ينشئ طبقة النص المخفية، ويكتب PDF النهائي في خطوة واحدة.

## تحويل PDF صورة ممسوحة باستخدام Aspose OCR
**Aspose OCR engine** هو المكوّن الأساسي الذي يقرأ الصور، ينفّذ التعرف الضوئي على الأحرف، وينتج مخرجات بصيغ مختلفة.  

الخطوات التالية توضح تدفق التحويل:

- استدعِ `setCreateSearchablePdf(true)` لتوجيه المحرك لتضمين طبقة النص المخفية.  
- استخدم `setCompressionLevel(9)` للحصول على مخرجات **high compression PDF**، مما يقلل حجم الملف بشكل كبير.  
- حدد `RecognitionLanguage.ENGLISH` (أو لغة أخرى) لـ **set OCR language** لتحقيق أقصى دقة.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**لماذا يعمل هذا:**  
- `setCreateSearchablePdf(true)` يخبر Aspose بإنشاء طبقة النص المخفية، مما يفي بمتطلب **embed text layer PDF**.  
- `setCompressionLevel(9)` يدفع الملف إلى نطاق **high compression PDF**، مما يقلص الحجم النهائي دون التضحية بدقة OCR.  
- معامل `RecognitionLanguage.ENGLISH` يوضح كيفية **set OCR language**؛ يمكنك استبداله بالفرنسية أو الألمانية، إلخ، حسب المادة المصدر.

---

## إعدادات PDF ذات الضغط العالي

**CompressionLevel** يتحكم في مدى ضغط كاتب PDF لحجم الصور المتضمنة والبيانات. القيم تتراوح من 0 (بدون ضغط) إلى 9 (أقصى ضغط).  

عند ضبط المستوى إلى 9، يطبق Aspose OCR **lossless PNG compression** للصفحات ذات النص الكثيف و**high‑quality JPEG** للمحتوى الفوتوغرافي، مما يقلل حجم الملف غالبًا بنسبة **70‑80 %** مقارنةً بالمخرجات غير المضغوطة.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

بعض النصائح:
- **Use lossless image formats** (PNG) للمسحات النصية الكثيفة؛ JPEG أفضل للصور.  
- **Enable font subsetting** إذا قمت بتضمين خطوط مخصصة—Aspose يقوم بذلك تلقائيًا عند إنشاء PDF قابل للبحث.  
- **Test the output size** بعد كل تعديل؛ أحيانًا ضغط المستوى 8 يمنحك تقليل حجم بنسبة 10 % مع فقدان جودة ضئيل مقارنةً بالمستوى 9.

## تضمين طبقة النص في PDF للبحث

إذا تخطيت استدعاء `setCreateSearchablePdf(true)`، سيظهر الملف الناتج جيدًا لكنك لن تتمكن من البحث في محتوياته. تُنشأ طبقة النص المخفية عن طريق ربط كل حرف مُعترف به بموقعه على الصفحة.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**ما يجب الانتباه إليه:**  
- **Mixed‑language documents** – قد تحتاج إلى تشغيل OCR مرتين، مرة لكل لغة، ثم دمج طبقات النص.  
- **Complex layouts** (tables, multi‑column) – Aspose يقوم بعمل جيد، لكن تحقق من المخرجات باستخدام عارض PDF يُظهر النص المخفي (مثل وضع “Edit PDF” في Adobe Acrobat).

## تعيين لغة OCR للتعرف الدقيق

**RecognitionLanguage** هو تعداد يُخبر محرك OCR بمجموعة الأحرف المتوقعة، مما يحسن الدقة بشكل كبير للخطوط غير اللاتينية.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**متى تغير اللغة:**  
- المستندات تحتوي على **non‑Latin scripts** (Cyrillic، Arabic) – غيّر إلى `RecognitionLanguage` المناسب.  
- صفحات متعددة اللغات – يمكنك استدعاء `recognizeImageAndSave` مرتين، كل مرة بلغة مختلفة، ثم دمج ملفات PDF.

## تشغيل المثال الكامل

فيما يلي البرنامج الكامل الجاهز للتنفيذ. استبدل مسارات العنصر النائب بمواقع الملفات الفعلية، وتأكد من وجود Aspose OCR JAR في classpath الخاص بك، ثم نفّذ.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Expected output:** عند تشغيل البرنامج، يطبع الطرفية:

```
Searchable PDF created.
```

افتح `searchable.pdf` في أي عارض PDF، حاول تحديد النص، وسترى الطبقة المخفية تعمل. لقد نجحت في **create searchable pdf** من صورة ممسوحة.

## المشكلات الشائعة والحلول

- **Memory‑out‑of‑bounds on large files** – فعّل وضع البث عن طريق استدعاء `OcrEngine.setUseStream(true)`.  
- **Incorrect language detection** – اضبط `RecognitionLanguage` صراحةً بدلاً من الاعتماد على الاكتشاف التلقائي.  
- **Blurry scans** – عالج الصور مسبقًا باستخدام Aspose Imaging لزيادة التباين قبل OCR.
