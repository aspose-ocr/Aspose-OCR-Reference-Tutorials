# Crea PDF ricercabile – tutorial di programmazione completo

Hai mai avuto bisogno di **creare PDF ricercabili** da immagini scansionate ma non sapevi da dove cominciare? Non sei solo. In molti flussi di lavoro con molti documenti, un PDF costituito solo da immagini è un vicolo cieco per la ricerca e l'indicizzazione.  

La buona notizia è che con Aspose OCR puoi **convertire PDF di immagini scansionate** in un documento completamente ricercabile con poche righe di Java. Questo tutorial ti guida passo passo—inizializzando il motore OCR, configurando le impostazioni PDF ad alta compressione, incorporando un livello di testo nascosto e persino scegliendo la lingua OCR corretta.

Alla fine di questa guida avrai un programma eseguibile che produce un PDF ricercabile, un file che potrai inserire in qualsiasi motore di ricerca o sistema di gestione documentale senza problemi.

---

## Risposte rapide
- **Cosa significa “PDF ricercabile”?** Combina un livello di immagine visiva con un livello di testo invisibile generato dall'OCR.  
- **Quale libreria gestisce la conversione?** Aspose OCR per Java.  
- **Come posso mantenere le dimensioni del file ridotte?** Usa `setCompressionLevel(9)` per un PDF ad alta compressione.  
- **Posso elaborare documenti non‑inglesi?** Sì—imposta il valore enum `RecognitionLanguage` appropriato.  
- **È necessaria una licenza per la produzione?** È richiesta una licenza commerciale di Aspose OCR per l'uso non‑trial.

---

## Cos'è un PDF ricercabile?
Un PDF ricercabile è un PDF che contiene sia l'immagine scansionata originale sia un livello di testo invisibile, leggibile da macchine, prodotto dall'OCR. Questo design a doppio livello consente agli utenti di selezionare, copiare e indicizzare il testo mantenendo l'aspetto originale della pagina.

---

## Perché usare Aspose OCR per Java?
Aspose OCR supporta **oltre 30 lingue** e può elaborare **fino a 120 pagine al minuto** su una CPU standard, rendendolo uno dei motori OCR Java più veloci. Il suo writer PDF integrato offre anche **nove livelli di compressione**, permettendoti di ridurre i grandi documenti scansionati fino all'**80 %** senza perdere precisione OCR.

---

## Prerequisiti
- Java 17 (o successivo) installato e configurato.  
- JAR di Aspose OCR per Java aggiunto al classpath del tuo progetto.  
- Un file immagine scansionato (PNG, JPEG o TIFF) che desideri trasformare in un PDF ricercabile.  

---

## Come crea Aspose OCR un PDF ricercabile?
Carica l'immagine di origine, abilita la modalità PDF‑ricercabile, imposta il livello di compressione desiderato, scegli la lingua OCR e indica al motore di salvare il risultato come PDF. L'API gestisce il lavoro pesante: esegue l'OCR, crea il livello di testo nascosto e scrive il PDF finale in un unico passaggio.

---

## Converti PDF di immagini scansionate usando Aspose OCR

**Il motore Aspose OCR** è il componente principale che legge le immagini, esegue il riconoscimento ottico dei caratteri e produce output in vari formati.  

I passaggi seguenti illustrano il flusso di conversione:

- Chiama `setCreateSearchablePdf(true)` per istruire il motore a incorporare il livello di testo nascosto.  
- Usa `setCompressionLevel(9)` per ottenere un output **PDF ad alta compressione**, riducendo drasticamente le dimensioni del file.  
- Specifica `RecognitionLanguage.ENGLISH` (o un'altra lingua) per **impostare la lingua OCR** per la massima precisione.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Perché funziona:**  
- `setCreateSearchablePdf(true)` indica ad Aspose di generare il livello di testo nascosto, soddisfacendo il requisito **PDF con livello di testo incorporato**.  
- `setCompressionLevel(9)` spinge il file nella gamma **PDF ad alta compressione**, riducendo le dimensioni finali senza sacrificare la precisione OCR.  
- L'argomento `RecognitionLanguage.ENGLISH` mostra come **impostare la lingua OCR**; puoi sostituirlo con francese, tedesco, ecc., a seconda del materiale di origine.

---

## Impostazioni PDF ad alta compressione

**CompressionLevel** controlla quanto aggressivamente il writer PDF riduce le dimensioni delle immagini e dei flussi incorporati. I valori vanno da 0 (nessuna compressione) a 9 (compressione massima).  

Quando imposti il livello a 9, Aspose OCR applica **compressione PNG senza perdita** per pagine ricche di testo e **JPEG ad alta qualità** per contenuti fotografici, spesso riducendo le dimensioni del file del **70‑80 %** rispetto all'output non compresso.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

A couple of tips:
- **Usa formati immagine senza perdita** (PNG) per scansioni ricche di testo; JPEG è migliore per le foto.  
- **Abilita il subset dei font** se incorpori font personalizzati—Aspose lo fa automaticamente quando crei un PDF ricercabile.  
- **Testa le dimensioni dell'output** dopo ogni modifica; a volte una compressione al livello 8 ti offre una riduzione del 10 % con perdita di qualità trascurabile rispetto al livello 9.

---

## Incorpora livello di testo PDF per la ricercabilità

Se salti la chiamata `setCreateSearchablePdf(true)`, il file risultante sembrerà a posto ma non potrai cercare il suo contenuto. Il livello di testo nascosto è creato mappando ogni carattere riconosciuto alla sua posizione sulla pagina.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Cosa tenere d'occhio:**  
- **Documenti multilingue** – potresti dover eseguire l'OCR due volte, una per lingua, e poi unire i livelli di testo.  
- **Layout complessi** (tabelle, più colonne) – Aspose fa un buon lavoro, ma verifica l'output con un visualizzatore PDF che mostra il testo nascosto (ad esempio la modalità “Modifica PDF” di Adobe Acrobat).

---

## Imposta la lingua OCR per un riconoscimento accurato

**RecognitionLanguage** è un'enumerazione che indica al motore OCR quale set di caratteri aspettarsi, migliorando notevolmente la precisione per script non latini.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Quando cambiare lingua:**  
- I documenti contengono **script non latini** (cirillico, arabo) – passa al `RecognitionLanguage` appropriato.  
- Pagine multilingue – puoi chiamare `recognizeImageAndSave` due volte, ogni volta con una lingua diversa, e poi unire i PDF.

## Esecuzione dell'esempio completo

Di seguito trovi il programma completo, pronto per l'esecuzione. Sostituisci i percorsi segnaposto con percorsi reali dei file, assicurati che il JAR di Aspose OCR sia nel tuo classpath ed esegui.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Output previsto:** Quando esegui il programma, la console stampa:

```
Searchable PDF created.
```

Apri `searchable.pdf` in qualsiasi visualizzatore PDF, prova a selezionare il testo e vedrai il livello invisibile in azione. Hai creato con successo **PDF ricercabile** da un'immagine scansionata.

## Problemi comuni e soluzioni

- **Memory‑out‑of‑bounds su file grandi** – abilita la modalità streaming chiamando `OcrEngine.setUseStream(true)`.  
- **Rilevamento lingua errato** – imposta esplicitamente `RecognitionLanguage` invece di affidarti all'auto‑rilevamento.  
- **Scansioni sfocate** – preelabora le immagini con Aspose Imaging per aumentare il contrasto prima dell'OCR.

---

## Domande frequenti

**Q: Posso elaborare in batch un'intera cartella di immagini?**  
A: Sì. Itera sui file, chiama la stessa configurazione OCR per ciascuno e concatena i PDF risultanti con `PdfDocument.merge()`.

**Q: Aspose OCR supporta direttamente l'input PDF?**  
A: Sì. Usa `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` e imposta `setCreateSearchablePdf(true)`.

**Q: Come gestisco i PDF protetti da password?**  
A: Passa la password a `OcrEngine.setPassword("yourPassword")` prima di invocare il metodo OCR.

**Q: Qual è la dimensione massima del file che Aspose OCR può gestire?**  
A: Il motore può elaborare PDF fino a **2 GB** quando lo streaming è abilitato, limitato solo dalla RAM disponibile.

**Q: È necessaria una licenza commerciale per l'uso in produzione?**  
A: Sì. Una licenza trial funziona per la valutazione, ma una licenza completa rimuove le filigrane di valutazione e sblocca tutte le funzionalità.

## Conclusione

Abbiamo coperto tutto ciò di cui hai bisogno per **creare PDF ricercabili** usando Aspose OCR:

- Inizializza il motore OCR.  
- **Converti PDF di immagini scansionate** fornendo un PNG/JPEG a `recognizeImageAndSave`.  
- Usa `setCreateSearchablePdf(true)` per **incorporare il livello di testo PDF**.  
- Applica `setCompressionLevel(9)` per un **PDF ad alta compressione** che rimane leggero.  
- Scegli il `RecognitionLanguage` corretto per **impostare la lingua OCR** per la massima precisione.

Da qui puoi sperimentare con l'elaborazione batch, lingue diverse, o anche combinare più pagine scansionate in un unico PDF ricercabile. Lo stesso schema funziona per altre lingue come lo spagnolo o il giapponese—basta sostituire l'enum `RecognitionLanguage`.
