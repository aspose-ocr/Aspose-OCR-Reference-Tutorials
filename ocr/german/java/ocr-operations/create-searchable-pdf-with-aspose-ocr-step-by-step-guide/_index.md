# Erstelle durchsuchbare PDF – vollständiges Programmier‑Tutorial

Haben Sie jemals **durchsuchbare PDF**‑Dateien aus gescannten Bildern erstellen müssen, wussten aber nicht, wo Sie anfangen sollen? Sie sind nicht allein. In vielen dokumentenintensiven Workflows ist ein reines Bild‑PDF ein Sackgasse für Suche und Indexierung.  

Die gute Nachricht ist, dass Sie mit Aspose OCR **gescannte Bild‑PDFs** in ein vollständig durchsuchbares Dokument mit nur wenigen Zeilen Java konvertieren können. Dieses Tutorial führt Sie durch jeden Schritt – Initialisierung der OCR‑Engine, Konfiguration von High‑Compression‑PDF‑Einstellungen, Einbetten einer versteckten Textebene und sogar die Auswahl der richtigen OCR‑Sprache.

Am Ende dieses Leitfadens haben Sie ein ausführbares Programm, das ein durchsuchbares PDF erzeugt, eine Datei, die Sie problemlos in jede Suchmaschine oder jedes Dokumenten‑Management‑System einbinden können.

---

## Schnelle Antworten
- **Was bedeutet „searchable PDF“?** Es kombiniert eine visuelle Bildebene mit einer unsichtbaren Textebene, die durch OCR erzeugt wird.  
- **Welche Bibliothek übernimmt die Konvertierung?** Aspose OCR for Java.  
- **Wie kann ich die Dateigröße klein halten?** Verwenden Sie `setCompressionLevel(9)` für ein hochkomprimiertes PDF.  
- **Kann ich nicht‑englische Dokumente verarbeiten?** Ja – setzen Sie den entsprechenden `RecognitionLanguage`‑Enum‑Wert.  
- **Benötige ich eine Lizenz für die Produktion?** Für den Einsatz außerhalb der Testphase ist eine kommerzielle Aspose OCR‑Lizenz erforderlich.

---

## Was ist ein durchsuchbares PDF?
Ein durchsuchbares PDF ist ein PDF, das sowohl das ursprüngliche gescannte Bild als auch eine unsichtbare, maschinenlesbare Textebene enthält, die durch OCR erzeugt wird. Dieses Dual‑Layer‑Design ermöglicht es Benutzern, den Text auszuwählen, zu kopieren und zu indexieren, während das ursprüngliche Seitenlayout erhalten bleibt.

---

## Warum Aspose OCR für Java verwenden?
Aspose OCR unterstützt **über 30 Sprachen** und kann **bis zu 120 Seiten pro Minute** auf einer Standard‑CPU verarbeiten, was es zu einer der schnellsten Java‑OCR‑Engines macht. Sein integrierter PDF‑Writer bietet zudem **neun Komprimierungsstufen**, mit denen Sie große gescannte Dokumente um bis zu **80 %** verkleinern können, ohne die OCR‑Genauigkeit zu verlieren.

---

## Voraussetzungen
- Java 17 (oder neuer) installiert und konfiguriert.  
- Aspose OCR for Java JAR zum Klassenpfad Ihres Projekts hinzugefügt.  
- Eine gescannte Bilddatei (PNG, JPEG oder TIFF), die Sie in ein durchsuchbares PDF umwandeln möchten.  

---

## Wie erstellt Aspose OCR ein durchsuchbares PDF?
Laden Sie das Quellbild, aktivieren Sie den searchable‑PDF‑Modus, setzen Sie die gewünschte Komprimierungsstufe, wählen Sie die OCR‑Sprache und lassen Sie die Engine das Ergebnis als PDF speichern. Die API übernimmt die schwere Arbeit: Sie führt OCR aus, erstellt die versteckte Textebene und schreibt das endgültige PDF in einem Durchgang.

---

## Gescanntes Bild‑PDF mit Aspose OCR konvertieren

**Aspose OCR‑Engine** ist die Kernkomponente, die Bilder liest, optische Zeichenerkennung durchführt und Ausgaben in verschiedenen Formaten erzeugt.  

Die folgenden Schritte veranschaulichen den Konvertierungsablauf:

- Rufen Sie `setCreateSearchablePdf(true)` auf, um die Engine anzuweisen, die versteckte Textebene einzubetten.  
- Verwenden Sie `setCompressionLevel(9)`, um ein **hochkomprimiertes PDF**‑Ergebnis zu erzielen, das die Dateigröße stark reduziert.  
- Geben Sie `RecognitionLanguage.ENGLISH` (oder eine andere Sprache) an, um die **OCR‑Sprache** für optimale Genauigkeit zu setzen.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Warum das funktioniert:**  
- `setCreateSearchablePdf(true)` weist Aspose an, die versteckte Textebene zu erzeugen, wodurch die Anforderung **embed text layer PDF** erfüllt wird.  
- `setCompressionLevel(9)` bringt die Datei in den **high compression PDF**‑Bereich und verkleinert die Endgröße, ohne die OCR‑Genauigkeit zu beeinträchtigen.  
- Das Argument `RecognitionLanguage.ENGLISH` zeigt, wie man die **OCR‑Sprache** setzt; Sie können es je nach Quellmaterial gegen Französisch, Deutsch usw. austauschen.

---

## Einstellungen für hochkomprimiertes PDF

**CompressionLevel** steuert, wie aggressiv der PDF‑Writer die Größe eingebetteter Bilder und Streams reduziert. Die Werte reichen von 0 (keine Kompression) bis 9 (maximale Kompression).  

Wenn Sie die Stufe auf 9 setzen, wendet Aspose OCR **verlustfreie PNG‑Kompression** für textlastige Seiten und **hochwertiges JPEG** für fotografische Inhalte an, wodurch die Dateigröße im Vergleich zur unkomprimierten Ausgabe häufig um **70‑80 %** reduziert wird.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Ein paar Tipps:

- **Verwenden Sie verlustfreie Bildformate** (PNG) für textlastige Scans; JPEG ist besser für Fotos.  
- **Aktivieren Sie Font‑Subsetting**, wenn Sie benutzerdefinierte Schriften einbetten – Aspose erledigt dies automatisch, wenn Sie ein durchsuchbares PDF erstellen.  
- **Testen Sie die Ausgabengröße** nach jeder Änderung; manchmal liefert eine Kompression auf Stufe 8 eine 10 %ige Größenreduktion bei vernachlässigbarem Qualitätsverlust im Vergleich zu Stufe 9.

---

## Text‑Ebenen‑PDF für Durchsuchbarkeit einbetten

Wenn Sie den Aufruf `setCreateSearchablePdf(true)` weglassen, sieht die resultierende Datei zwar gut aus, Sie können jedoch deren Inhalt nicht durchsuchen. Die versteckte Textebene wird erstellt, indem jedes erkannte Zeichen seiner Position auf der Seite zugeordnet wird.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Worauf Sie achten sollten:**  

- **Dokumente mit gemischten Sprachen** – Sie müssen möglicherweise OCR zweimal ausführen, einmal pro Sprache, und anschließend die Textebenen zusammenführen.  
- **Komplexe Layouts** (Tabellen, mehrspaltig) – Aspose leistet gute Arbeit, aber überprüfen Sie die Ausgabe mit einem PDF‑Viewer, der versteckten Text anzeigt (z. B. Adobe Acrobat „PDF bearbeiten“-Modus).

---

## OCR‑Sprache für genaue Erkennung festlegen

**RecognitionLanguage** ist eine Aufzählung, die der OCR‑Engine mitteilt, welchen Zeichensatz sie erwarten soll, und die Genauigkeit für nicht‑lateinische Schriften deutlich verbessert.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Wann die Sprache zu ändern ist:**  

- Dokumente enthalten **nicht‑lateinische Schriften** (Kyrillisch, Arabisch) – wechseln Sie zum entsprechenden `RecognitionLanguage`.  
- Seiten mit gemischten Sprachen – Sie können `recognizeImageAndSave` zweimal aufrufen, jedes Mal mit einer anderen Sprache, und anschließend die PDFs zusammenführen.

---

## Ausführen des vollständigen Beispiels

Unten finden Sie das vollständige, sofort ausführbare Programm. Ersetzen Sie die Platzhalter‑Pfade durch echte Dateipfade, stellen Sie sicher, dass das Aspose OCR‑JAR im Klassenpfad ist, und führen Sie es aus.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Erwartete Ausgabe:** Beim Ausführen des Programms gibt die Konsole aus:

```
Searchable PDF created.
```

Öffnen Sie `searchable.pdf` in einem beliebigen PDF‑Viewer, versuchen Sie, Text auszuwählen, und Sie sehen die unsichtbare Ebene in Aktion. Sie haben erfolgreich **durchsuchbare PDF** aus einem gescannten Bild erstellt.

## Häufige Probleme und Lösungen

- **Memory‑out‑of‑bounds bei großen Dateien** – aktivieren Sie den Streaming‑Modus, indem Sie `OcrEngine.setUseStream(true)` aufrufen.  
- **Falsche Spracherkennung** – setzen Sie `RecognitionLanguage` explizit, anstatt sich auf die automatische Erkennung zu verlassen.  
- **Unscharfe Scans** – bearbeiten Sie Bilder mit Aspose Imaging, um den Kontrast vor der OCR zu erhöhen.

---

## Häufig gestellte Fragen

**F: Kann ich einen gesamten Ordner mit Bildern stapelweise verarbeiten?**  
A: Ja. Durchlaufen Sie die Dateien, rufen Sie für jede die gleiche OCR‑Konfiguration auf und fügen Sie die resultierenden PDFs mit `PdfDocument.merge()` zusammen.

**F: Unterstützt Aspose OCR direkte PDF‑Eingabe?**  
A: Ja. Verwenden Sie `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` und setzen Sie `setCreateSearchablePdf(true)`.

**F: Wie gehe ich mit passwortgeschützten PDFs um?**  
A: Übergeben Sie das Passwort an `OcrEngine.setPassword("yourPassword")`, bevor Sie die OCR‑Methode aufrufen.

**F: Wie groß ist die maximale Dateigröße, die Aspose OCR verarbeiten kann?**  
A: Die Engine kann PDFs bis zu **2 GB** verarbeiten, wenn Streaming aktiviert ist, nur durch den verfügbaren RAM begrenzt.

**F: Wird für den Produktionseinsatz eine kommerzielle Lizenz benötigt?**  
A: Ja. Eine Testlizenz funktioniert für die Evaluierung, aber eine Voll‑Lizenz entfernt Wasserzeichen und schaltet alle Funktionen frei.

---

## Fazit

Wir haben alles behandelt, was Sie benötigen, um **durchsuchbare PDF**‑Dateien mit Aspose OCR zu **erstellen**:

- Initialisieren Sie die OCR‑Engine.  
- **Konvertieren Sie gescannte Bild‑PDFs**, indem Sie ein PNG/JPEG an `recognizeImageAndSave` übergeben.  
- Verwenden Sie `setCreateSearchablePdf(true)`, um **Text‑Ebenen‑PDF** einzubetten.  
- Wenden Sie `setCompressionLevel(9)` für ein **hochkomprimiertes PDF** an, das leicht bleibt.  
- Wählen Sie das passende `RecognitionLanguage`, um die **OCR‑Sprache** für maximale Genauigkeit zu setzen.

Ab hier können Sie mit Stapelverarbeitung, verschiedenen Sprachen experimentieren oder mehrere gescannte Seiten zu einem einzigen durchsuchbaren PDF kombinieren. Das gleiche Muster funktioniert für andere Sprachen wie Spanisch oder Japanisch – einfach das `RecognitionLanguage`‑Enum austauschen.
