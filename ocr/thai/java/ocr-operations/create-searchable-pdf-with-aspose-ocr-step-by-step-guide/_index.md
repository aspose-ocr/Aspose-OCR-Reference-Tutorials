# สร้าง PDF ที่ค้นหาได้ – คู่มือการเขียนโปรแกรมแบบครบถ้วน

เคยต้องการ **สร้าง PDF ที่ค้นหาได้** จากภาพสแกนแต่ไม่แน่ใจว่าจะเริ่มต้นอย่างไรหรือไม่? คุณไม่ได้อยู่คนเดียว ในกระบวนการทำงานที่มีเอกสารจำนวนมาก PDF ที่เป็นเพียงภาพอย่างเดียวเป็นจุดสิ้นสุดสำหรับการค้นหาและการทำดัชนี.  

ข่าวดีคือด้วย Aspose OCR คุณสามารถ **แปลง PDF ภาพสแกน** ให้เป็นเอกสารที่ค้นหาได้เต็มรูปแบบด้วยเพียงไม่กี่บรรทัดของ Java. tutorial นี้จะพาคุณผ่านทุกขั้นตอน—การเริ่มต้นเครื่อง OCR, การกำหนดค่าการบีบอัด PDF ระดับสูง, การฝังชั้นข้อความที่ซ่อนอยู่, และแม้กระทั่งการเลือกภาษาของ OCR ที่เหมาะสม.  

เมื่อจบคู่มือคุณจะมีโปรแกรมที่สามารถรันได้ซึ่งสร้าง PDF ที่ค้นหาได้, ไฟล์ที่คุณสามารถใส่ลงในเครื่องมือค้นหาใด ๆ หรือระบบจัดการเอกสารโดยไม่มีปัญหา.

## แปลง PDF ภาพสแกนโดยใช้ Aspose OCR

**Aspose OCR engine** is the core component that reads images, performs optical character recognition, and produces output in various formats.  
The following steps illustrate the conversion flow:

- Call `setCreateSearchablePdf(true)` to instruct the engine to embed the hidden text layer.  
- Use `setCompressionLevel(9)` to achieve **high compression PDF** output, reducing file size dramatically.  
- Specify `RecognitionLanguage.ENGLISH` (or another language) to **set OCR language** for optimal accuracy.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**ทำไมวิธีนี้ถึงได้ผล:**  
- `setCreateSearchablePdf(true)` tells Aspose to generate the hidden text layer, satisfying the **embed text layer PDF** requirement.  
- `setCompressionLevel(9)` pushes the file into the **high compression PDF** range, shrinking the final size without sacrificing OCR accuracy.  
- The `RecognitionLanguage.ENGLISH` argument shows how to **set OCR language**; you can swap it for French, German, etc., depending on your source material.

---

## การตั้งค่า PDF บีบอัดระดับสูง

**CompressionLevel** controls how aggressively the PDF writer reduces the size of embedded images and streams. Values range from 0 (no compression) to 9 (maximum compression).  

When you set the level to 9, Aspose OCR applies **lossless PNG compression** for text‑heavy pages and **high‑quality JPEG** for photographic content, often cutting file size by **70‑80 %** compared with the uncompressed output.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

เคล็ดลับบางประการ:
- **Use lossless image formats** (PNG) for text‑heavy scans; JPEG is better for photos.  
- **Enable font subsetting** if you embed custom fonts—Aspose does this automatically when you create a searchable PDF.  
- **Test the output size** after each change; sometimes a level‑8 compression gives you a 10 % size reduction with negligible quality loss compared to level 9.

## ฝังชั้นข้อความใน PDF เพื่อการค้นหา

If you skip the `setCreateSearchablePdf(true)` call, the resulting file will look fine but you won’t be able to search its contents. The hidden text layer is created by mapping each recognized character to its location on the page.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**สิ่งที่ควรระวัง:**  
- **Mixed‑language documents** – you might need to run OCR twice, once per language, and then merge the text layers.  
- **Complex layouts** (tables, multi‑column) – Aspose does a decent job, but double‑check the output with a PDF viewer that shows hidden text (e.g., Adobe Acrobat’s “Edit PDF” mode).

---

## ตั้งค่าภาษา OCR เพื่อการจดจำที่แม่นยำ

**RecognitionLanguage** is an enumeration that tells the OCR engine which character set to expect, dramatically improving accuracy for non‑Latin scripts.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**เมื่อควรเปลี่ยนภาษา:**  
- Documents contain **non‑Latin scripts** (Cyrillic, Arabic) – switch to the appropriate `RecognitionLanguage`.  
- Mixed language pages – you can call `recognizeImageAndSave` twice, each time with a different language, and then merge the PDFs.

## การรันตัวอย่างเต็มรูปแบบ

Below is the full, ready‑to‑run program. Replace the placeholder paths with real file locations, ensure the Aspose OCR JAR is on your classpath, and execute.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**ผลลัพธ์ที่คาดหวัง:** เมื่อคุณรันโปรแกรม คอนโซลจะแสดง:

```
Searchable PDF created.
```

เปิด `searchable.pdf` ในโปรแกรมอ่าน PDF ใด ๆ, ลองเลือกข้อความ, แล้วคุณจะเห็นชั้นที่ซ่อนอยู่ทำงาน. คุณได้ **สร้าง PDF ที่ค้นหาได้** จากภาพสแกนสำเร็จแล้ว.

## ปัญหาทั่วไปและวิธีแก้
- **Memory‑out‑of‑bounds on large files** – enable streaming mode by calling `OcrEngine.setUseStream(true)`.  
- **Incorrect language detection** – explicitly set `RecognitionLanguage` rather than relying on auto‑detect.  
- **Blurry scans** – preprocess images with Aspose Imaging to increase contrast before OCR.

## คำถามที่พบบ่อย

**Q: ฉันสามารถประมวลผลแบบแบตช์โฟลเดอร์ของภาพทั้งหมดได้หรือไม่?**  
A: ใช่. Iterate over the files, call the same OCR configuration for each, and concatenate the resulting PDFs with `PdfDocument.merge()`.

**Q: Aspose OCR รองรับการป้อน PDF โดยตรงหรือไม่?**  
A: รองรับ. Use `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` and set `setCreateSearchablePdf(true)`.

**Q: ฉันจะจัดการกับ PDF ที่มีการป้องกันด้วยรหัสผ่านอย่างไร?**  
A: Pass the password to `OcrEngine.setPassword("yourPassword")` before invoking the OCR method.

**Q: ขนาดไฟล์สูงสุดที่ Aspose OCR สามารถจัดการได้คือเท่าไหร่?**  
A: The engine can process PDFs up to **2 GB** when streaming is enabled, limited only by available RAM.

**Q: จำเป็นต้องมีใบอนุญาตเชิงพาณิชย์สำหรับการใช้งานในผลิตภัณฑ์หรือไม่?**  
A: ใช่. A trial license works for evaluation, but a full license removes evaluation watermarks and unlocks all features.

## สรุป

เราได้ครอบคลุมทุกอย่างที่คุณต้องการ **สร้าง PDF ที่ค้นหาได้** ด้วย Aspose OCR:
- เริ่มต้นเครื่อง OCR.
