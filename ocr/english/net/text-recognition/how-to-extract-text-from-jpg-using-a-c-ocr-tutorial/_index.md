# How to extract text from JPG using a C# OCR tutorial

If you need to extract text from JPG images in a .NET application, this guide shows you exactly how to do it. You’ll load an image for OCR, set the OCR language, and retrieve the recognized text with Aspose.OCR—all in a single, self‑contained C# program.

The tutorial covers everything required to run OCR on Ukrainian, English, or any supported language. No external tools are needed beyond the Aspose.OCR NuGet package, and the code follows best practices for resource management and error handling.

## What you’ll accomplish

By the end of this tutorial you will:

* Load an image for OCR directly from the file system.  
* Set OCR language to match the source document.  
* Extract text from a JPG file and output the result to the console.  
* Understand how to adapt the example for other image formats or languages.

**Prerequisites**  

* .NET 6.0 SDK or later installed.  
* Visual Studio 2022 (or any C# IDE).  
* Aspose.OCR NuGet package (`dotnet add package Aspose.OCR`).  

No prior OCR experience is required.

## How to extract text from JPG with Aspose OCR in C#

The following sections break the process into clear steps. Each step includes a code snippet, an explanation of why the step matters, and practical tips you can apply in real projects.

### Step 1: Install the Aspose.OCR package

Open a terminal in your project folder and run:

```bash
dotnet add package Aspose.OCR
```

The package contains the `OcrEngine` class, language data files, and utilities for loading images. Installing it once makes the library available to every project that references the `.csproj` file.

### Step 2: Create a console application skeleton

Create a new console project if you don’t already have one:

```bash
dotnet new console -n OcrDemo
cd OcrDemo
```

Replace the autogenerated `Program.cs` with the code shown in the next steps. Keeping the project minimal helps you focus on the OCR workflow.

### Step 3: Load an image for OCR

The first operation after instantiating the engine is to provide the image you want to process. Aspose.OCR supports JPEG, PNG, BMP, GIF, and TIFF. In this tutorial we work with a JPEG file named **sample_ukrainian.jpg**.

```csharp
using System;
using Aspose.OCR;

class Program
{
    static void Main()
    {
        // Step 3: Load the image to be processed
        // ImageStream.FromFile reads the file and creates a stream compatible with OcrEngine.
        var imagePath = "YOUR_DIRECTORY/sample_ukrainian.jpg";
        using (var engine = new OcrEngine())
        {
            engine.Image = ImageStream.FromFile(imagePath);
```

**Why this matters** – Loading the image into an `ImageStream` ensures the engine can access the pixel data without locking the original file. This approach also works for images stored in memory or received from a web API.

### Step 4: Set OCR language

OCR accuracy heavily depends on the language model. Aspose.OCR ships with data files for more than 30 languages. To recognize Ukrainian text, set the language code to `"ukr"`.

```csharp
            // Step 4: Set the language for recognition (Ukrainian = "ukr")
            engine.Language = "ukr";
```

If you need to process English, use `"eng"`; for Spanish, `"spa"`. The language codes follow the ISO 639‑2 standard. When you specify a language that is not yet downloaded, the engine automatically fetches the required data the first time you run the code.

### Step 5: Perform OCR and extract text from JPG

Calling `Recognize()` runs the recognition pipeline and returns the detected text as a plain string.

```csharp
            // Step 5: Perform OCR – required language data will be downloaded automatically if missing
            string recognizedText = engine.Recognize();

            // Step 6: Output the recognized text
            Console.WriteLine("=== Extracted text ===");
            Console.WriteLine(recognizedText);
        }
    }
}
```

**Explanation** – The `using` block guarantees that the `OcrEngine` instance is disposed correctly, releasing unmanaged resources such as native memory buffers. Disposing the engine is crucial in long‑running services that process many images.

### Step 6: Run the program and verify the output

Compile and execute the application:

```bash
dotnet run
```

You should see output similar to:

```
=== Extracted text ===
Привіт, це тестовий текст українською мовою.
```

If the console displays garbled characters, ensure that your terminal uses UTF‑8 encoding (`chcp 65001` on Windows) and that the source image contains clear, high‑contrast text.

## Adapting the c# OCR tutorial for other scenarios

### Loading images from memory or a web request

Instead of `ImageStream.FromFile`, you can create a stream from a byte array:

```csharp
byte[] imageBytes = await httpClient.GetByteArrayAsync(imageUrl);
engine.Image = ImageStream.FromBytes(imageBytes);
```

This technique is useful when processing images uploaded via an API endpoint.

### Processing multiple images in a batch

Wrap the OCR logic in a method and iterate over a collection of file paths:

```csharp
static string ExtractText(string path, string language = "eng")
{
    using var engine = new OcrEngine();
    engine.Image = ImageStream.FromFile(path);
    engine.Language = language;
    return engine.Recognize();
}
```

Batch processing reduces overhead by reusing the same `OcrEngine` instance if you move the `using` statement outside the loop.

### Handling errors and edge cases

OCR can fail if the image is corrupted or the language data cannot be downloaded. Catch exceptions to provide a graceful fallback:

```csharp
try
{
    string text = ExtractText(imagePath, "ukr");
    Console.WriteLine(text);
}
catch (Exception ex)
{
    Console.Error.WriteLine($"OCR failed: {ex.Message}");
}
```

Logging the exception helps you troubleshoot network issues when language files need to be fetched.

## Full, runnable example

Below is the complete program you can copy directly into `Program.cs`. It includes all required `using` directives, comments, and error handling.

```csharp
using System;
using Aspose.OCR;

class Program
{
    static void Main()
    {
        // Path to the JPEG image you want to process.
        var imagePath = "YOUR_DIRECTORY/sample_ukrainian.jpg";

        // Ensure the file exists before attempting OCR.
        if (!System.IO.File.Exists(imagePath))
        {
            Console.Error.WriteLine($"File not found: {imagePath}");
            return;
        }

        try
        {
            // Create the OCR engine inside a using block to guarantee disposal.
            using var engine = new OcrEngine();

            // Load the image for OCR.
            engine.Image = ImageStream.FromFile(imagePath);

            // Set OCR language (Ukrainian = "ukr").
            engine.Language = "ukr";

            // Perform OCR and retrieve the recognized text.
            string recognizedText = engine.Recognize();

            // Output the extracted text.
            Console.WriteLine("=== Extracted text from JPG ===");
            Console.WriteLine(recognizedText);
        }
        catch (Exception ex)
        {
            // Handle any exceptions that occur during OCR.
            Console.Error.WriteLine($"Error during OCR processing: {ex.Message}");
        }
    }
}
```

Running this code extracts text from a JPG file and prints it to the console. Replace `imagePath` and `engine.Language` to work with other files and languages.
