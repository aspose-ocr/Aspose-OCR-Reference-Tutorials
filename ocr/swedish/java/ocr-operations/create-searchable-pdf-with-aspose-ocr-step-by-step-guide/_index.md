# Skapa sökbar PDF – komplett programmeringshandledning

Har du någonsin behövt **skapa sökbar PDF**‑filer från skannade bilder men varit osäker på var du ska börja? Du är inte ensam. I många dokumenttunga arbetsflöden är en ren bild‑endast PDF en återvändsgränd för sökning och indexering.  

Den goda nyheten är att du med Aspose OCR kan **konvertera skannad bild‑PDF** till ett fullt sökbart dokument med bara några rader Java. Denna handledning guidar dig genom varje steg — initiering av OCR‑motorn, konfigurering av högkomprimerings‑PDF‑inställningar, inbäddning av ett dolt textlager och även val av rätt OCR‑språk.  

I slutet av den här guiden har du ett körbart program som producerar en sökbar PDF, en fil du kan släppa in i vilken sökmotor eller dokumenthanteringssystem som helst utan problem.

---

## Snabba svar
- **Vad betyder “searchable PDF”?** Det kombinerar ett visuellt bildlager med ett osynligt textlager som genereras av OCR.  
- **Vilket bibliotek hanterar konverteringen?** Aspose OCR for Java.  
- **Hur kan jag hålla filstorleken liten?** Använd `setCompressionLevel(9)` för högkomprimerings‑PDF.  
- **Kan jag bearbeta icke‑engelska dokument?** Ja — ange rätt `RecognitionLanguage`‑enum‑värde.  
- **Behöver jag en licens för produktion?** En kommersiell Aspose OCR‑licens krävs för icke‑testanvändning.

---

## Vad är en sökbar PDF?
En sökbar PDF är en PDF som innehåller både den ursprungliga skannade bilden och ett osynligt, maskinläsbart textlager skapat av OCR. Denna dubbellagersdesign låter användare markera, kopiera och indexera texten samtidigt som de ser den ursprungliga sidans utseende.

---

## Varför använda Aspose OCR för Java?
Aspose OCR stödjer **över 30 språk** och kan bearbeta **upp till 120 sidor per minut** på en standard‑CPU, vilket gör den till en av de snabbaste Java‑OCR‑motorerna. Dess inbyggda PDF‑skrivare erbjuder också **nio komprimeringsnivåer**, vilket låter dig krympa stora skannade dokument med upp till **80 %** utan att förlora OCR‑noggrannhet.

---

## Förutsättningar
- Java 17 (eller senare) installerat och konfigurerat.  
- Aspose OCR for Java JAR tillagd i ditt projekts classpath.  
- En skannad bildfil (PNG, JPEG eller TIFF) som du vill omvandla till en sökbar PDF.  

---

## Hur skapar Aspose OCR en sökbar PDF?
Läs in källbilden, aktivera searchable‑PDF‑läge, ange önskad komprimeringsnivå, välj OCR‑språk och instruera motorn att spara resultatet som en PDF. API‑et sköter det tunga arbetet: det kör OCR, skapar det dolda textlagret och skriver den slutgiltiga PDF‑filen i ett steg.

---

## Konvertera skannad bild‑PDF med Aspose OCR

**Aspose OCR‑motor** är kärnkomponenten som läser bilder, utför optisk teckenigenkänning och producerar utdata i olika format.  

Följande steg illustrerar konverteringsflödet:

- Anropa `setCreateSearchablePdf(true)` för att instruera motorn att bädda in det dolda textlagret.  
- Använd `setCompressionLevel(9)` för att uppnå **high compression PDF**‑utdata, vilket minskar filstorleken dramatiskt.  
- Specificera `RecognitionLanguage.ENGLISH` (eller ett annat språk) för att **set OCR language** för optimal noggrannhet.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Varför detta fungerar:**  
- `setCreateSearchablePdf(true)` instruerar Aspose att generera det dolda textlagret, vilket uppfyller kravet **embed text layer PDF**.  
- `setCompressionLevel(9)` förflyttar filen till **high compression PDF**‑intervallet, vilket krymper den slutliga storleken utan att offra OCR‑noggrannhet.  
- `RecognitionLanguage.ENGLISH`‑argumentet visar hur man **set OCR language**; du kan byta det till franska, tyska osv., beroende på ditt källmaterial.

---

## Inställningar för hög komprimerings‑PDF

**CompressionLevel** styr hur aggressivt PDF‑skrivaren minskar storleken på inbäddade bilder och strömmar. Värdena sträcker sig från 0 (ingen komprimering) till 9 (maximal komprimering).  

När du sätter nivån till 9 använder Aspose OCR **lossless PNG compression** för texttunga sidor och **high‑quality JPEG** för fotografiskt innehåll, vilket ofta minskar filstorleken med **70‑80 %** jämfört med den okomprimerade utdata.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Ett par tips:

- **Use lossless image formats** (PNG) för texttunga skanningar; JPEG är bättre för foton.  
- **Enable font subsetting** om du bäddar in anpassade typsnitt — Aspose gör detta automatiskt när du skapar en searchable PDF.  
- **Test the output size** efter varje förändring; ibland ger en nivå‑8 komprimering en 10 % minskning med försumbar kvalitetsförlust jämfört med nivå 9.

---

## Bädda in textlager‑PDF för sökbarhet

Om du hoppar över anropet `setCreateSearchablePdf(true)`, kommer den resulterande filen att se bra ut men du kommer inte kunna söka i dess innehåll. Det dolda textlagret skapas genom att mappa varje igenkänd tecken till dess position på sidan.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Vad att se upp för:**  

- **Mixed‑language documents** – du kan behöva köra OCR två gånger, en gång per språk, och sedan slå ihop textlagren.  
- **Complex layouts** (tables, multi‑column) – Aspose gör ett bra jobb, men dubbelkolla utdata med en PDF‑visare som visar dolt text (t.ex. Adobe Acrobat’s “Edit PDF”‑läge).

---

## Ställ in OCR‑språk för exakt igenkänning

**RecognitionLanguage** är en uppräkning som talar om för OCR‑motorn vilken teckenuppsättning som förväntas, vilket dramatiskt förbättrar noggrannheten för icke‑latinska skript.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**När du ska byta språk:**  

- Dokument innehåller **non‑Latin scripts** (Cyrillic, Arabic) – byt till lämplig `RecognitionLanguage`.  
- Sidor med blandade språk – du kan anropa `recognizeImageAndSave` två gånger, varje gång med ett annat språk, och sedan slå ihop PDF‑erna.

## Köra det kompletta exemplet

Nedan är det fullständiga, färdiga att köra programmet. Ersätt platshållar‑sökvägarna med riktiga filplatser, säkerställ att Aspose OCR‑JAR‑filen finns i din classpath och kör programmet.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Förväntad utskrift:** När du kör programmet skriver konsolen ut:

```
Searchable PDF created.
```

Öppna `searchable.pdf` i någon PDF‑visare, försök markera text, och du kommer att se det osynliga lagret i aktion. Du har framgångsrikt **create searchable pdf** från en skannad bild.

## Vanliga problem och lösningar

- **Memory‑out‑of‑bounds on large files** – aktivera streaming‑läge genom att anropa `OcrEngine.setUseStream(true)`.  
- **Incorrect language detection** – ange explicit `RecognitionLanguage` istället för att förlita dig på auto‑detect.  
- **Blurry scans** – förbehandla bilder med Aspose Imaging för att öka kontrasten före OCR.

---

## Vanliga frågor

**Q: Kan jag batch‑processa en hel mapp med bilder?**  
A: Ja. Iterera över filerna, anropa samma OCR‑konfiguration för varje, och slå ihop de resulterande PDF‑erna med `PdfDocument.merge()`.

**Q: Stöder Aspose OCR PDF‑inmatning direkt?**  
A: Ja. Använd `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` och sätt `setCreateSearchablePdf(true)`.

**Q: Hur hanterar jag lösenordsskyddade PDF‑filer?**  
A: Skicka lösenordet till `OcrEngine.setPassword("yourPassword")` innan du anropar OCR‑metoden.

**Q: Vad är den maximala filstorleken Aspose OCR kan hantera?**  
A: Motorn kan bearbeta PDF‑filer upp till **2 GB** när streaming är aktiverat, begränsat endast av tillgängligt RAM.

**Q: Krävs en kommersiell licens för produktionsanvändning?**  
A: Ja. En testlicens fungerar för utvärdering, men en full licens tar bort vattenstämplar och låser upp alla funktioner.

## Slutsats

Vi har gått igenom allt du behöver för att **create searchable PDF**‑filer med Aspose OCR:

- Initiera OCR‑motorn.  
- **Convert scanned image PDF** genom att mata in en PNG/JPEG i `recognizeImageAndSave`.  
- Använd `setCreateSearchablePdf(true)` för att **embed text layer PDF**.  
- Applicera `setCompressionLevel(9)` för en **high compression PDF** som förblir lätt.  
- Välj rätt `RecognitionLanguage` för att **set OCR language** för maximal noggrannhet.

Härifrån kan du experimentera med batch‑bearbetning, olika språk, eller till och med kombinera flera skannade sidor till en enda sökbar PDF. Samma mönster fungerar för andra språk som spanska eller japanska — byt bara `RecognitionLanguage`‑enum.
