# Aspose.OCR for .NET を使用した画像からテキストを抽出する方法

## はじめに

画像からテキストを**extract text from image**ファイルを迅速かつ確実に処理したい場合、Aspose.OCR for .NET は堅実な選択肢です。このチュートリアルでは、ライブラリのセットアップ、認識オプションの設定、そして多言語出力やレイアウトデータを含む完全な OCR 結果の取得手順を解説します。最後まで読むと、**extract text from image**ファイルの抽出方法、さまざまな言語で**recognize text from image**する方法、そして公式の Aspose OCR ドキュメントの場所が分かります。

## クイック回答
- **What does “extract text from image” mean?** それは、OCR エンジンが画像内で検出した読み取れる文字を取得することを指します。  
- **Which library should I use?** Aspose.OCR for .NET はシンプルな API、多言語サポート、そしてすぐに試せる **aspose ocr trial** を提供します。  
- **Do I need a license?** 無料トライアルが利用可能です。製品版の使用にはライセンスが必要です。  
- **What .NET versions are supported?** .NET Framework 4.5 以上および .NET Core/5/6+ がサポートされています。  
- **Can I improve OCR accuracy?** はい、正しい言語を選択し DPI を調整することで **improve ocr accuracy** が可能です。

## “extract text from image” とは何か

画像からテキストを抽出することは、ビットマップ内の文字の視覚的表現を編集可能で検索可能な Unicode 文字列に変換することを意味します。このプロセスは、ピクセルパターンを解析し、グリフを識別し、単語や文に組み立てる OCR エンジンに依存しています。Aspose.OCR のエンジンは 50 以上の言語をサポートし、プレーンテキスト、JSON、XML のいずれかで出力できるため、結果を下流のワークフローに簡単に組み込むことができます。

## このタスクに Aspose.OCR を使用する理由

Aspose.OCR は **50+ languages** をサポートし、ファイル全体をメモリに読み込むことなく **multi‑hundred‑page image batches** を処理でき、 多くのオープンソース代替品と比較して最大 **3 × faster** のパフォーマンスを提供します。API は数行のコードだけで使用でき、組み込みの前処理（二値化、ノイズ除去）によりノイズの多いスキャンで **improve OCR accuracy** が最大 **30 %** 向上します。

## Aspose.OCR はどのように OCR 精度を向上させるか

Aspose.OCR は、認識前に二値化、デスキュー、ノイズ除去などの画像前処理を自動的に適用することで OCR 精度を向上させます。また、DPI（dots per inch）を 150〜300 の範囲で手動設定することも可能です。高い DPI は細部を保持し、低い DPI は処理速度を向上させます。混在したスクリプトを含む文書では、マルチリンガルモードを有効にすることでエンジンが各領域に最適な言語モデルを選択し、精度がさらに向上します。

## Aspose.OCR で OCR 言語を設定する方法

`engine.Recognize()` を呼び出す前に、目的の ISO‑639‑1 コードを `settings.Language` プロパティに割り当てることで OCR 言語を設定します。例えば、英語は `"en"`、フランス語は `"fr"`、英語とスペイン語を同時に検出したい場合は `"en,es"` のようにカンマ区切りで指定します。正しい言語を選択することで不要な言語モデルのチェックが省かれ、平均で処理時間が **15 %** 短縮されます。

## Aspose OCR ライセンスの取得方法

Aspose ストアから永続または一時ライセンスを購入し、ライセンスファイル（`Aspose.OCR.lic`）をアプリケーションのルートフォルダーに配置します。実行時に `License license = new License(); license.SetLicense("Aspose.OCR.lic");` でロードします。評価用の 30 日間の一時ライセンスも利用可能で、クレジットカード情報なしで Aspose ポータルからリクエストできます。

## 名前空間のインポート

.NET アプリケーションで、まず必要な名前空間をインポートします:
```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.IO;
using Aspose.OCR;
```

## 手順 1: ドキュメントディレクトリの設定

処理したい画像が格納されているフォルダーを指定します:
```csharp
string dataDir = "Your Document Directory";
```

## 手順 2: Aspose.OCR の初期化

OCR エンジンのインスタンスを作成します:
```csharp
AsposeOcr api = new AsposeOcr();
```

## 手順 3: 画像パスの指定

認識したい画像ファイルの正確なパスを指定します:
```csharp
string fullPath = dataDir + "sample.png";
```

## 手順 4: 認識設定の構成

シナリオに合わせて設定を調整します。デフォルト動作が必要な場合や、多言語テキスト認識のための言語選択などのカスタムオプションが必要な場合に対応します:
```csharp
RecognitionSettings settings = new RecognitionSettings
{
    // Specify your recognition settings here
    // Example: Language = Language.English | Language.Spanish
};
```

## 手順 5: 画像認識の実行

OCR プロセスを実行し、結果を取得します:
```csharp
RecognitionResult result = api.RecognizeImage(fullPath, settings);
```

## 手順 6: 認識結果の出力

抽出されたテキスト、レイアウト情報、JSON 表現、警告などを含む完全な認識出力を表示します:
```csharp
PrintRecognitionResult(result);
```

## よくある問題と解決策

| 問題 | 原因 | 解決策 |
|-------|--------|-----|
| **No text returned** | 画像パスが間違っているか、サポートされていない形式です | `fullPath` を確認し、画像がサポートされているタイプ（PNG、JPEG、BMP）であることを確認してください。 |
| **Incorrect language detection** | デフォルトの言語設定が画像に合っていない可能性があります | より高い精度のために、`settings.Language` を適切な言語に設定してください。 |
| **Performance slowdown on large images** | 高解像度画像は処理時間を増加させます | 認識前に画像のサイズを変更するか、`settings.Dpi` を低い値に調整してください。 |
| **Low accuracy on scanned documents** | スキャン画像にノイズが含まれている可能性があります | 二値化などの前処理を使用するか、`settings.Preprocess = true` を適用して **improve ocr accuracy** を実現してください。 |
| **Need to handle a scanned PDF** | PDF はまず画像に変換する必要があります | **Convert scanned image** ページを PDF‑to‑image ライブラリで PNG/JPEG に変換し、各画像を Aspose.OCR に渡してください。 |
