# 検索可能なPDFの作成 – 完全プログラミングチュートリアル

スキャンした画像から **検索可能なPDF** を作成する必要があったが、どこから始めればいいかわからなかったことはありませんか？ あなたは一人ではありません。文書が大量にあるワークフローでは、画像だけのPDFは検索やインデックス作成において行き止まりです。  

良いニュースは、Aspose OCR を使用すれば、**スキャン画像PDF** を数行のJavaコードで完全に検索可能なドキュメントに **変換** できることです。このチュートリアルでは、OCRエンジンの初期化、高圧縮PDF設定の構成、隠しテキストレイヤーの埋め込み、さらには適切なOCR言語の選択まで、すべての手順を案内します。  

このガイドの最後までに、検索可能なPDFを生成する実行可能なプログラムが手に入ります。このファイルは、検索エンジンや文書管理システムに問題なく投入できます。

## クイック回答
- **検索可能なPDFとは何ですか？** 画像のビジュアルレイヤーと、OCRによって生成された見えないテキストレイヤーを組み合わせたものです。  
- **変換を処理するライブラリはどれですか？** Aspose OCR for Java。  
- **ファイルサイズを小さく保つにはどうすればよいですか？** 高圧縮PDFのために `setCompressionLevel(9)` を使用します。  
- **英語以外の文書を処理できますか？** はい — 適切な `RecognitionLanguage` 列挙値を設定してください。  
- **本番環境でライセンスが必要ですか？** 無料トライアル以外の使用には商用の Aspose OCR ライセンスが必要です。

## 検索可能なPDFとは？
検索可能なPDFは、元のスキャン画像と、OCRによって生成された見えない機械可読テキストレイヤーの両方を含むPDFです。この二層構造により、ユーザーはテキストを選択、コピー、インデックス作成でき、元のページの外観もそのまま表示されます。

## なぜ Aspose OCR for Java を使用するのか？
Aspose OCR は **30以上の言語** をサポートし、標準CPU上で **1分あたり最大120ページ** を処理できるため、最も高速なJava OCRエンジンの一つです。組み込みのPDFライターは **9段階の圧縮** を提供し、OCR精度を損なうことなく大きなスキャン文書を最大 **80 %** 縮小できます。

- 検索可能なPDFに変換したいスキャン画像ファイル（PNG、JPEG、またはTIFF）。

ソース画像を読み込み、searchable‑PDFモードを有効にし、希望する圧縮レベルを設定し、OCR言語を選択し、エンジンに結果をPDFとして保存させます。API が重い処理を担当し、OCRを実行し、隠しテキストレイヤーを作成し、最終的なPDFを書き出します。

## Aspose OCR を使用したスキャン画像PDFの変換

**Aspose OCR エンジン** は画像を読み取り、光学文字認識を実行し、さまざまな形式で出力を生成するコアコンポーネントです。  

以下の手順で変換フローを示します：

- `setCreateSearchablePdf(true)` を呼び出して、エンジンに隠しテキストレイヤーの埋め込みを指示します。  
- `setCompressionLevel(9)` を使用して、**高圧縮PDF** 出力を実現し、ファイルサイズを大幅に削減します。  
- `RecognitionLanguage.ENGLISH`（または他の言語）を指定して、最適な精度のために **OCR言語を設定** します。

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**この動作の理由:**  
- `setCreateSearchablePdf(true)` は Aspose に隠しテキストレイヤーの生成を指示し、**embed text layer PDF** の要件を満たします。  
- `setCompressionLevel(9)` はファイルを **high compression PDF** の範囲に押し上げ、OCR精度を犠牲にせず最終サイズを縮小します。  
- `RecognitionLanguage.ENGLISH` 引数は **OCR言語を設定** する方法を示しています。ソース素材に応じてフランス語やドイツ語などに置き換えることができます。

---

## 高圧縮PDF設定
**CompressionLevel** は、PDFライターが埋め込まれた画像やストリームのサイズをどれだけ積極的に削減するかを制御します。値は 0（圧縮なし）から 9（最大圧縮）までです。  

レベルを 9 に設定すると、Aspose OCR はテキストが多いページに対して **ロスレスPNG圧縮** を、写真コンテンツに対して **高品質JPEG** を適用し、非圧縮出力と比較してファイルサイズを **70‑80 %** 縮小することがよくあります。

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

いくつかのヒント：

- **テキストが多いスキャンにはロスレス画像形式（PNG）を使用**してください。写真には JPEG が適しています。  
- **カスタムフォントを埋め込む場合はフォントサブセット化を有効化**してください。検索可能なPDFを作成するとき、Aspose は自動的にこれを行います。  
- **各変更後に出力サイズをテスト**してください。レベル‑8圧縮は、レベル‑9と比較して品質低下がほとんどなく、10 % のサイズ削減をもたらすことがあります。

---

## 検索可能性のためのテキストレイヤーPDFの埋め込み
`setCreateSearchablePdf(true)` の呼び出しを省略すると、結果のファイルは見た目は問題ありませんが、内容を検索できません。隠しテキストレイヤーは、認識された各文字をページ上の位置にマッピングすることで作成されます。

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**注意点:**  

- **混合言語文書** – 言語ごとに OCR を2回実行し、テキストレイヤーをマージする必要がある場合があります。  
- **複雑なレイアウト**（テーブル、マルチカラム） – Aspose はかなりの精度で処理しますが、隠しテキストを表示できるPDFビューア（例：Adobe Acrobat の「PDFを編集」モード）で出力を再確認してください。

---

## 正確な認識のためにOCR言語を設定する
**RecognitionLanguage** は、OCRエンジンに期待する文字セットを指示する列挙型で、ラテン文字以外のスクリプトの精度を劇的に向上させます。

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**言語を変更すべき時:**  

- 文書に **ラテン文字以外のスクリプト**（キリル文字、アラビア文字など）が含まれる場合 – 適切な `RecognitionLanguage` に切り替えてください。  
- 混合言語ページ – `recognizeImageAndSave` を異なる言語で2回呼び出し、PDF をマージすることができます。

---

## 完全なサンプルの実行
以下は完全に実行可能なプログラムです。プレースホルダーのパスを実際のファイル場所に置き換え、Aspose OCR JAR がクラスパスにあることを確認して実行してください。

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**期待される出力:** プログラムを実行すると、コンソールに次が表示されます：

```
Searchable PDF created.
```

`searchable.pdf` を任意のPDFビューアで開き、テキスト選択を試すと、隠しレイヤーが機能しているのが分かります。スキャン画像から **検索可能なPDFの作成** に成功しました。

## よくある問題と解決策
- **大きなファイルでのメモリ不足** – `OcrEngine.setUseStream(true)` を呼び出してストリーミングモードを有効にします。  
- **言語検出の誤り** – 自動検出に頼らず、明示的に `RecognitionLanguage` を設定してください。  
- **ぼやけたスキャン** – OCR 前に Aspose Imaging で画像を前処理し、コントラストを上げます。

## よくある質問
**Q: 画像フォルダー全体をバッチ処理できますか？**  
A: はい。ファイルを反復処理し、各ファイルに同じOCR設定を呼び出し、`PdfDocument.merge()` で生成されたPDFを連結します。

**Q: Aspose OCR は PDF 入力を直接サポートしていますか？**  
A: サポートしています。`OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` を使用し、`setCreateSearchablePdf(true)` を設定します。

**Q: パスワード保護されたPDFを処理するには？**  
A: OCR メソッドを呼び出す前に、`OcrEngine.setPassword("yourPassword")` にパスワードを渡します。

**Q: Aspose OCR が処理できる最大ファイルサイズは？**  
A: ストリーミングが有効な場合、エンジンは **2 GB** までのPDFを処理でき、利用可能なRAMが唯一の制限です。

**Q: 本番使用には商用ライセンスが必要ですか？**  
A: はい。トライアルライセンスは評価用に機能しますが、フルライセンスが評価用の透かしを除去し、すべての機能を解放します。

## 結論
Aspose OCR を使用して **検索可能なPDF** を作成するために必要なすべてをカバーしました：

- OCRエンジンを初期化します。  
- `recognizeImageAndSave` に PNG/JPEG を渡して **スキャン画像PDFを変換** します。  
- `setCreateSearchablePdf(true)` を使用して **テキストレイヤーPDFを埋め込み** します。  
- `setCompressionLevel(9)` を適用して、軽量な **高圧縮PDF** を作成します。  
- 最大精度のために **OCR言語を設定** するために適切な `RecognitionLanguage` を選択します。

ここからは、バッチ処理や異なる言語、あるいは複数のスキャンページを単一の検索可能なPDFに結合するなどを試すことができます。同じパターンはスペイン語や日本語など他の言語でも機能します — `RecognitionLanguage` 列挙を置き換えるだけです。問題が発生した場合は遠慮なくコメントを残してください。コーディングを楽しんでください！
