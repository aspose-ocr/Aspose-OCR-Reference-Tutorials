# Создать поисковый PDF – полное программное руководство

Когда‑нибудь вам нужно было **create searchable PDF** файлы из отсканированных изображений, но вы не знали, с чего начать? Вы не одиноки. Во многих рабочих процессах с большим количеством документов обычный PDF, содержащий только изображения, является тупиковой точкой для поиска и индексации.  

Хорошая новость в том, что с Aspose OCR вы можете **convert scanned image PDF** в полностью поисковый документ всего за несколько строк кода на Java. Этот учебник проведет вас через каждый шаг — инициализацию OCR‑движка, настройку параметров PDF с высоким уровнем сжатия, встраивание скрытого текстового слоя и даже выбор правильного языка OCR.

К концу этого руководства у вас будет исполняемая программа, создающая поисковый PDF, файл, который вы сможете без проблем загрузить в любой поисковый движок или систему управления документами.

---

## Быстрые ответы
- **Что означает “searchable PDF”?** It combines a visual image layer with an invisible text layer generated by OCR.  
- **Какая библиотека обрабатывает конвертацию?** Aspose OCR for Java.  
- **Как уменьшить размер файла?** Use `setCompressionLevel(9)` for high compression PDF.  
- **Могу ли я обрабатывать документы не на английском?** Yes—set the appropriate `RecognitionLanguage` enum value.  
- **Нужна ли лицензия для продакшна?** A commercial Aspose OCR license is required for non‑trial use.

---

## Что такое поисковый PDF?
Поисковый PDF — это PDF, содержащий как оригинальное отсканированное изображение, так и невидимый, машинно‑читаемый текстовый слой, созданный OCR. Такая двойная структура позволяет пользователям выделять, копировать и индексировать текст, сохраняя при этом внешний вид оригинальной страницы.

---

## Почему использовать Aspose OCR для Java?
Aspose OCR поддерживает **более 30 языков** и может обрабатывать **до 120 страниц в минуту** на стандартном процессоре, что делает его одним из самых быстрых Java OCR‑движков. Встроенный PDF‑писатель также предлагает **девять уровней сжатия**, позволяя уменьшать размер больших отсканированных документов до **80 %** без потери точности OCR.

---

## Предварительные требования
- Java 17 (или новее), установленный и настроенный.  
- JAR‑файл Aspose OCR for Java, добавленный в classpath вашего проекта.  
- Отсканированный файл изображения (PNG, JPEG или TIFF), который вы хотите преобразовать в поисковый PDF.  

---

## Как Aspose OCR создает поисковый PDF?
Загрузите исходное изображение, включите режим searchable‑PDF, задайте желаемый уровень сжатия, выберите язык OCR и укажите движку сохранить результат в виде PDF. API выполняет всю тяжелую работу: запускает OCR, создает скрытый текстовый слой и записывает окончательный PDF за один проход.

## Конвертация PDF из отсканированного изображения с помощью Aspose OCR

**Aspose OCR engine** — это основной компонент, который читает изображения, выполняет оптическое распознавание символов и генерирует вывод в различных форматах.  

Следующие шаги иллюстрируют процесс конвертации:

- Вызовите `setCreateSearchablePdf(true)`, чтобы указать движку встраивание скрытого текстового слоя.  
- Используйте `setCompressionLevel(9)`, чтобы получить **high compression PDF** вывод, значительно уменьшающий размер файла.  
- Укажите `RecognitionLanguage.ENGLISH` (или другой язык), чтобы **set OCR language** для оптимальной точности.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Почему это работает:**  
- `setCreateSearchablePdf(true)` сообщает Aspose о необходимости создания скрытого текстового слоя, удовлетворяя требование **embed text layer PDF**.  
- `setCompressionLevel(9)` переводит файл в диапазон **high compression PDF**, уменьшая окончательный размер без потери точности OCR.  
- Аргумент `RecognitionLanguage.ENGLISH` демонстрирует, как **set OCR language**; вы можете заменить его на французский, немецкий и т.д., в зависимости от исходного материала.

---

## Настройки PDF с высоким уровнем сжатия

**CompressionLevel** управляет степенью сжатия, с которой PDF‑писатель уменьшает размер вложенных изображений и потоков. Значения варьируются от 0 (без сжатия) до 9 (максимальное сжатие).  

Когда вы задаёте уровень 9, Aspose OCR применяет **lossless PNG compression** для страниц с большим количеством текста и **high‑quality JPEG** для фотоматериалов, часто уменьшая размер файла на **70‑80 %** по сравнению с несжатым выводом.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Несколько советов:

- **Use lossless image formats** (PNG) для сканов, содержащих много текста; JPEG лучше подходит для фотографий.  
- **Enable font subsetting**, если вы встраиваете пользовательские шрифты — Aspose делает это автоматически при создании поискового PDF.  
- **Test the output size** после каждого изменения; иногда сжатие уровня 8 дает снижение размера на 10 % при незначительной потере качества по сравнению с уровнем 9.

---

## Встраивание текстового слоя PDF для возможности поиска

Если вы пропустите вызов `setCreateSearchablePdf(true)`, полученный файл будет выглядеть нормально, но вы не сможете искать его содержимое. Скрытый текстовый слой создаётся путём сопоставления каждого распознанного символа с его положением на странице.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**На что обратить внимание:**  

- **Mixed‑language documents** — возможно, потребуется выполнить OCR дважды, по одному разу для каждого языка, а затем объединить текстовые слои.  
- **Complex layouts** (tables, multi‑column) — Aspose справляется неплохо, но проверьте результат в PDF‑просмотрщике, который отображает скрытый текст (например, режим «Edit PDF» в Adobe Acrobat).

---

## Установка языка OCR для точного распознавания

**RecognitionLanguage** — это перечисление, которое указывает OCR‑движку, какой набор символов ожидать, значительно повышая точность для нелатинских скриптов.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Когда менять язык:**  

- Документы содержат **non‑Latin scripts** (Cyrillic, Arabic) — переключитесь на соответствующий `RecognitionLanguage`.  
- Страницы с несколькими языками — вы можете вызвать `recognizeImageAndSave` дважды, каждый раз с другим языком, а затем объединить PDF‑файлы.

## Запуск полного примера

Ниже представлен полный готовый к запуску пример. Замените пути‑заполнители реальными расположениями файлов, убедитесь, что JAR‑файл Aspose OCR находится в вашем classpath, и выполните программу.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Expected output:** При запуске программы консоль выводит:

```
Searchable PDF created.
```

Откройте `searchable.pdf` в любом PDF‑просмотрщике, попробуйте выделить текст, и вы увидите работу невидимого слоя. Вы успешно **create searchable pdf** из отсканированного изображения.

## Распространённые проблемы и решения

- **Memory‑out‑of‑bounds on large files** — включите режим потоковой обработки, вызвав `OcrEngine.setUseStream(true)`.  
- **Incorrect language detection** — явно задайте `RecognitionLanguage` вместо автодетекции.  
- **Blurry scans** — предварительно обработайте изображения с помощью Aspose Imaging, чтобы увеличить контраст перед OCR.

## Часто задаваемые вопросы

**Q: Могу ли я пакетно обрабатывать всю папку изображений?**  
A: Да. Пройдитесь по файлам, вызовите одинаковую конфигурацию OCR для каждого и объедините полученные PDF с помощью `PdfDocument.merge()`.

**Q: Поддерживает ли Aspose OCR прямой ввод PDF?**  
A: Да. Используйте `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` и установите `setCreateSearchablePdf(true)`.

**Q: Как работать с PDF, защищёнными паролем?**  
A: Перед вызовом метода OCR передайте пароль в `OcrEngine.setPassword("yourPassword")`.

**Q: Какой максимальный размер файла может обрабатывать Aspose OCR?**  
A: Движок может обрабатывать PDF до **2 GB**, если включён режим потоковой обработки, ограниченный только доступной оперативной памятью.

**Q: Требуется ли коммерческая лицензия для использования в продакшене?**  
A: Да. Пробная лицензия подходит для оценки, но полная лицензия удаляет водяные знаки оценки и открывает все функции.
