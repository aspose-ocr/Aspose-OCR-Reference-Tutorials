# 검색 가능한 PDF 만들기 – 완전 프로그래밍 튜토리얼

스캔한 이미지에서 **검색 가능한 PDF** 파일을 만들어야 했지만 어디서 시작해야 할지 몰랐던 적이 있나요? 당신만 그런 것이 아닙니다. 문서가 많은 작업 흐름에서는 이미지만 포함된 일반 PDF가 검색 및 인덱싱에 있어 막다른 길이 됩니다.

좋은 소식은 Aspose OCR을 사용하면 **스캔 이미지 PDF**를 몇 줄의 Java 코드만으로 완전한 검색 가능한 문서로 **변환**할 수 있다는 것입니다. 이 튜토리얼에서는 OCR 엔진 초기화, 고압축 PDF 설정 구성, 숨겨진 텍스트 레이어 삽입, 그리고 적절한 OCR 언어 선택까지 모든 단계를 안내합니다.

이 가이드를 끝까지 따라가면 검색 가능한 PDF를 생성하는 실행 가능한 프로그램을 얻게 되며, 이를 어떤 검색 엔진이나 문서 관리 시스템에든 문제 없이 넣을 수 있습니다.

## 빠른 답변
- **“searchable PDF”가 무엇을 의미하나요?** 시각 이미지 레이어와 OCR로 생성된 보이지 않는 텍스트 레이어를 결합합니다.  
- **변환을 담당하는 라이브러리는?** Aspose OCR for Java.  
- **파일 크기를 작게 유지하려면?** 고압축 PDF를 위해 `setCompressionLevel(9)`를 사용합니다.  
- **비영어 문서도 처리할 수 있나요?** 예—적절한 `RecognitionLanguage` 열거형 값을 설정하면 됩니다.  
- **프로덕션에 라이선스가 필요합니까?** 비시험용으로는 상업용 Aspose OCR 라이선스가 필요합니다.

## 검색 가능한 PDF란?
검색 가능한 PDF는 원본 스캔 이미지와 OCR에 의해 생성된 보이지 않는 기계가 읽을 수 있는 텍스트 레이어를 모두 포함하는 PDF입니다. 이 이중 레이어 설계 덕분에 사용자는 텍스트를 선택하고 복사하며 인덱싱할 수 있지만, 여전히 원본 페이지의 모습을 볼 수 있습니다.

## Java용 Aspose OCR을 사용하는 이유
Aspose OCR은 **30개 이상의 언어**를 지원하며 표준 CPU에서 **분당 최대 120페이지**까지 처리할 수 있어 가장 빠른 Java OCR 엔진 중 하나입니다. 내장된 PDF 라이터는 **9단계 압축**을 제공하여 OCR 정확도를 잃지 않으면서 대용량 스캔 문서를 **최대 80 %**까지 축소할 수 있습니다.

## 전제 조건
- Java 17(또는 그 이후 버전)이 설치되고 구성되어 있어야 합니다.  
- Aspose OCR for Java JAR가 프로젝트의 클래스패스에 추가되어 있어야 합니다.  
- 검색 가능한 PDF로 변환하려는 스캔 이미지 파일(PNG, JPEG 또는 TIFF).

## Aspose OCR은 검색 가능한 PDF를 어떻게 생성하나요?
소스 이미지를 로드하고, searchable‑PDF 모드를 활성화하며, 원하는 압축 레벨을 설정하고, OCR 언어를 선택한 뒤 엔진에 결과를 PDF로 저장하도록 지시합니다. API가 무거운 작업을 처리하여 OCR을 실행하고 숨겨진 텍스트 레이어를 생성한 뒤 한 번에 최종 PDF를 작성합니다.

## Aspose OCR을 사용하여 스캔 이미지 PDF 변환
**Aspose OCR 엔진**은 이미지를 읽고 광학 문자 인식을 수행하며 다양한 형식으로 출력물을 생성하는 핵심 구성 요소입니다.  

다음 단계는 변환 흐름을 보여줍니다:

- 엔진이 숨겨진 텍스트 레이어를 삽입하도록 `setCreateSearchablePdf(true)`를 호출합니다.  
- 파일 크기를 크게 줄이기 위해 `setCompressionLevel(9)`를 사용하여 **고압축 PDF** 출력을 얻습니다.  
- 최적의 정확도를 위해 `RecognitionLanguage.ENGLISH`(또는 다른 언어)를 지정하여 **OCR 언어를 설정**합니다.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**왜 이렇게 작동하나요:**  
- `setCreateSearchablePdf(true)`는 Aspose에게 숨겨진 텍스트 레이어를 생성하도록 지시하여 **텍스트 레이어 삽입 PDF** 요구 사항을 충족합니다.  
- `setCompressionLevel(9)`는 파일을 **고압축 PDF** 범위로 밀어 최종 크기를 OCR 정확도를 손상시키지 않고 축소합니다.  
- `RecognitionLanguage.ENGLISH` 인자는 **OCR 언어를 설정**하는 방법을 보여주며, 소스 자료에 따라 프랑스어, 독일어 등으로 교체할 수 있습니다.

## 고압축 PDF 설정
**CompressionLevel**은 PDF 라이터가 삽입된 이미지와 스트림의 크기를 얼마나 적극적으로 줄일지를 제어합니다. 값은 0 (압축 없음)부터 9 (최대 압축)까지입니다.  

레벨을 9로 설정하면 Aspose OCR은 텍스트가 많은 페이지에 **무손실 PNG 압축**을, 사진 콘텐츠에는 **고품질 JPEG**를 적용하여 비압축 출력에 비해 파일 크기를 **70‑80 %** 정도 줄이는 경우가 많습니다.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

몇 가지 팁:
- 텍스트가 많은 스캔에는 **무손실 이미지 포맷**(PNG)을 사용하고, 사진에는 JPEG가 더 좋습니다.  
- 사용자 정의 폰트를 삽입하는 경우 **폰트 서브세팅**을 활성화하세요—검색 가능한 PDF를 만들 때 Aspose가 자동으로 수행합니다.  
- 각 변경 후 **출력 크기를 테스트**하세요; 때때로 레벨‑8 압축이 레벨‑9에 비해 품질 손실이 거의 없으면서 10 % 정도 크기를 줄일 수 있습니다.

## 검색 가능성을 위한 텍스트 레이어 PDF 삽입
`setCreateSearchablePdf(true)` 호출을 생략하면 결과 파일은 정상적으로 보이지만 내용 검색이 불가능합니다. 숨겨진 텍스트 레이어는 인식된 각 문자를 페이지상의 위치에 매핑하여 생성됩니다.

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**주의할 점:**  
- **혼합 언어 문서** – 언어당 OCR을 두 번 실행하고 텍스트 레이어를 병합해야 할 수 있습니다.  
- **복잡한 레이아웃**(표, 다중 컬럼) – Aspose가 꽤 잘 처리하지만, 숨겨진 텍스트를 표시하는 PDF 뷰어(예: Adobe Acrobat의 “Edit PDF” 모드)로 결과를 다시 확인하세요.

## 정확한 인식을 위한 OCR 언어 설정
**RecognitionLanguage**는 OCR 엔진에 어떤 문자 집합을 기대할지 알려주는 열거형으로, 비라틴 스크립트에 대한 정확도를 크게 향상시킵니다.

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**언어를 변경해야 할 때:**  
- 문서에 **비라틴 스크립트**(키릴 문자, 아라비아어 등)가 포함된 경우 적절한 `RecognitionLanguage`로 전환합니다.  
- 혼합 언어 페이지 – `recognizeImageAndSave`를 두 번 호출하고 각각 다른 언어를 지정한 뒤 PDF를 병합할 수 있습니다.

## 전체 예제 실행
아래는 완전한 실행 가능한 프로그램입니다. 자리표시자 경로를 실제 파일 위치로 교체하고, Aspose OCR JAR가 클래스패스에 포함되어 있는지 확인한 뒤 실행하세요.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**예상 출력:** 프로그램을 실행하면 콘솔에 다음이 출력됩니다:

```
Searchable PDF created.
```

`searchable.pdf`를 어떤 PDF 뷰어에서 열고 텍스트 선택을 시도하면 보이지 않는 레이어가 작동하는 것을 확인할 수 있습니다. 스캔 이미지에서 **검색 가능한 PDF를 성공적으로 생성**했습니다.

## 일반적인 문제와 해결책
- **대용량 파일에서 메모리 초과** – `OcrEngine.setUseStream(true)`를 호출하여 스트리밍 모드를 활성화합니다.  
- **잘못된 언어 감지** – 자동 감지에 의존하지 말고 `RecognitionLanguage`를 명시적으로 설정합니다.  
- **흐릿한 스캔** – OCR 전에 Aspose Imaging을 사용해 이미지를 전처리하고 대비를 높입니다.

## 자주 묻는 질문

**Q: 전체 이미지 폴더를 일괄 처리할 수 있나요?**  
A: 예. 파일들을 순회하면서 동일한 OCR 구성을 적용하고, `PdfDocument.merge()`를 사용해 결과 PDF를 연결하면 됩니다.

**Q: Aspose OCR이 PDF 입력을 직접 지원하나요?**  
A: 지원합니다. `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)`를 사용하고 `setCreateSearchablePdf(true)`를 설정하면 됩니다.

**Q: 비밀번호로 보호된 PDF를 어떻게 처리하나요?**  
A: OCR 메서드를 호출하기 전에 `OcrEngine.setPassword("yourPassword")`에 비밀번호를 전달합니다.

**Q: Aspose OCR이 처리할 수 있는 최대 파일 크기는 얼마인가요?**  
A: 스트리밍이 활성화된 경우 엔진은 **2 GB**까지의 PDF를 처리할 수 있으며, 이는 사용 가능한 RAM에 의해 제한됩니다.

**Q: 프로덕션 사용에 상업용 라이선스가 필요합니까?**  
A: 예. 평가용으로는 체험 라이선스로 충분하지만, 전체 라이선스를 사용하면 평가 워터마크가 제거되고 모든 기능을 사용할 수 있습니다.

## 결론

Aspose OCR을 사용하여 **검색 가능한 PDF** 파일을 만들기 위해 필요한 모든 내용을 다루었습니다:

- OCR 엔진 초기화.  
- PNG/JPEG를 `recognizeImageAndSave`에 전달하여 **스캔 이미지 PDF 변환**.  
- `setCreateSearchablePdf(true)`를 사용하여 **텍스트 레이어 PDF 삽입**.  
- `setCompressionLevel(9)`를 적용하여 **고압축 PDF**를 만들고 가볍게 유지합니다.  
- 최적의 정확도를 위해 적절한 `RecognitionLanguage`를 선택하여 **OCR 언어 설정**.

여기서부터는 배치 처리, 다양한 언어 실험, 혹은 여러 스캔 페이지를 하나의 검색 가능한 PDF로 결합하는 등 다양한 시도를 할 수 있습니다. 동일한 패턴이 스페인어나 일본어와 같은 다른 언어에도 적용되며, `RecognitionLanguage` 열거형만 교체하면 됩니다.
