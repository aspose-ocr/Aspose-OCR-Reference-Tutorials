# Aspose.OCR for .NET을 사용하여 이미지에서 텍스트 추출하는 방법

## 소개

이미지 파일에서 **텍스트를 추출**해야 하고 빠르고 신뢰할 수 있다면, Aspose.OCR for .NET은 견고한 선택입니다. 이 튜토리얼에서는 라이브러리 설정, 인식 옵션 구성, 전체 OCR 결과(다국어 출력 및 레이아웃 데이터 포함) 가져오는 과정을 단계별로 안내합니다. 마지막까지 읽으면 **이미지에서 텍스트를 추출**하는 방법, 다양한 언어로 **이미지에서 텍스트를 인식**하는 방법, 그리고 심층 탐색을 위한 공식 Aspose OCR 문서를 찾는 위치를 알게 됩니다.

## 빠른 답변
- **“이미지에서 텍스트 추출”이 의미하는 바는?** OCR 엔진이 이미지 내부에서 감지한 읽을 수 있는 문자들을 가져오는 것을 의미합니다.  
- **어떤 라이브러리를 사용해야 하나요?** Aspose.OCR for .NET은 직관적인 API, 다국어 지원, 그리고 즉시 체험할 수 있는 **aspose ocr trial**을 제공합니다.  
- **라이선스가 필요합니까?** 무료 체험판을 사용할 수 있으며, 실제 운영에서는 라이선스가 필요합니다.  
- **지원되는 .NET 버전은 무엇인가요?** .NET Framework 4.5 이상 및 .NET Core/5/6 이상을 지원합니다.  
- **OCR 정확도를 향상시킬 수 있나요?** 네—올바른 언어를 선택하고 DPI를 조정하면 **OCR 정확도를 향상**시킬 수 있습니다.

## “이미지에서 텍스트 추출”이 의미하는 바는?

이미지에서 텍스트를 추출한다는 것은 비트맵 내부에 시각적으로 표시된 문자를 편집 가능하고 검색 가능한 유니코드 문자열로 변환하는 것을 의미합니다. 이 과정은 픽셀 패턴을 분석하고 글리프를 식별해 단어와 문장으로 조합하는 OCR 엔진에 의존합니다. Aspose.OCR 엔진은 50개 이상의 언어를 지원하며 일반 텍스트, JSON, XML 형태로 출력할 수 있어 결과를 후속 워크플로에 쉽게 전달할 수 있습니다.

## 이 작업에 Aspose.OCR을 사용하는 이유

Aspose.OCR은 **50개 이상의 언어**를 지원하고 전체 파일을 메모리에 로드하지 않고도 **수백 페이지에 이르는 이미지 배치를** 처리할 수 있어 많은 오픈소스 대안에 비해 최대 **3배 빠른** 성능을 제공합니다. API는 몇 줄의 코드만 필요하며, 내장 전처리(이진화, 노이즈 제거) 기능을 통해 노이즈가 많은 스캔에서도 **OCR 정확도를 최대 30 %** 향상시킬 수 있습니다.

## Aspose.OCR은 OCR 정확도를 어떻게 향상시키나요?

Aspose.OCR은 인식 전에 이진화, 기울기 보정, 노이즈 감소와 같은 이미지 전처리 단계를 자동으로 적용하여 OCR 정확도를 향상시킵니다. 또한 DPI(인치당 점)를 150~300 사이의 값으로 수동 설정할 수 있으며, 높은 DPI는 세부 정보를 보존하고 낮은 DPI는 처리 속도를 높입니다. 혼합 스크립트가 포함된 문서의 경우 다국어 모드를 활성화하면 엔진이 각 영역에 가장 적합한 언어 모델을 선택해 정밀도를 더욱 높입니다.

## Aspose.OCR에서 OCR 언어를 설정하는 방법

OCR 언어는 `engine.Recognize()`를 호출하기 전에 `settings.Language` 속성에 원하는 ISO‑639‑1 코드를 할당하여 설정합니다. 예를 들어 영어는 `"en"`, 프랑스어는 `"fr"`를 사용하고, 영어와 스페인어를 동시에 감지하려면 `"en,es"`와 같이 쉼표로 구분된 목록을 지정합니다. 올바른 언어를 선택하면 불필요한 언어 모델 검사를 없애 평균 **15 %** 정도 처리 시간을 단축할 수 있습니다.

## Aspose OCR 라이선스를 얻는 방법

Aspose 스토어에서 영구 라이선스 또는 임시 라이선스를 구매한 후 라이선스 파일(`Aspose.OCR.lic`)을 애플리케이션 루트 폴더에 배치합니다. 런타임에 `License license = new License(); license.SetLicense("Aspose.OCR.lic");` 코드를 사용해 로드합니다. 평가용으로 30일 임시 라이선스를 제공하며, 신용카드 정보 없이 Aspose 포털에서 요청할 수 있습니다.

## 네임스페이스 가져오기

.NET 애플리케이션에서 필요한 네임스페이스를 가져오는 것으로 시작합니다:

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.IO;
using Aspose.OCR;
```

## 단계 1: 문서 디렉터리 설정

처리하려는 이미지가 들어 있는 폴더를 지정합니다:

```csharp
string dataDir = "Your Document Directory";
```

## 단계 2: Aspose.OCR 초기화

OCR 엔진의 인스턴스를 생성합니다:

```csharp
AsposeOcr api = new AsposeOcr();
```

## 단계 3: 이미지 경로 지정

인식하려는 정확한 이미지 파일 경로를 지정합니다:

```csharp
string fullPath = dataDir + "sample.png";
```

## 단계 4: 인식 설정 구성

시나리오에 맞게 설정을 조정합니다—기본 동작이 필요하거나 다국어 텍스트 인식을 위한 언어 선택과 같은 사용자 옵션이 필요할 경우:

```csharp
RecognitionSettings settings = new RecognitionSettings
{
    // Specify your recognition settings here
    // Example: Language = Language.English | Language.Spanish
};
```

## 단계 5: 이미지 인식 수행

OCR 프로세스를 실행하고 결과를 캡처합니다:

```csharp
RecognitionResult result = api.RecognizeImage(fullPath, settings);
```

## 단계 6: 인식 결과 출력

추출된 텍스트, 레이아웃 정보, JSON 표현 및 경고 등을 포함한 전체 인식 출력을 표시합니다:

```csharp
PrintRecognitionResult(result);
```

## 일반적인 문제 및 해결책

| 문제 | 이유 | 해결 방법 |
|-------|--------|-----|
| **텍스트가 반환되지 않음** | 이미지 경로가 잘못되었거나 지원되지 않는 형식 | `fullPath`를 확인하고 이미지가 지원되는 유형(PNG, JPEG, BMP)인지 확인하세요. |
| **잘못된 언어 감지** | 기본 언어 설정이 이미지와 일치하지 않을 수 있음 | 정확도를 높이려면 `settings.Language`를 적절한 언어(들)로 설정하세요. |
| **대형 이미지에서 성능 저하** | 고해상도 이미지가 처리 시간을 늘림 | 인식 전에 이미지를 리사이즈하거나 `settings.Dpi`를 낮은 값으로 조정하세요. |
| **스캔 문서에서 낮은 정확도** | 스캔된 이미지에 노이즈가 포함될 수 있음 | 이진화와 같은 전처리 단계를 사용하거나 `settings.Preprocess = true`를 적용하여 **OCR 정확도를 향상**시킵니다. |
| **스캔된 PDF 처리 필요** | PDF를 먼저 이미지로 변환해야 함 | PDF‑to‑image 라이브러리를 사용해 스캔된 페이지를 PNG/JPEG로 **변환**한 뒤 각 이미지를 Aspose.OCR에 전달합니다. |
