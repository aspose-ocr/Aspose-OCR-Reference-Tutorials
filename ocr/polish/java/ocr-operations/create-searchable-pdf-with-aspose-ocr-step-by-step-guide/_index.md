# Utwórz przeszukiwalny PDF – kompletny samouczek programistyczny

Czy kiedykolwiek potrzebowałeś **utworzyć przeszukiwalny PDF** z zeskanowanych obrazów, ale nie wiedziałeś od czego zacząć? Nie jesteś sam. W wielu procesach opartych na dokumentach, zwykły PDF zawierający tylko obrazy jest ślepą uliczką dla wyszukiwania i indeksowania.  

Dobrą wiadomością jest to, że dzięki Aspose OCR możesz **przekształcić zeskanowany PDF** w w pełni przeszukiwalny dokument w zaledwie kilku linijkach Javy. Ten samouczek przeprowadzi Cię przez każdy krok — inicjalizację silnika OCR, konfigurowanie ustawień PDF o wysokiej kompresji, osadzenie ukrytej warstwy tekstowej oraz wybór odpowiedniego języka OCR.

Po zakończeniu tego przewodnika będziesz mieć uruchamialny program, który generuje przeszukiwalny PDF, plik, który możesz bez problemu wstawić do dowolnej wyszukiwarki lub systemu zarządzania dokumentami.

---

## Szybkie odpowiedzi
- **Co oznacza „przeszukiwalny PDF”?** Łączy warstwę wizualnego obrazu z niewidoczną warstwą tekstową wygenerowaną przez OCR.  
- **Która biblioteka obsługuje konwersję?** Aspose OCR for Java.  
- **Jak mogę utrzymać mały rozmiar pliku?** Użyj `setCompressionLevel(9)` dla PDF o wysokiej kompresji.  
- **Czy mogę przetwarzać dokumenty nie‑angielskie?** Tak — ustaw odpowiednią wartość wyliczenia `RecognitionLanguage`.  
- **Czy potrzebna jest licencja do produkcji?** Wymagana jest komercyjna licencja Aspose OCR do użytku nie‑testowego.

## Co to jest przeszukiwalny PDF?
Przeszukiwalny PDF to plik PDF, który zawiera zarówno oryginalny zeskanowany obraz, jak i niewidoczną, maszynowo czytelną warstwę tekstową wygenerowaną przez OCR. Ten dwuwarstwowy projekt pozwala użytkownikom zaznaczać, kopiować i indeksować tekst, jednocześnie zachowując wygląd oryginalnej strony.

## Dlaczego używać Aspose OCR dla Javy?
Aspose OCR obsługuje **ponad 30 języków** i może przetwarzać **do 120 stron na minutę** na standardowym procesorze, co czyni go jednym z najszybszych silników OCR w Javie. Wbudowany zapis PDF oferuje **dziewięć poziomów kompresji**, umożliwiając zmniejszenie dużych zeskanowanych dokumentów nawet o **80 %** bez utraty dokładności OCR.

## Wymagania wstępne
- Java 17 (lub nowsza) zainstalowana i skonfigurowana.  
- Dodany do classpath projektu plik JAR Aspose OCR for Java.  
- Zeskanowany plik obrazu (PNG, JPEG lub TIFF), który chcesz przekształcić w przeszukiwalny PDF.  

## Jak Aspose OCR tworzy przeszukiwalny PDF?
Wczytaj obraz źródłowy, włącz tryb searchable‑PDF, ustaw żądany poziom kompresji, wybierz język OCR i poinstruuj silnik, aby zapisał wynik jako PDF. API zajmuje się ciężką pracą: wykonuje OCR, tworzy ukrytą warstwę tekstową i zapisuje ostateczny PDF w jednym przebiegu.

## Konwersja zeskanowanego PDF obrazu przy użyciu Aspose OCR

**Silnik Aspose OCR** jest podstawowym komponentem, który odczytuje obrazy, wykonuje rozpoznawanie znaków optycznych i generuje wyjście w różnych formatach.  

Poniższe kroki ilustrują przepływ konwersji:

- Wywołaj `setCreateSearchablePdf(true)`, aby poinstruować silnik o osadzeniu ukrytej warstwy tekstowej.  
- Użyj `setCompressionLevel(9)`, aby uzyskać **PDF o wysokiej kompresji**, znacznie zmniejszając rozmiar pliku.  
- Określ `RecognitionLanguage.ENGLISH` (lub inny język), aby **ustawić język OCR** dla optymalnej dokładności.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Dlaczego to działa:**  
- `setCreateSearchablePdf(true)` instruuje Aspose, aby wygenerował ukrytą warstwę tekstową, spełniając wymóg **embed text layer PDF**.  
- `setCompressionLevel(9)` wprowadza plik w zakres **high compression PDF**, zmniejszając ostateczny rozmiar bez utraty dokładności OCR.  
- Argument `RecognitionLanguage.ENGLISH` pokazuje, jak **ustawić język OCR**; możesz go zamienić na francuski, niemiecki itp., w zależności od materiału źródłowego.

## Ustawienia PDF o wysokiej kompresji

**CompressionLevel** kontroluje, jak agresywnie zapis PDF zmniejsza rozmiar osadzonych obrazów i strumieni. Wartości mieszczą się w przedziale od 0 (brak kompresji) do 9 (maksymalna kompresja).  

Gdy ustawisz poziom na 9, Aspose OCR stosuje **bezstratną kompresję PNG** dla stron z dużą ilością tekstu oraz **wysokiej jakości JPEG** dla treści fotograficznych, często redukując rozmiar pliku o **70‑80 %** w porównaniu z niekompresowanym wyjściem.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Kilka wskazówek:
- **Używaj bezstratnych formatów obrazu** (PNG) dla skanów z dużą ilością tekstu; JPEG jest lepszy dla zdjęć.  
- **Włącz podzestaw czcionek**, jeśli osadzasz własne czcionki — Aspose robi to automatycznie przy tworzeniu przeszukiwalnego PDF.  
- **Testuj rozmiar wyjścia** po każdej zmianie; czasami kompresja poziomu 8 daje 10 % redukcję rozmiaru przy znikomej utracie jakości w porównaniu z poziomem 9.

## Osadź warstwę tekstową PDF dla możliwości wyszukiwania

Jeśli pominiesz wywołanie `setCreateSearchablePdf(true)`, wynikowy plik będzie wyglądał dobrze, ale nie będzie można przeszukiwać jego zawartości. Ukryta warstwa tekstowa jest tworzona przez mapowanie każdego rozpoznanego znaku na jego położenie na stronie.

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Na co zwrócić uwagę:**
- **Dokumenty wielojęzyczne** — może być konieczne dwukrotne uruchomienie OCR, raz dla każdego języka, a następnie połączenie warstw tekstowych.  
- **Złożone układy** (tabele, wielokolumnowe) — Aspose radzi sobie przyzwoicie, ale sprawdź wynik w przeglądarce PDF, która wyświetla ukryty tekst (np. tryb „Edit PDF” w Adobe Acrobat).

## Ustaw język OCR dla dokładnego rozpoznawania

**RecognitionLanguage** to wyliczenie, które informuje silnik OCR, jakiego zestawu znaków się spodziewać, znacznie poprawiając dokładność dla skryptów nie‑łacińskich.

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Kiedy zmienić język:**
- Dokumenty zawierają **skrypty nie‑łacińskie** (cyrylica, arabski) — przełącz na odpowiedni `RecognitionLanguage`.  
- Strony wielojęzyczne — możesz wywołać `recognizeImageAndSave` dwukrotnie, za każdym razem z innym językiem, a następnie połączyć PDF‑y.

## Uruchamianie pełnego przykładu

Poniżej znajduje się pełny, gotowy do uruchomienia program. Zamień ścieżki zastępcze na rzeczywiste lokalizacje plików, upewnij się, że JAR Aspose OCR znajduje się w classpath i uruchom program.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Oczekiwany wynik:** Po uruchomieniu programu konsola wyświetli:

```
Searchable PDF created.
```

Otwórz `searchable.pdf` w dowolnej przeglądarce PDF, spróbuj zaznaczyć tekst i zobaczysz działanie niewidzialnej warstwy. Pomyślnie **utworzyłeś przeszukiwalny PDF** ze zeskanowanego obrazu.

## Typowe problemy i rozwiązania

- **Memory‑out‑of‑bounds przy dużych plikach** — włącz tryb strumieniowy, wywołując `OcrEngine.setUseStream(true)`.  
- **Nieprawidłowe wykrywanie języka** — jawnie ustaw `RecognitionLanguage` zamiast polegać na automatycznym wykrywaniu.  
- **Rozmyte skany** — wstępnie przetwórz obrazy przy użyciu Aspose Imaging, aby zwiększyć kontrast przed OCR.

## Najczęściej zadawane pytania

**Q: Czy mogę przetwarzać wsadowo cały folder obrazów?**  
A: Tak. Iteruj po plikach, wywołuj tę samą konfigurację OCR dla każdego i łącz wynikowe PDF‑y przy użyciu `PdfDocument.merge()`.

**Q: Czy Aspose OCR obsługuje bezpośrednio wejście PDF?**  
A: Tak. Użyj `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` i ustaw `setCreateSearchablePdf(true)`.

**Q: Jak obsłużyć PDF‑y chronione hasłem?**  
A: Przekaż hasło do `OcrEngine.setPassword("yourPassword")` przed wywołaniem metody OCR.

**Q: Jaki jest maksymalny rozmiar pliku, który Aspose OCR może obsłużyć?**  
A: Silnik może przetwarzać PDF‑y do **2 GB**, gdy włączony jest tryb strumieniowy, ograniczony jedynie dostępnej pamięcią RAM.

**Q: Czy wymagana jest komercyjna licencja do użytku produkcyjnego?**  
A: Tak. Licencja próbna działa w celach oceny, ale pełna licencja usuwa znaki wodne oceny i odblokowuje wszystkie funkcje.

## Zakończenie

Omówiliśmy wszystko, co potrzebne, aby **utworzyć przeszukiwalny PDF** przy użyciu Aspose OCR:
- Zainicjalizuj silnik OCR.  
- **Konwertuj zeskanowany PDF obrazu** podając PNG/JPEG do `recognizeImageAndSave`.  
- Użyj `setCreateSearchablePdf(true)`, aby **osadzić warstwę tekstową PDF**.  
- Zastosuj `setCompressionLevel(9)` dla **PDF o wysokiej kompresji**, który pozostaje lekki.  
- Wybierz odpowiedni `RecognitionLanguage`, aby **ustawić język OCR** dla maksymalnej dokładności.

Od tego momentu możesz eksperymentować z przetwarzaniem wsadowym, różnymi językami lub nawet łączyć wiele zeskanowanych stron w jeden przeszukiwalny PDF. Ten sam schemat działa dla innych języków, takich jak hiszpański czy japoński — po prostu zamień wartość wyliczenia `RecognitionLanguage`.
