# 建立可搜尋 PDF – 完整程式教學

是否曾需要從掃描圖像**建立可搜尋 PDF**檔案，但不知從何開始？你並不孤單。在許多文件密集的工作流程中，僅含圖像的 PDF 對搜尋與索引而言是死路。  

好消息是，使用 Aspose OCR，你只需幾行 Java 程式碼即可**將掃描圖像 PDF 轉換**為完整可搜尋的文件。本教學將逐步說明每個步驟——初始化 OCR 引擎、設定高壓縮 PDF、嵌入隱藏文字層，甚至選擇正確的 OCR 語言。  

完成本指南後，你將擁有一個可執行的程式，產生可搜尋的 PDF，這個檔案可直接投入任何搜尋引擎或文件管理系統，毫無障礙。

---

## 快速回答
- **What does “searchable PDF” mean?** 它結合了視覺圖像層與由 OCR 產生的隱形文字層。  
- **Which library handles the conversion?** Aspose OCR for Java。  
- **How can I keep the file size small?** 使用 `setCompressionLevel(9)` 以獲得高壓縮 PDF。  
- **Can I process non‑English documents?** 是的——設定相應的 `RecognitionLanguage` 列舉值。  
- **Do I need a license for production?** 在非試用情況下，需要商業版 Aspose OCR 授權。

## 什麼是可搜尋 PDF？
可搜尋 PDF 是同時包含原始掃描圖像與由 OCR 產生的隱形、機器可讀文字層的 PDF。這種雙層設計使用戶能夠選取、複製及索引文字，同時仍保留原始頁面的外觀。

## 為何使用 Aspose OCR for Java？
Aspose OCR 支援**超過 30 種語言**，且在標準 CPU 上每分鐘可處理**最高 120 頁**，使其成為最快的 Java OCR 引擎之一。其內建 PDF 寫入器亦提供**九層壓縮**，讓你在不失去 OCR 準確度的情況下，將大型掃描文件縮減至**最高 80 %**。

## 前置條件
- 已安裝並設定 Java 17（或更新版本）。  
- 已將 Aspose OCR for Java JAR 加入專案的 classpath。  
- 一個欲轉換為可搜尋 PDF 的掃描圖像檔（PNG、JPEG 或 TIFF）。

## Aspose OCR 如何建立可搜尋 PDF？
載入來源圖像，啟用 searchable‑PDF 模式，設定所需的壓縮等級，選擇 OCR 語言，並指示引擎將結果儲存為 PDF。API 會處理繁重工作：執行 OCR、建立隱藏文字層，並一次性寫入最終 PDF。

## 使用 Aspose OCR 轉換掃描圖像 PDF

**Aspose OCR engine**是讀取圖像、執行光學字符辨識，並產生多種格式輸出的核心元件。  

以下步驟說明轉換流程：

- 呼叫 `setCreateSearchablePdf(true)` 以指示引擎嵌入隱藏文字層。  
- 使用 `setCompressionLevel(9)` 以產生**高壓縮 PDF**輸出，顯著減少檔案大小。  
- 指定 `RecognitionLanguage.ENGLISH`（或其他語言）以**設定 OCR 語言**，達到最佳準確度。

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Why this works:**  
- `setCreateSearchablePdf(true)` 告訴 Aspose 產生隱藏文字層，滿足 **embed text layer PDF** 的需求。  
- `setCompressionLevel(9)` 將檔案推入 **high compression PDF** 範圍，縮小最終大小而不犧牲 OCR 準確度。  
- `RecognitionLanguage.ENGLISH` 參數示範了如何**設定 OCR 語言**；你可以依據來源材料改為法語、德語等。

## 高壓縮 PDF 設定

**CompressionLevel** 控制 PDF 寫入器對嵌入圖像與資料流的壓縮力度。值範圍從 0（無壓縮）到 9（最大壓縮）。  

當將等級設定為 9 時，Aspose OCR 會對文字密集的頁面使用**無損 PNG 壓縮**，對照片內容使用**高品質 JPEG**，通常可比未壓縮輸出減少 **70‑80 %** 的檔案大小。

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

以下是幾個提示：

- **使用無損圖像格式**（PNG）於文字密集的掃描；照片則較適合 JPEG。  
- **啟用字型子集化**，若嵌入自訂字型——在建立可搜尋 PDF 時，Aspose 會自動執行此動作。  
- **測試輸出大小**於每次變更後；有時等級 8 的壓縮可提供 10 % 的大小縮減，且相較於等級 9，品質損失可忽略不計。

## 嵌入文字層 PDF 以提升可搜尋性

如果跳過 `setCreateSearchablePdf(true)` 呼叫，產生的檔案外觀仍然正常，但無法搜尋其內容。隱藏文字層是透過將每個辨識出的字元映射到頁面上的位置而建立的。  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**What to watch out for:**  

- **混合語言文件**——可能需要針對每種語言分別執行 OCR 兩次，然後合併文字層。  
- **複雜版面**（表格、多欄）——Aspose 表現不錯，但請使用能顯示隱藏文字的 PDF 檢視器（例如 Adobe Acrobat 的「編輯 PDF」模式）再次確認輸出。

## 設定 OCR 語言以提升辨識準確度

**RecognitionLanguage** 是一個列舉，用於告訴 OCR 引擎預期的字元集，能顯著提升非拉丁文字的辨識準確度。  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**When to change the language:**  

- 文件包含**非拉丁文字**（西里爾文、阿拉伯文）——切換至相應的 `RecognitionLanguage`。  
- 混合語言頁面——可呼叫 `recognizeImageAndSave` 兩次，每次使用不同語言，然後合併 PDF。

## 執行完整範例

以下為完整、可直接執行的程式。將佔位路徑替換為實際檔案位置，確保 Aspose OCR JAR 已加入 classpath，然後執行。

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**預期輸出：** 執行程式時，主控台會印出：

```
Searchable PDF created.
```

在任何 PDF 檢視器中開啟 `searchable.pdf`，嘗試選取文字，即可看到隱形層的效果。你已成功**create searchable pdf** 從掃描圖像。

## 常見問題與解決方案

- **大型檔案記憶體溢位**——透過呼叫 `OcrEngine.setUseStream(true)` 啟用串流模式。  
- **語言偵測不正確**——明確設定 `RecognitionLanguage`，而非依賴自動偵測。  
- **掃描圖像模糊**——在 OCR 前使用 Aspose Imaging 進行前處理，提高對比度。

## 常見問答

**Q: 我可以批次處理整個資料夾的圖像嗎？**  
A: 是的。遍歷檔案，對每個檔案呼叫相同的 OCR 設定，並使用 `PdfDocument.merge()` 合併產生的 PDF。  

**Q: Aspose OCR 是否直接支援 PDF 輸入？**  
A: 支援。使用 `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` 並設定 `setCreateSearchablePdf(true)`。  

**Q: 我該如何處理受密碼保護的 PDF？**  
A: 在呼叫 OCR 方法前，將密碼傳遞給 `OcrEngine.setPassword("yourPassword")`。  

**Q: Aspose OCR 能處理的最大檔案大小是多少？**  
A: 啟用串流時，該引擎可處理最高 **2 GB** 的 PDF，僅受可用記憶體限制。  

**Q: 生產環境是否需要商業授權？**  
A: 是的。試用授權僅供評估使用，完整授權則會移除評估浮水印並解鎖所有功能。

## 結論

我們已說明使用 Aspose OCR **建立可搜尋 PDF** 所需的全部步驟：

- 初始化 OCR 引擎。  
- **Convert scanned image PDF**：將 PNG/JPEG 輸入 `recognizeImageAndSave`。  
- 使用 `setCreateSearchablePdf(true)` 以**embed text layer PDF**。  
- 套用 `setCompressionLevel(9)` 以產生**high compression PDF**，保持輕量。  
- 選擇適當的 `RecognitionLanguage` 以**set OCR language**，達到最高準確度。  

從此你可以嘗試批次處理、不同語言，或將多頁掃描合併為單一可搜尋 PDF。同樣的模式也適用於其他語言，如西班牙語或日語——只需更換 `RecognitionLanguage` 列舉即可。
