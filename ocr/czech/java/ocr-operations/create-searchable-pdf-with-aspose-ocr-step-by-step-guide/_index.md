# Vytvoření prohledávatelného PDF – kompletní programovací tutoriál

Už jste někdy potřebovali **vytvořit prohledávatelné PDF** soubory ze skenovaných obrázků, ale nevedeli jste, kde začít? Nejste v tom sami. V mnoha pracovních postupech s velkým množstvím dokumentů je obyčejné PDF obsahující jen obrázky slepou uličkou pro vyhledávání a indexaci.  

Dobrou zprávou je, že s Aspose OCR můžete **převést PDF se skenovaným obrázkem** na plně prohledávatelný dokument během několika řádků Java kódu. Tento tutoriál vás provede každým krokem – inicializací OCR enginu, nastavením parametrů pro vysokou kompresi PDF, vložením skryté textové vrstvy a dokonce výběrem správného jazyka OCR.  

Na konci tohoto průvodce budete mít spustitelný program, který vytvoří prohledávatelné PDF, soubor, který můžete bez problémů vložit do jakéhokoli vyhledávače nebo systému pro správu dokumentů.

---

## Rychlé odpovědi
- **Co znamená „prohledávatelné PDF“?** Kombinuje vizuální vrstvu obrázku s neviditelnou textovou vrstvou generovanou OCR.  
- **Která knihovna provádí konverzi?** Aspose OCR pro Java.  
- **Jak mohu udržet velikost souboru malou?** Použijte `setCompressionLevel(9)` pro PDF s vysokou kompresí.  
- **Mohu zpracovávat dokumenty v jiných jazycích než angličtině?** Ano – nastavte odpovídající hodnotu výčtu `RecognitionLanguage`.  
- **Potřebuji licenci pro produkční použití?** Pro ne‑zkušební použití je vyžadována komerční licence Aspose OCR.

## Co je prohledávatelné PDF?
Prohledávatelné PDF je PDF, které obsahuje jak původní skenovaný obrázek, tak neviditelnou, strojově čitelnou textovou vrstvu vytvořenou OCR. Tento dvojvrstvý design umožňuje uživatelům vybrat, kopírovat a indexovat text a přitom stále vidět původní vzhled stránky.

## Proč použít Aspose OCR pro Java?
Aspose OCR podporuje **více než 30 jazyků** a dokáže zpracovat **až 120 stránek za minutu** na standardním procesoru, což z něj činí jeden z nejrychlejších Java OCR enginů. Jeho vestavěný PDF zapisovač také nabízí **devět úrovní komprese**, což vám umožní zmenšit velké skenované dokumenty až o **80 %** bez ztráty přesnosti OCR.

## Požadavky
- Java 17 (nebo novější) nainstalována a nakonfigurována.  
- JAR Aspose OCR pro Java přidán do classpath vašeho projektu.  
- Skenovaný soubor obrázku (PNG, JPEG nebo TIFF), který chcete převést na prohledávatelné PDF.  

## Jak Aspose OCR vytvoří prohledávatelné PDF?
Načtěte zdrojový obrázek, povolte režim searchable‑PDF, nastavte požadovanou úroveň komprese, vyberte jazyk OCR a řekněte enginu, aby výsledek uložil jako PDF. API provádí těžkou práci: spustí OCR, vytvoří skrytou textovou vrstvu a zapíše finální PDF v jednom kroku.

## Převod PDF se skenovaným obrázkem pomocí Aspose OCR

**Aspose OCR engine** je hlavní komponenta, která čte obrázky, provádí optické rozpoznávání znaků a produkuje výstup v různých formátech.  

Následující kroky ilustrují tok konverze:

- Zavolejte `setCreateSearchablePdf(true)`, aby engine vložil skrytou textovou vrstvu.  
- Použijte `setCompressionLevel(9)` pro získání výstupu **PDF s vysokou kompresí**, což dramaticky snižuje velikost souboru.  
- Zadejte `RecognitionLanguage.ENGLISH` (nebo jiný jazyk), aby se **nastavil jazyk OCR** pro optimální přesnost.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Proč to funguje:**  
- `setCreateSearchablePdf(true)` říká Aspose, aby vygeneroval skrytou textovou vrstvu, čímž splňuje požadavek **embed text layer PDF**.  
- `setCompressionLevel(9)` posouvá soubor do rozsahu **high compression PDF**, zmenšuje finální velikost bez ztráty přesnosti OCR.  
- Argument `RecognitionLanguage.ENGLISH` ukazuje, jak **nastavit jazyk OCR**; můžete jej vyměnit za francouzštinu, němčinu atd., v závislosti na vašem zdrojovém materiálu.

## Nastavení vysoké komprese PDF

**CompressionLevel** řídí, jak agresivně PDF zapisovač snižuje velikost vložených obrázků a streamů. Hodnoty se pohybují od 0 (žádná komprese) po 9 (maximální komprese).  

Když nastavíte úroveň na 9, Aspose OCR použije **bezztrátovou PNG kompresi** pro stránky s velkým množstvím textu a **vysoce kvalitní JPEG** pro fotografický obsah, často zmenšuje velikost souboru o **70‑80 %** ve srovnání s nekomprimovaným výstupem.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Několik tipů:
- **Používejte bezztrátové formáty obrázků** (PNG) pro skeny s velkým množstvím textu; JPEG je lepší pro fotografie.  
- **Povolte podmnožinu fontů**, pokud vkládáte vlastní fonty – Aspose to provádí automaticky při vytváření prohledávatelného PDF.  
- **Otestujte velikost výstupu** po každé změně; někdy úroveň 8 komprese poskytne 10 % úsporu velikosti s neznatelnou ztrátou kvality ve srovnání s úrovní 9.

## Vložení textové vrstvy PDF pro vyhledatelnost

Pokud vynecháte volání `setCreateSearchablePdf(true)`, výsledný soubor bude vypadat v pořádku, ale nebudete moci prohledávat jeho obsah. Skrytá textová vrstva je vytvořena mapováním každého rozpoznaného znaku na jeho umístění na stránce.

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Na co si dát pozor:**  
- **Dokumenty s více jazyky** – možná bude potřeba spustit OCR dvakrát, jednou pro každý jazyk, a poté sloučit textové vrstvy.  
- **Komplexní rozvržení** (tabulky, více sloupců) – Aspose odvádí slušnou práci, ale výstup si dvakrát zkontrolujte pomocí PDF prohlížeče, který zobrazuje skrytý text (např. režim „Edit PDF“ v Adobe Acrobat).

## Nastavení jazyka OCR pro přesné rozpoznání

**RecognitionLanguage** je výčet, který říká OCR enginu, jakou znakovou sadu očekávat, což dramaticky zlepšuje přesnost pro ne‑latinské skripty.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Kdy změnit jazyk:**  
- Dokumenty obsahují **ne‑latinské skripty** (cyrilice, arabština) – přepněte na odpovídající `RecognitionLanguage`.  
- Stránky s více jazyky – můžete volat `recognizeImageAndSave` dvakrát, pokaždé s jiným jazykem, a poté sloučit PDF soubory.

## Spuštění kompletního příkladu

Níže je celý, připravený ke spuštění program. Nahraďte zástupné cesty skutečnými umístěními souborů, ujistěte se, že JAR Aspose OCR je ve vašem classpath, a spusťte.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Očekávaný výstup:** Když spustíte program, konzole vypíše:

```
Searchable PDF created.
```

Otevřete `searchable.pdf` v libovolném PDF prohlížeči, zkuste vybrat text a uvidíte skrytou vrstvu v akci. Úspěšně jste **vytvořili prohledávatelné PDF** ze skenovaného obrázku.

## Časté problémy a řešení
- **Memory‑out‑of‑bounds u velkých souborů** – povolte režim streamování voláním `OcrEngine.setUseStream(true)`.  
- **Nesprávná detekce jazyka** – explicitně nastavte `RecognitionLanguage` místo spoléhaní se na automatickou detekci.  
- **Rozmazané skeny** – předzpracujte obrázky pomocí Aspose Imaging ke zvýšení kontrastu před OCR.

## Často kladené otázky
**Q: Mohu dávkově zpracovat celý adresář obrázků?**  
A: Ano. Procházejte soubory, použijte stejnou konfiguraci OCR pro každý a spojte výsledné PDF pomocí `PdfDocument.merge()`.

**Q: Podporuje Aspose OCR přímý vstup PDF?**  
A: Ano. Použijte `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` a nastavte `setCreateSearchablePdf(true)`.

**Q: Jak zacházet s PDF chráněnými heslem?**  
A: Před voláním OCR metody předávejte heslo pomocí `OcrEngine.setPassword("yourPassword")`.

**Q: Jaká je maximální velikost souboru, kterou Aspose OCR dokáže zpracovat?**  
A: Engine může zpracovat PDF až do **2 GB**, pokud je povolen streaming, omezeno pouze dostupnou RAM.

**Q: Je pro produkční použití vyžadována komerční licence?**  
A: Ano. Zkušební licence funguje pro hodnocení, ale plná licence odstraňuje vodoznaky hodnocení a odemyká všechny funkce.

## Závěr
Probrali jsme vše, co potřebujete k **vytvoření prohledávatelných PDF** souborů pomocí Aspose OCR:
- Inicializujte OCR engine.  
- **Převod PDF se skenovaným obrázkem** vložením PNG/JPEG do `recognizeImageAndSave`.  
- Použijte `setCreateSearchablePdf(true)` k **vložením textové vrstvy PDF**.  
- Aplikujte `setCompressionLevel(9)` pro **PDF s vysokou kompresí**, který zůstane lehký.  
- Vyberte správný `RecognitionLanguage` pro **nastavení jazyka OCR** pro maximální přesnost.

Odtud můžete experimentovat s dávkovým zpracováním, různými jazyky nebo dokonce spojit více skenovaných stránek do jednoho prohledávatelného PDF. Stejný vzor funguje i pro jiné jazyky, jako španělština nebo japonština – stačí vyměnit výčet `RecognitionLanguage`.
