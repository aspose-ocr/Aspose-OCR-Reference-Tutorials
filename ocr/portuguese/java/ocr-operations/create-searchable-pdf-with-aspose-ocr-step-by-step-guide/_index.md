# Criar PDF pesquisável – tutorial de programação completo

Já precisou **criar PDF pesquisável** a partir de imagens digitalizadas, mas não sabia por onde começar? Você não está sozinho. Em muitos fluxos de trabalho com muitos documentos, um PDF apenas com imagem é um beco sem saída para busca e indexação.  

A boa notícia é que, com o Aspose OCR, você pode **converter PDF de imagem digitalizada** em um documento totalmente pesquisável em apenas algumas linhas de Java. Este tutorial orienta você em cada passo — inicializando o motor OCR, configurando as definições de PDF de alta compressão, incorporando uma camada de texto oculta e até escolhendo o idioma OCR correto.  

Ao final deste guia, você terá um programa executável que produz um PDF pesquisável, um arquivo que pode ser inserido em qualquer motor de busca ou sistema de gerenciamento de documentos sem problemas.

---

## Respostas rápidas
- **O que significa “PDF pesquisável”?** Ele combina uma camada visual de imagem com uma camada de texto invisível gerada pelo OCR.  
- **Qual biblioteca realiza a conversão?** Aspose OCR for Java.  
- **Como posso manter o tamanho do arquivo pequeno?** Use `setCompressionLevel(9)` para PDF de alta compressão.  
- **Posso processar documentos não‑inglês?** Sim — defina o valor apropriado do enum `RecognitionLanguage`.  
- **Preciso de uma licença para produção?** Uma licença comercial do Aspose OCR é necessária para uso que não seja de avaliação.

---

## O que é um PDF pesquisável?
Um PDF pesquisável é um PDF que contém tanto a imagem digitalizada original quanto uma camada de texto invisível e legível por máquina, produzida pelo OCR. Esse design de camada dupla permite que os usuários selecionem, copiem e indexem o texto enquanto ainda veem a aparência original da página.

---

## Por que usar Aspose OCR para Java?
Aspose OCR suporta **mais de 30 idiomas** e pode processar **até 120 páginas por minuto** em uma CPU padrão, tornando‑se um dos motores OCR Java mais rápidos. Seu gravador de PDF incorporado também oferece **nove níveis de compressão**, permitindo reduzir documentos digitalizados grandes em até **80 %** sem perder a precisão do OCR.

---

## Pré‑requisitos
- Java 17 (ou superior) instalado e configurado.  
- JAR do Aspose OCR for Java adicionado ao classpath do seu projeto.  
- Um arquivo de imagem digitalizada (PNG, JPEG ou TIFF) que você deseja transformar em um PDF pesquisável.  

---

## Como o Aspose OCR cria um PDF pesquisável?
Carregue a imagem de origem, habilite o modo searchable‑PDF, defina o nível de compressão desejado, escolha o idioma OCR e indique ao motor para salvar o resultado como PDF. A API cuida do trabalho pesado: executa o OCR, cria a camada de texto oculta e grava o PDF final em uma única passagem.

---

## Converter PDF de imagem digitalizada usando Aspose OCR

**O motor Aspose OCR** é o componente central que lê imagens, realiza reconhecimento óptico de caracteres e produz saída em vários formatos.  

Os passos a seguir ilustram o fluxo de conversão:

- Chame `setCreateSearchablePdf(true)` para instruir o motor a incorporar a camada de texto oculta.  
- Use `setCompressionLevel(9)` para obter saída de **PDF de alta compressão**, reduzindo o tamanho do arquivo drasticamente.  
- Especifique `RecognitionLanguage.ENGLISH` (ou outro idioma) para **definir o idioma OCR** para precisão ótima.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Por que isso funciona:**  
- `setCreateSearchablePdf(true)` informa ao Aspose para gerar a camada de texto oculta, atendendo ao requisito de **PDF com camada de texto incorporada**.  
- `setCompressionLevel(9)` coloca o arquivo na faixa de **PDF de alta compressão**, reduzindo o tamanho final sem sacrificar a precisão do OCR.  
- O argumento `RecognitionLanguage.ENGLISH` demonstra como **definir o idioma OCR**; você pode troc‑lo por francês, alemão etc., dependendo do material de origem.

---

## Configurações de PDF de alta compressão

**CompressionLevel** controla o quão agressivamente o gravador de PDF reduz o tamanho das imagens e fluxos incorporados. Os valores variam de 0 (sem compressão) a 9 (compressão máxima).  

Ao definir o nível para 9, o Aspose OCR aplica **compressão PNG sem perdas** para páginas com muito texto e **JPEG de alta qualidade** para conteúdo fotográfico, frequentemente reduzindo o tamanho do arquivo em **70‑80 %** comparado à saída sem compressão.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

A couple of tips:

- **Use formatos de imagem sem perdas** (PNG) para digitalizações com muito texto; JPEG é melhor para fotos.  
- **Habilite a subconfiguração de fontes** se você incorporar fontes personalizadas — o Aspose faz isso automaticamente ao criar um PDF pesquisável.  
- **Teste o tamanho da saída** após cada alteração; às vezes a compressão nível‑8 oferece uma redução de tamanho de 10 % com perda de qualidade insignificante comparada ao nível 9.

---

## Incorporar camada de texto PDF para pesquisabilidade

Se você omitir a chamada `setCreateSearchablePdf(true)`, o arquivo resultante parecerá bom, mas não será possível pesquisar seu conteúdo. A camada de texto oculta é criada ao mapear cada caractere reconhecido para sua localização na página.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**O que observar:**  

- **Documentos com múltiplos idiomas** – pode ser necessário executar o OCR duas vezes, uma por idioma, e então mesclar as camadas de texto.  
- **Layouts complexos** (tabelas, múltiplas colunas) – o Aspose faz um trabalho razoável, mas verifique a saída com um visualizador de PDF que mostre texto oculto (por exemplo, o modo “Editar PDF” do Adobe Acrobat).

---

## Definir idioma OCR para reconhecimento preciso

**RecognitionLanguage** é uma enumeração que informa ao motor OCR qual conjunto de caracteres esperar, melhorando drasticamente a precisão para scripts não latinos.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Quando mudar o idioma:**  

- Documentos contêm **scripts não latinos** (Cirílico, Árabe) – altere para o `RecognitionLanguage` apropriado.  
- Páginas com múltiplos idiomas – você pode chamar `recognizeImageAndSave` duas vezes, cada vez com um idioma diferente, e então mesclar os PDFs.

## Executando o exemplo completo

Abaixo está o programa completo, pronto para execução. Substitua os caminhos de placeholder pelos locais reais dos arquivos, garanta que o JAR do Aspose OCR esteja no seu classpath e execute.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Saída esperada:** Quando você executar o programa, o console imprime:

```
Searchable PDF created.
```

Abra `searchable.pdf` em qualquer visualizador de PDF, tente selecionar texto e você verá a camada invisível em ação. Você criou com sucesso **um PDF pesquisável** a partir de uma imagem digitalizada.

## Problemas comuns e soluções

- **Memory‑out‑of‑bounds em arquivos grandes** – habilite o modo de streaming chamando `OcrEngine.setUseStream(true)`.  
- **Detecção de idioma incorreta** – defina explicitamente `RecognitionLanguage` em vez de depender da detecção automática.  
- **Digitalizações borradas** – pré‑procese as imagens com Aspose Imaging para aumentar o contraste antes do OCR.

---

## Perguntas frequentes

**Q: Posso processar em lote uma pasta inteira de imagens?**  
A: Sim. Itere sobre os arquivos, chame a mesma configuração OCR para cada um e concatene os PDFs resultantes com `PdfDocument.merge()`.

**Q: O Aspose OCR suporta entrada de PDF diretamente?**  
A: Sim. Use `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` e defina `setCreateSearchablePdf(true)`.

**Q: Como lidar com PDFs protegidos por senha?**  
A: Passe a senha para `OcrEngine.setPassword("yourPassword")` antes de invocar o método OCR.

**Q: Qual é o tamanho máximo de arquivo que o Aspose OCR pode processar?**  
A: O motor pode processar PDFs de até **2 GB** quando o streaming está habilitado, limitado apenas pela RAM disponível.

**Q: É necessária uma licença comercial para uso em produção?**  
A: Sim. Uma licença de avaliação funciona para testes, mas uma licença completa remove as marcas d'água de avaliação e desbloqueia todos os recursos.

## Conclusão

Cobremos tudo o que você precisa para **criar arquivos PDF pesquisáveis** usando o Aspose OCR:

- Inicializar o motor OCR.  
- **Converter PDF de imagem digitalizada** alimentando um PNG/JPEG em `recognizeImageAndSave`.  
- Use `setCreateSearchablePdf(true)` para **incorporar camada de texto PDF**.  
- Aplique `setCompressionLevel(9)` para um **PDF de alta compressão** que permanece leve.  
- Escolha o `RecognitionLanguage` correto para **definir o idioma OCR** e obter a máxima precisão.

A partir daqui, você pode experimentar o processamento em lote, diferentes idiomas ou até combinar várias páginas digitalizadas em um único PDF pesquisável. O mesmo padrão funciona para outros idiomas como espanhol ou japonês — basta trocar o enum `RecognitionLanguage`.
