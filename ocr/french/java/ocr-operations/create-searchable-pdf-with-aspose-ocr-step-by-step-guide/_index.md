# Créer un PDF consultable – tutoriel complet de programmation

Ever needed to **create searchable PDF** files from scanned images but weren’t sure where to start? You’re not alone. In many document‑heavy workflows, a plain image‑only PDF is a dead‑end for search and indexing.  

The good news is that with Aspose OCR you can **convert scanned image PDF** into a fully searchable document in just a few lines of Java. This tutorial walks you through every step—initializing the OCR engine, configuring high compression PDF settings, embedding a hidden text layer, and even choosing the right OCR language.

By the end of this guide you’ll have a runnable program that produces a searchable PDF, a file you can drop into any search engine or document management system without a hitch.

---

## Réponses rapides
- **Que signifie « PDF consultable » ?** Il combine une couche d'image visuelle avec une couche de texte invisible générée par OCR.  
- **Quelle bibliothèque gère la conversion ?** Aspose OCR for Java.  
- **Comment garder la taille du fichier petite ?** Utilisez `setCompressionLevel(9)` pour un PDF à haute compression.  
- **Puis-je traiter des documents non anglais ?** Oui—définissez la valeur appropriée de l'énumération `RecognitionLanguage`.  
- **Ai‑je besoin d'une licence pour la production ?** Une licence commerciale Aspose OCR est requise pour un usage hors période d'essai.

---

## Qu'est‑ce qu'un PDF consultable ?
A searchable PDF is a PDF that contains both the original scanned image and an invisible, machine‑readable text layer produced by OCR. This dual‑layer design lets users select, copy, and index the text while still seeing the original page appearance.

---

## Pourquoi utiliser Aspose OCR pour Java ?
Aspose OCR supports **over 30 languages** and can process **up to 120 pages per minute** on a standard CPU, making it one of the fastest Java OCR engines. Its built‑in PDF writer also offers **nine levels of compression**, allowing you to shrink large scanned documents by up to **80 %** without losing OCR accuracy.

---

## Prérequis
- Java 17 (ou version ultérieure) installé et configuré.  
- JAR Aspose OCR for Java ajouté au classpath de votre projet.  
- Un fichier image numérisé (PNG, JPEG ou TIFF) que vous souhaitez transformer en PDF consultable.  

---

## Comment Aspose OCR crée‑t‑il un PDF consultable ?
Load the source image, enable searchable‑PDF mode, set the desired compression level, choose the OCR language, and tell the engine to save the result as a PDF. The API handles the heavy lifting: it runs OCR, creates the hidden text layer, and writes the final PDF in one pass.

---

## Convertir un PDF d'image numérisée avec Aspose OCR

**Aspose OCR engine** is the core component that reads images, performs optical character recognition, and produces output in various formats.  

The following steps illustrate the conversion flow:

- Appelez `setCreateSearchablePdf(true)` pour indiquer au moteur d'intégrer la couche de texte cachée.  
- Utilisez `setCompressionLevel(9)` pour obtenir une sortie **PDF à haute compression**, réduisant la taille du fichier de façon spectaculaire.  
- Spécifiez `RecognitionLanguage.ENGLISH` (ou une autre langue) pour **définir la langue OCR** afin d'obtenir une précision optimale.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Pourquoi cela fonctionne :**  
- `setCreateSearchablePdf(true)` indique à Aspose de générer la couche de texte cachée, répondant à l'exigence **PDF avec couche de texte intégrée**.  
- `setCompressionLevel(9)` place le fichier dans la gamme **PDF à haute compression**, réduisant la taille finale sans sacrifier la précision de l'OCR.  
- L'argument `RecognitionLanguage.ENGLISH` montre comment **définir la langue OCR** ; vous pouvez le remplacer par le français, l'allemand, etc., selon votre matériel source.

---

## Paramètres de PDF à haute compression

**CompressionLevel** controls how aggressively the PDF writer reduces the size of embedded images and streams. Values range from 0 (no compression) to 9 (maximum compression).  

When you set the level to 9, Aspose OCR applies **lossless PNG compression** for text‑heavy pages and **high‑quality JPEG** for photographic content, often cutting file size by **70‑80 %** compared with the uncompressed output.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Quelques conseils :

- **Utilisez des formats d'image sans perte** (PNG) pour les numérisations riches en texte ; le JPEG est préférable pour les photos.  
- **Activez la sous‑ensemble de polices** si vous intégrez des polices personnalisées—Aspose le fait automatiquement lors de la création d'un PDF consultable.  
- **Testez la taille de sortie** après chaque modification ; parfois une compression de niveau 8 vous donne une réduction de taille de 10 % avec une perte de qualité négligeable comparée au niveau 9.

---

## Intégrer une couche de texte PDF pour la recherche

If you skip the `setCreateSearchablePdf(true)` call, the resulting file will look fine but you won’t be able to search its contents. The hidden text layer is created by mapping each recognized character to its location on the page.  

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**À surveiller :**  

- **Documents multilingues** – il peut être nécessaire d'exécuter l'OCR deux fois, une fois par langue, puis de fusionner les couches de texte.  
- **Mises en page complexes** (tables, colonnes multiples) – Aspose fait un travail correct, mais vérifiez le résultat avec un visualiseur PDF affichant le texte caché (par ex., le mode « Modifier le PDF » d'Adobe Acrobat).

---

## Définir la langue OCR pour une reconnaissance précise

**RecognitionLanguage** is an enumeration that tells the OCR engine which character set to expect, dramatically improving accuracy for non‑Latin scripts.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Quand changer la langue :**  

- Les documents contiennent des **scripts non latins** (cyrillique, arabe) – passez à la `RecognitionLanguage` appropriée.  
- Pages multilingues – vous pouvez appeler `recognizeImageAndSave` deux fois, chaque fois avec une langue différente, puis fusionner les PDF.

## Exécuter l'exemple complet

Below is the full, ready‑to‑run program. Replace the placeholder paths with real file locations, ensure the Aspose OCR JAR is on your classpath, and execute.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Sortie attendue :** Lorsque vous exécutez le programme, la console affiche:

```
Searchable PDF created.
```

Ouvrez `searchable.pdf` dans n'importe quel visualiseur PDF, essayez de sélectionner du texte, et vous verrez la couche invisible en action. Vous avez réussi à **créer un PDF consultable** à partir d'une image numérisée.

## Problèmes courants et solutions

- **Mémoire insuffisante sur les gros fichiers** – activez le mode flux en appelant `OcrEngine.setUseStream(true)`.  
- **Détection de langue incorrecte** – définissez explicitement `RecognitionLanguage` au lieu de vous fier à la détection automatique.  
- **Numérisations floues** – prétraitez les images avec Aspose Imaging pour augmenter le contraste avant l'OCR.

## Questions fréquemment posées

**Q : Puis‑je traiter en lot un dossier entier d'images ?**  
A : Oui. Parcourez les fichiers, appelez la même configuration OCR pour chacun, et concaténez les PDF résultants avec `PdfDocument.merge()`.

**Q : Aspose OCR prend‑il en charge directement les PDF en entrée ?**  
A : Oui. Utilisez `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` et définissez `setCreateSearchablePdf(true)`.

**Q : Comment gérer les PDF protégés par mot de passe ?**  
A : Passez le mot de passe à `OcrEngine.setPassword("yourPassword")` avant d'appeler la méthode OCR.

**Q : Quelle est la taille maximale de fichier qu'Aspose OCR peut gérer ?**  
A : Le moteur peut traiter des PDF jusqu'à **2 Go** lorsque le mode flux est activé, limité uniquement par la RAM disponible.

**Q : Une licence commerciale est‑elle requise pour une utilisation en production ?**  
A : Oui. Une licence d'essai fonctionne pour l'évaluation, mais une licence complète supprime les filigranes d'évaluation et débloque toutes les fonctionnalités.

## Conclusion

We’ve covered everything you need to **create searchable PDF** files using Aspose OCR:

- Initialisez le moteur OCR.  
- **Convertir un PDF d'image numérisée** en fournissant un PNG/JPEG à `recognizeImageAndSave`.  
- Utilisez `setCreateSearchablePdf(true)` pour **intégrer une couche de texte PDF**.  
- Appliquez `setCompressionLevel(9)` pour un **PDF à haute compression** qui reste léger.  
- Choisissez la bonne `RecognitionLanguage` pour **définir la langue OCR** afin d'obtenir une précision maximale.

From here you can experiment with batch processing, different languages, or even combine multiple scanned pages into a single searchable PDF. The same pattern works for other languages like Spanish or Japanese—just swap the `RecognitionLanguage` enum.
