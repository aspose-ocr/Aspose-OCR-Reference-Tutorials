## Δημιουργία αναζητήσιμου pdf – επισκόπηση

Ο πυρήνας της λύσης βρίσκεται στην κλάση `PdfOcrProcessor` που παρέχεται από το Aspose. **Η κλάση `PdfOcrProcessor` είναι η μηχανή του Aspose OCR που διαβάζει κάθε σελίδα PDF, εκτελεί OCR και γράφει ένα κρυφό στρώμα κειμένου πίσω στο αρχείο.** Αυτό το στρώμα κάνει το αρχείο αναζητήσιμο ενώ διατηρεί την αρχική εμφάνιση της εικόνας.

Παρακάτω είναι το πλήρες, έτοιμο‑για‑εκτέλεση πρόγραμμα Java. Μπορείτε να το αντιγράψετε‑και‑επικολλήσετε στο IDE σας και να πατήσετε **Run**.

```java
import com.aspose.ocr.*;
import com.aspose.ocr.pdf.*;

public class PdfToSearchablePdf {
    public static void main(String[] args) throws Exception {

        // Step 1: Define the source scanned PDF and the target searchable PDF paths
        String inputPdfPath = "YOUR_DIRECTORY/input.pdf";
        String outputPdfPath = "YOUR_DIRECTORY/searchable_output.pdf";

        // Step 2: Create an instance of the PDF OCR processor
        PdfOcrProcessor pdfProcessor = new PdfOcrProcessor();

        // Step 3: (Optional) Configure OCR settings – DPI and language
        pdfProcessor.getConfiguration().setDpi(300);               // higher DPI can improve accuracy
        pdfProcessor.getConfiguration().setLanguage(Language.ENGLISH);

        // Step 4: Convert the scanned PDF into a searchable PDF
        pdfProcessor.convertToSearchablePdf(inputPdfPath, outputPdfPath);

        // Step 5: Inform the user where the result was saved
        System.out.println("Searchable PDF created at: " + outputPdfPath);
    }
}
```

Η εκτέλεση του προγράμματος εκτυπώνει κάτι όπως:

```
Searchable PDF created at: YOUR_DIRECTORY/searchable_output.pdf
```

Ανοίξτε το παραγόμενο αρχείο στο Adobe Reader, πατήστε **Ctrl + F**, και θα δείτε ότι το κείμενο που πληκτρολογήσατε στο πεδίο αναζήτησης ταιριάζει τώρα με το περιεχόμενο των σαρωμένων σελίδων. Αυτή είναι η στιγμή που ξέρετε ότι έχετε δημιουργήσει επιτυχώς **create searchable pdf**.

## Βήμα 1: ρυθμίστε το aspose ocr για java

Πριν μπορέσετε να καλέσετε το `PdfOcrProcessor`, χρειάζεστε τα JAR του Aspose OCR στο classpath σας.

**Χρήστες Maven** προσθέτουν την ακόλουθη εξάρτηση στο `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-ocr</artifactId>
    <version>23.10</version> <!-- check for the latest version -->
</dependency>
```

**Χρήστες Gradle** προσθέτουν αυτή τη γραμμή στο `build.gradle`:

```gradle
implementation 'com.aspose:aspose-ocr:23.10'
```

Αν προτιμάτε χειροκίνητη λήψη, κατεβάστε το JAR από το portal του Aspose και τοποθετήστε το στο `libs/`. Θυμηθείτε να δείξετε το IDE σας στο JAR, διαφορετικά θα εμφανιστούν σφάλματα μεταγλώττισης.

> **Συμβουλή επαγγελματία:** Χρησιμοποιήστε την πιο πρόσφατη έκδοση του Aspose OCR για να επωφεληθείτε από βελτιώσεις απόδοσης και νέα πακέτα γλωσσών. Η τρέχουσα έκδοση υποστηρίζει **60+ γλώσσες** και μπορεί να επεξεργαστεί PDF έως **500 MB** χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη.

## Βήμα 2: ρυθμίστε τις ρυθμίσεις ocr (προαιρετικό αλλά συνιστάται)

Η προεπιλεγμένη ρύθμιση OCR λειτουργεί, αλλά η ρύθμιση του DPI και της γλώσσας μπορεί να βελτιώσει δραστικά το αποτέλεσμα όταν **convert scanned pdf** που περιέχει μικρές γραμματοσειρές ή μη‑Αγγλικό κείμενο.

```java
pdfProcessor.getConfiguration().setDpi(300); // 300 DPI is a sweet spot
pdfProcessor.getConfiguration().setLanguage(Language.ENGLISH);
```

* **DPI** – Υψηλότερο DPI δίνει στη μηχανή OCR περισσότερα pixel για ανάλυση, κάτι που συνήθως μεταφράζεται σε υψηλότερη ακρίβεια. Ωστόσο, αυξάνει και τη χρήση μνήμης, έτσι το 300 DPI είναι ένα πρακτικό συμβιβαστικό για τα περισσότερα έγγραφα.  
* **Language** – Η ρύθμιση της σωστής γλώσσας μειώνει τα ψευδώς θετικά. Το Aspose υποστηρίζει **πάνω από 60 γλώσσες**· απλώς αντικαταστήστε το `Language.ENGLISH` με `Language.FRENCH`, `Language.SPANISH`, κλπ., αν χρειάζεται.

Αν χρειάζεστε **how to make searchable pdf** σε πολλές γλώσσες, μπορείτε να καλέσετε το `setLanguage` πολλές φορές ή να χρησιμοποιήσετε το `Language.MULTI` (αν η βιβλιοθήκη το υποστηρίζει).

## Βήμα 3: μετατρέψτε scanned pdf σε searchable pdf

Τώρα συμβαίνει η μαγεία. Η μέθοδος `convertToSearchablePdf` κάνει όλη τη βαριά δουλειά.

Η μέθοδος `convertToSearchablePdf` μετατρέπει το εισερχόμενο PDF σε αναζητήσιμο PDF εκτελώντας OCR σε κάθε σελίδα και προσθέτοντας ένα κρυφό στρώμα κειμένου.

```java
pdfProcessor.convertToSearchablePdf(inputPdfPath, outputPdfPath);
```

Στο παρασκήνιο, το Aspose διαβάζει την εικόνα κάθε σελίδας, εκτελεί OCR και προσθέτει ένα κρυφό στρώμα κειμένου. Η αρχική εικόνα παραμένει άθικτη, πράγμα που σημαίνει ότι η οπτική διάταξη που βλέπετε στο πηγαίο PDF διατηρείται.

**Περίπτωση άκρης:** Αν το πηγαίο PDF είναι προστατευμένο με κωδικό, θα πρέπει πρώτα να το ξεκλειδώσετε με το `PdfDocument` πριν περάσετε τη διαδρομή στον επεξεργαστή OCR. Η βιβλιοθήκη παρέχει `pdfDocument.decrypt("password")` για αυτό το σκοπό.

## Βήμα 4: επαληθεύστε το αποτέλεσμα

Μετά τη μετατροπή, ανοίξτε το αρχείο εξόδου σε οποιονδήποτε προβολέα PDF που υποστηρίζει αναζήτηση κειμένου (Adobe Acrobat Reader, Foxit, κλπ.) και δοκιμάστε να αναζητήσετε μια λέξη που γνωρίζετε ότι εμφανίζεται στην σαρωμένη εικόνα. Αν η αναζήτηση βρει τη λέξη, έχετε δημιουργήσει επιτυχώς **create searchable pdf**.

Μπορείτε επίσης προγραμματιστικά να επαληθεύσετε την παρουσία ενός στρώματος κειμένου χρησιμοποιώντας το Aspose PDF:

```java
PdfDocument doc = new PdfDocument(outputPdfPath);
boolean hasText = doc.getPages().get_Item(1).getExtractedText().length() > 0;
System.out.println("Text layer detected: " + hasText);
```

Αν το `hasText` εκτυπώσει `true`, το στρώμα OCR είναι στη θέση του.
