# Δημιουργία αναζητήσιμου PDF – πλήρης προγραμματιστικός οδηγός

Έχετε ποτέ χρειαστεί να **δημιουργήσετε αναζητήσιμα PDF** αρχεία από σαρωμένες εικόνες αλλά δεν ήξερες από πού να ξεκινήσεις; Δεν είστε μόνοι. Σε πολλές ροές εργασίας με πολλά έγγραφα, ένα απλό PDF μόνο με εικόνες είναι αδιέξοδο για την αναζήτηση και την ευρετηρίαση.  

Τα καλά νέα είναι ότι με το Aspose OCR μπορείτε να **μετατρέψετε PDF σαρωμένης εικόνας** σε ένα πλήρως αναζητήσιμο έγγραφο με λίγες μόνο γραμμές Java. Αυτό το tutorial σας καθοδηγεί βήμα προς βήμα — την αρχικοποίηση της μηχανής OCR, τη διαμόρφωση ρυθμίσεων PDF υψηλής συμπίεσης, την ενσωμάτωση κρυφής στρώσης κειμένου, και ακόμη την επιλογή της σωστής γλώσσας OCR.

Στο τέλος αυτού του οδηγού θα έχετε ένα εκτελέσιμο πρόγραμμα που παράγει ένα αναζητήσιμο PDF, ένα αρχείο που μπορείτε να ενσωματώσετε σε οποιαδήποτε μηχανή αναζήτησης ή σύστημα διαχείρισης εγγράφων χωρίς προβλήματα.

---

## Γρήγορες απαντήσεις
- **Τι σημαίνει το “searchable PDF”;** Συνδυάζει μια οπτική στρώση εικόνας με μια αόρατη στρώση κειμένου που δημιουργείται από το OCR.  
- **Ποια βιβλιοθήκη διαχειρίζεται τη μετατροπή;** Aspose OCR for Java.  
- **Πώς μπορώ να διατηρήσω το μέγεθος του αρχείου μικρό;** Χρησιμοποιήστε `setCompressionLevel(9)` για PDF υψηλής συμπίεσης.  
- **Μπορώ να επεξεργαστώ έγγραφα μη‑Αγγλικά;** Ναι — ορίστε την κατάλληλη τιμή του enum `RecognitionLanguage`.  
- **Χρειάζομαι άδεια για παραγωγή;** Απαιτείται εμπορική άδεια Aspose OCR για χρήση εκτός δοκιμής.

---

## Τι είναι ένα αναζητήσιμο PDF;
Ένα αναζητήσιμο PDF είναι ένα PDF που περιέχει τόσο την αρχική σαρωμένη εικόνα όσο και μια αόρατη, μηχανικά αναγνώσιμη στρώση κειμένου που παράγεται από το OCR. Αυτός ο διπλός σχεδιασμός επιτρέπει στους χρήστες να επιλέγουν, να αντιγράφουν και να ευρετηριάζουν το κείμενο ενώ εξακολουθούν να βλέπουν την αρχική εμφάνιση της σελίδας.

---

## Γιατί να χρησιμοποιήσετε το Aspose OCR για Java;
Το Aspose OCR υποστηρίζει **πάνω από 30 γλώσσες** και μπορεί να επεξεργαστεί **έως 120 σελίδες ανά λεπτό** σε τυπική CPU, καθιστώντας το μία από τις πιο γρήγορες μηχανές OCR για Java. Ο ενσωματωμένος δημιουργός PDF προσφέρει επίσης **εννέα επίπεδα συμπίεσης**, επιτρέποντάς σας να μειώσετε μεγάλα σαρωμένα έγγραφα έως και **80 %** χωρίς να χάσετε την ακρίβεια του OCR.

- Ένα αρχείο σαρωμένης εικόνας (PNG, JPEG ή TIFF) που θέλετε να μετατρέψετε σε αναζητήσιμο PDF.

## Πώς δημιουργεί το Aspose OCR ένα αναζητήσιμο PDF;
Φορτώστε την πηγή εικόνας, ενεργοποιήστε τη λειτουργία searchable‑PDF, ορίστε το επιθυμητό επίπεδο συμπίεσης, επιλέξτε τη γλώσσα OCR και ζητήστε από τη μηχανή να αποθηκεύσει το αποτέλεσμα ως PDF. Το API διαχειρίζεται το δύσκολο μέρος: εκτελεί OCR, δημιουργεί τη κρυφή στρώση κειμένου και γράφει το τελικό PDF σε ένα βήμα.

## Μετατροπή PDF σαρωμένης εικόνας χρησιμοποιώντας το Aspose OCR

**Η μηχανή Aspose OCR** είναι το κύριο συστατικό που διαβάζει εικόνες, εκτελεί οπτική αναγνώριση χαρακτήρων και παράγει έξοδο σε διάφορες μορφές.  

Τα παρακάτω βήματα απεικονίζουν τη ροή μετατροπής:

- Καλέστε `setCreateSearchablePdf(true)` για να υποδείξετε στη μηχανή να ενσωματώσει τη κρυφή στρώση κειμένου.  
- Χρησιμοποιήστε `setCompressionLevel(9)` για να επιτύχετε έξοδο **PDF υψηλής συμπίεσης**, μειώνοντας δραστικά το μέγεθος του αρχείου.  
- Καθορίστε `RecognitionLanguage.ENGLISH` (ή άλλη γλώσσα) για να **ορίσετε τη γλώσσα OCR** για βέλτιστη ακρίβεια.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Γιατί αυτό λειτουργεί:**  
- `setCreateSearchablePdf(true)` λέει στο Aspose να δημιουργήσει τη κρυφή στρώση κειμένου, ικανοποιώντας την απαίτηση **ενσωμάτωσης στρώσης κειμένου PDF**.  
- `setCompressionLevel(9)` μεταφέρει το αρχείο στην περιοχή **PDF υψηλής συμπίεσης**, μειώνοντας το τελικό μέγεθος χωρίς να θυσιάζει την ακρίβεια του OCR.  
- Το όρισμα `RecognitionLanguage.ENGLISH` δείχνει πώς να **ορίσετε τη γλώσσα OCR**· μπορείτε να το αντικαταστήσετε με Γαλλικά, Γερμανικά κ.λπ., ανάλογα με το υλικό προέλευσης.

---

## Ρυθμίσεις PDF υψηλής συμπίεσης

**CompressionLevel** ελέγχει πόσο επιθετικά ο δημιουργός PDF μειώνει το μέγεθος των ενσωματωμένων εικόνων και ροών. Οι τιμές κυμαίνονται από 0 (χωρίς συμπίεση) έως 9 (μέγιστη συμπίεση).  

Όταν ορίσετε το επίπεδο σε 9, το Aspose OCR εφαρμόζει **συμπίεση PNG χωρίς απώλειες** για σελίδες με πολύ κείμενο και **JPEG υψηλής ποιότητας** για φωτογραφικό περιεχόμενο, συχνά μειώνοντας το μέγεθος του αρχείου κατά **70‑80 %** σε σύγκριση με την ασυμπίεστη έξοδο.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Μερικές συμβουλές:

- **Χρησιμοποιήστε μορφές εικόνας χωρίς απώλειες** (PNG) για σαρώσεις με πολύ κείμενο· το JPEG είναι καλύτερο για φωτογραφίες.  
- **Ενεργοποιήστε την υπο‑επιλογή γραμματοσειρών** εάν ενσωματώνετε προσαρμοσμένες γραμματοσειρές — το Aspose το κάνει αυτό αυτόματα όταν δημιουργείτε ένα αναζητήσιμο PDF.  
- **Δοκιμάστε το μέγεθος εξόδου** μετά από κάθε αλλαγή· μερικές φορές μια συμπίεση επιπέδου 8 προσφέρει μείωση μεγέθους 10 % με αμελητέο απώλεια ποιότητας σε σύγκριση με το επίπεδο 9.

---

## Ενσωμάτωση στρώσης κειμένου PDF για αναζητησιμότητα

Αν παραλείψετε την κλήση `setCreateSearchablePdf(true)`, το παραγόμενο αρχείο θα φαίνεται εντάξει αλλά δεν θα μπορείτε να αναζητήσετε το περιεχόμενό του. Η κρυφή στρώση κειμένου δημιουργείται αντιστοιχίζοντας κάθε αναγνωρισμένο χαρακτήρα στη θέση του στη σελίδα.

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Τι πρέπει να προσέξετε:**  

- **Έγγραφα μικτής γλώσσας** – ίσως χρειαστεί να εκτελέσετε OCR δύο φορές, μία ανά γλώσσα, και στη συνέχεια να συγχωνεύσετε τις στρώσεις κειμένου.  
- **Πολύπλοκες διατάξεις** (πίνακες, πολλαπλές στήλες) – το Aspose κάνει καλή δουλειά, αλλά ελέγξτε ξανά το αποτέλεσμα με έναν προβολέα PDF που εμφανίζει κρυφό κείμενο (π.χ., τη λειτουργία “Edit PDF” του Adobe Acrobat).

---

## Ορισμός γλώσσας OCR για ακριβή αναγνώριση

**RecognitionLanguage** είναι μια απαρίθμηση που ενημερώνει τη μηχανή OCR για το σύνολο χαρακτήρων που αναμένεται, βελτιώνοντας δραματικά την ακρίβεια για μη‑λατινικά αλφάβητα.

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Πότε να αλλάξετε τη γλώσσα:**  

- Τα έγγραφα περιέχουν **μη‑λατινικά αλφάβητα** (Κυριλλικά, Αραβικά) – μεταβείτε στην κατάλληλη `RecognitionLanguage`.  
- Σελίδες μικτής γλώσσας – μπορείτε να καλέσετε `recognizeImageAndSave` δύο φορές, κάθε φορά με διαφορετική γλώσσα, και στη συνέχεια να συγχωνεύσετε τα PDFs.

## Εκτέλεση του πλήρους παραδείγματος

Παρακάτω βρίσκεται το πλήρες, έτοιμο‑για‑εκτέλεση πρόγραμμα. Αντικαταστήστε τις διαδρομές placeholder με πραγματικές τοποθεσίες αρχείων, βεβαιωθείτε ότι το JAR του Aspose OCR βρίσκεται στο classpath σας και εκτελέστε.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Αναμενόμενη έξοδος:** Όταν εκτελέσετε το πρόγραμμα, η κονσόλα εκτυπώνει:

```
Searchable PDF created.
```

Ανοίξτε το `searchable.pdf` σε οποιονδήποτε προβολέα PDF, δοκιμάστε να επιλέξετε κείμενο και θα δείτε τη λειτουργία της αόρατης στρώσης. Έχετε δημιουργήσει επιτυχώς **αναζητήσιμο pdf** από μια σαρωμένη εικόνα.

## Συχνά προβλήματα και λύσεις

- **Memory‑out‑of‑bounds σε μεγάλα αρχεία** – ενεργοποιήστε τη λειτουργία streaming καλώντας `OcrEngine.setUseStream(true)`.  
- **Λανθασμένος εντοπισμός γλώσσας** – ορίστε ρητά το `RecognitionLanguage` αντί να βασίζεστε στην αυτόματη ανίχνευση.  
- **Θολές σαρώσεις** – προεπεξεργαστείτε τις εικόνες με το Aspose Imaging για να αυξήσετε την αντίθεση πριν το OCR.

## Συχνές ερωτήσεις

**Q: Μπορώ να επεξεργαστώ μαζικά ολόκληρο φάκελο εικόνων;**  
A: Ναι. Επαναλάβετε πάνω στα αρχεία, καλέστε την ίδια διαμόρφωση OCR για κάθε ένα, και συνενώστε τα παραγόμενα PDFs με `PdfDocument.merge()`.

**Q: Υποστηρίζει το Aspose OCR άμεση είσοδο PDF;**  
A: Ναι. Χρησιμοποιήστε `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)` και ορίστε `setCreateSearchablePdf(true)`.

**Q: Πώς διαχειρίζομαι PDF με κωδικό πρόσβασης;**  
A: Περνάτε τον κωδικό στο `OcrEngine.setPassword("yourPassword")` πριν καλέσετε τη μέθοδο OCR.

**Q: Ποιο είναι το μέγιστο μέγεθος αρχείου που μπορεί να χειριστεί το Aspose OCR;**  
A: Η μηχανή μπορεί να επεξεργαστεί PDFs έως **2 GB** όταν είναι ενεργοποιημένη η λειτουργία streaming, περιοριζόμενο μόνο από τη διαθέσιμη μνήμη RAM.

**Q: Απαιτείται εμπορική άδεια για χρήση σε παραγωγή;**  
A: Ναι. Μια δοκιμαστική άδεια λειτουργεί για αξιολόγηση, αλλά μια πλήρης άδεια αφαιρεί τα υδατογραφήματα αξιολόγησης και ξεκλειδώνει όλες τις λειτουργίες.
