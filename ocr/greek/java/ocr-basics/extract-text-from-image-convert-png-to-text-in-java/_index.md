## Τι είναι η μετατροπή PNG σε κείμενο;
**Convert PNG to text** σημαίνει την εξαγωγή των γραμματικών χαρακτήρων που εμφανίζονται μέσα σε μια εικόνα PNG και η μετατροπή τους σε μια απλή συμβολοσειρά κειμένου που μπορείτε να επεξεργαστείτε, να αναζητήσετε ή να αποθηκεύσετε. Αυτή η διαδικασία ονομάζεται συνήθως optical character recognition (OCR). Λειτουργεί αναλύοντας τα πρότυπα εικονοστοιχείων και ταιριάζοντάς τα με λεξικά ειδικά για κάθε γλώσσα, επιτρέποντας τη μετατροπή σαρωμένων εγγράφων, στιγμιότυπων οθόνης ή οποιουδήποτε bitmap που περιέχει αναγνώσιμο κείμενο σε επεξεργάσιμα δεδομένα.

## Πώς προσθέτετε το Aspose OCR στο έργο σας;

## Πώς να δημιουργήσετε ένα στιγμιότυπο της μηχανής OCR;
Το OcrEngine είναι η κεντρική κλάση που εκτελεί την αναγνώριση OCR. Συμπυκνώνει όλα τα εσωτερικά buffers, τα δεδομένα γλώσσας και τις ρυθμίσεις επεξεργασίας που απαιτούνται για τη μετατροπή των εικονοστοιχείων σε κείμενο. Η δημιουργία ενός νέου στιγμιότυπου για κάθε λειτουργία εγγυάται ντετερμινιστικά αποτελέσματα, ειδικά όταν αλλάζετε γλώσσες ή λειτουργίες επεξεργασίας μεταξύ εκτελέσεων.

```java
import com.aspose.ocr.*;

public class ExtractTextExample {
    public static void main(String[] args) throws Exception {
        // Initialize the OCR engine
        OcrEngine ocrEngine = new OcrEngine();
        // ... further steps will follow
    }
}
```

Γιατί δημιουργούμε μια νέα μηχανή κάθε φορά; Επειδή η μηχανή αποθηκεύει στην κρυφή μνήμη λεξικά γλωσσών· η επαναφορά της αποτρέπει τη διασταυρούμενη μόλυνση μεταξύ διαφορετικών σκαναρίων γλώσσας.

## Πώς να ενεργοποιήσετε την επιθυμητή γλώσσα (προαιρετικό αλλά συνιστάται);
Το OcrLanguage αντιπροσωπεύει ένα συγκεκριμένο λεξικό γλώσσας που η μηχανή χρησιμοποιεί κατά την αναγνώριση. Η επιλογή της κατάλληλης γλώσσας μειώνει το χώρο αναζήτησης, επιταχύνει την επεξεργασία και βελτιώνει την ακρίβεια εστιάζοντας στο σύνολο χαρακτήρων που αναμένετε στην εικόνα.

`OcrLanguage` αντιπροσωπεύει ένα συγκεκριμένο λεξικό γλώσσας. Στο παράδειγμά μας θα ενεργοποιήσουμε το Khmer (`khm`), αλλά μπορείτε να το αντικαταστήσετε με `ENG` για Αγγλικά, `CHN` για Κινέζικα κ.λπ.

```java
// Enable Khmer language support (ISO 639‑2 code "khm")
ocrEngine.getLanguages().add(OcrLanguage.KHM);
```

> **Γιατί είναι σημαντικό:** Όταν **load image for OCR**, η μηχανή θα ψάχνει μόνο στα ενεργοποιημένα λεξικά γλώσσας. Η ενεργοποίηση όλων των γλωσσών μπορεί να επιβραδύνει τη διαδικασία και να αυξήσει τα ψευδώς θετικά.

## Πώς να φορτώσετε εικόνα για OCR – μετατροπή PNG σε κείμενο
Το ImageStream είναι ένας περιτύλιγμα που διαβάζει το αρχείο εικόνας σε μια ροή συμβατή με τη μηχανή OCR, διαχειριζόμενο αυτόματα την ανίχνευση μορφής. Απομονώνει τις χαμηλού επιπέδου λειτουργίες I/O, επιτρέποντάς σας να περάσετε ένα απλό αντικείμενο στη μηχανή χωρίς να ανησυχείτε για λεπτομέρειες διαχείρισης αρχείων.

`ImageStream` είναι ένας περιτύλιγμα που διαβάζει το αρχείο εικόνας σε μια ροή συμβατή με τη μηχανή OCR, διαχειριζόμενο αυτόματα την ανίχνευση μορφής.

```java
// Load the PNG that contains the text you want to extract
ocrEngine.setImage(ImageStream.fromFile("YOUR_DIRECTORY/khmer-sign.png"));
```

Αν η εικόνα σας είναι σε άλλη μορφή (JPEG, BMP, TIFF), η ίδια μέθοδος λειτουργεί—το Aspose ανιχνεύει αυτόματα τη μορφή. Απλώς βεβαιωθείτε ότι η διαδρομή του αρχείου είναι σωστή· διαφορετικά θα αντιμετωπίσετε ένα `FileNotFoundException`.

## Πώς να εκτελέσετε τη διαδικασία OCR και να μετατρέψετε PNG σε κείμενο;
Το OcrResult περιέχει το αποτέλεσμα της λειτουργίας αναγνώρισης, συμπεριλαμβανομένου του εξαγόμενου κειμένου και των μετρικών εμπιστοσύνης για κάθε χαρακτήρα ή λέξη. Μετά την κλήση της μεθόδου `recognize()` στη μηχανή, λαμβάνετε ένα αντικείμενο OcrResult που μπορείτε να ερωτήσετε για τη ακατέργαστη συμβολοσειρά και πρόσθετες λεπτομέρειες.

`ocrEngine.recognize()` επιστρέφει ένα `OcrResult` που περιέχει `getText()` για την εξαγόμενη συμβολοσειρά και `getConfidence()` για ένα μετρικό εμπιστοσύνης ανά χαρακτήρα.

```java
// Run OCR and fetch the recognized text
String recognizedText = ocrEngine.recognize().getText();
```

Αυτό είναι όλο—μόλις **convert PNG to text**. Η επιστρεφόμενη συμβολοσειρά μπορεί να περιέχει αλλαγές γραμμής και κενά ακριβώς όπως τα είδε η μηχανή. Μπορείτε να την επεξεργαστείτε με `trim()`, `replaceAll("\\s+", " ")`, ή οποιοδήποτε άλλο καθαρισμό χρειάζεστε.

## Πώς να εμφανίσετε το αποτέλεσμα (ή να το αποθηκεύσετε);
Το Result είναι ένα στιγμιότυπο του OcrResult που παρέχει το αναγνωρισμένο κείμενο μέσω `getText()`. Η εκτύπωση του αποτελέσματος στην κονσόλα είναι ένας γρήγορος τρόπος για να επαληθεύσετε ότι το OCR πέτυχε, ενώ στην παραγωγή μπορείτε να γράψετε το κείμενο σε αρχείο, βάση δεδομένων ή άλλη υπηρεσία.

`System.out.println(result.getText());` εκτυπώνει το εξαγόμενο κείμενο.

## Πώς φαίνεται ένα πλήρες λειτουργικό παράδειγμα;
Παρακάτω υπάρχει ένα αυτόνομο πρόγραμμα Java που δείχνει κάθε βήμα από την προσθήκη της εξάρτησης μέχρι την εκτύπωση του αποτελέσματος OCR. Η κλάση `ExtractTextExample` περιέχει μια μέθοδο `main` που δημιουργεί τη μηχανή, ορίζει τη γλώσσα, φορτώνει την εικόνα, εκτελεί την αναγνώριση και εμφανίζει το κείμενο. Μπορείτε να αντιγράψετε‑και‑επικολλήσετε αυτόν τον κώδικα σε ένα αρχείο με όνομα `ExtractTextExample.java` και να το εκτελέσετε άμεσα.

```java
import com.aspose.ocr.*;

public class ExtractTextExample {
    public static void main(String[] args) throws Exception {
        // 1️⃣ Create OCR engine
        OcrEngine ocrEngine = new OcrEngine();

        // 2️⃣ Enable the language you need (Khmer in this case)
        ocrEngine.getLanguages().add(OcrLanguage.KHM);

        // 3️⃣ Load the PNG image you want to extract text from
        ocrEngine.setImage(ImageStream.fromFile("YOUR_DIRECTORY/khmer-sign.png"));

        // 4️⃣ Run OCR – this step actually converts PNG to text
        String recognizedText = ocrEngine.recognize().getText();

        // 5️⃣ Show the result
        System.out.println("=== OCR Result ===");
        System.out.println(recognizedText);
    }
}
```

Εκτελέστε το πρόγραμμα με:

```bash
mvn compile exec:java -Dexec.mainClass=ExtractTextExample
```

ή, αν χρησιμοποιείτε Gradle:

```bash
./gradlew run --args='ExtractTextExample'
```

Θα πρέπει να δείτε το εξαγόμενο κείμενο να εκτυπώνεται στην κονσόλα, επιβεβαιώνοντας ότι έχετε επιτυχώς **extract text from image** χρησιμοποιώντας το Aspose OCR.
