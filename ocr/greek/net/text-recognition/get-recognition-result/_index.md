# Πώς να εξάγετε κείμενο από εικόνα χρησιμοποιώντας το Aspose.OCR για .NET

## Εισαγωγή

Αν χρειάζεστε να **extract text from image** αρχεία γρήγορα και αξιόπιστα, το Aspose.OCR για .NET είναι μια αξιόπιστη επιλογή. Σε αυτό το tutorial θα περάσουμε από τη ρύθμιση της βιβλιοθήκης, τη διαμόρφωση των επιλογών αναγνώρισης και την ανάκτηση του πλήρους αποτελέσματος OCR — συμπεριλαμβανομένων των πολυγλωσσικών εξόδων και των δεδομένων διάταξης. Στο τέλος θα ξέρετε πώς να **extract text from image** αρχεία, πώς να **recognize text from image** σε διαφορετικές γλώσσες, και πού να βρείτε την επίσημη τεκμηρίωση Aspose OCR για πιο βαθιά εξερεύνηση.

## Γρήγορες απαντήσεις
- **What does “extract text from image” mean?** Αναφέρεται στην ανάκτηση των αναγνώσιμων χαρακτήρων που εντοπίζει μια μηχανή OCR μέσα σε μια εικόνα.  
- **Which library should I use?** Το Aspose.OCR για .NET προσφέρει ένα απλό API, πολυγλωσσική υποστήριξη, και ένα **aspose ocr trial** που μπορείτε να δοκιμάσετε αμέσως.  
- **Do I need a license?** Διατίθεται δωρεάν δοκιμή· απαιτείται άδεια για χρήση σε παραγωγή.  
- **What .NET versions are supported?** .NET Framework 4.5+ και .NET Core/5/6+.  
- **Can I improve OCR accuracy?** Ναι—επιλέγοντας τη σωστή γλώσσα και ρυθμίζοντας το DPI μπορείτε να **improve ocr accuracy**.

## Τι σημαίνει “extract text from image”;
Το Extract text from image σημαίνει τη μετατροπή της οπτικής αναπαράστασης των χαρακτήρων μέσα σε ένα bitmap σε επεξεργάσιμες, αναζητήσιμες συμβολοσειρές Unicode. Η διαδικασία βασίζεται σε μια μηχανή OCR που αναλύει τα μοτίβα των pixel, εντοπίζει τα γλύφους και τα συναρμολογεί σε λέξεις και προτάσεις. Η μηχανή του Aspose.OCR υποστηρίζει πάνω από 50 γλώσσες και μπορεί να εξάγει απλό κείμενο, JSON ή XML, καθιστώντας εύκολο το ενσωμάτωση των αποτελεσμάτων σε επόμενες ροές εργασίας.

## Γιατί να χρησιμοποιήσετε το Aspose.OCR για αυτήν την εργασία;
Το Aspose.OCR υποστηρίζει **50+ languages** και μπορεί να επεξεργαστεί **multi‑hundred‑page image batches** χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη, παρέχοντας έως και **3 × faster** απόδοση σε σύγκριση με πολλές ανοιχτού κώδικα εναλλακτικές. Το API απαιτεί μόνο λίγες γραμμές κώδικα, και η ενσωματωμένη προεπεξεργασία (δυαδικοποίηση, αφαίρεση θορύβου) βοηθά **improve OCR accuracy** έως και **30 %** σε θορυβώδεις σκαναρίσματα.

## Πώς το Aspose.OCR βελτιώνει την ακρίβεια OCR;
Το Aspose.OCR βελτιώνει την ακρίβεια OCR εφαρμόζοντας αυτόματα βήματα προεπεξεργασίας εικόνας όπως δυαδικοποίηση, διόρθωση κλίσης και μείωση θορύβου πριν από την αναγνώριση. Μπορείτε επίσης να ορίσετε χειροκίνητα το DPI (dots per inch) σε τιμή μεταξύ 150 και 300· υψηλότερο DPI διατηρεί λεπτομερέστερες λεπτομέρειες, ενώ χαμηλότερο DPI επιταχύνει την επεξεργασία. Για έγγραφα με μεικτά σενάρια, η ενεργοποίηση της πολυγλωσσικής λειτουργίας εξασφαλίζει ότι η μηχανή επιλέγει το καλύτερο μοντέλο γλώσσας για κάθε περιοχή, ενισχύοντας περαιτέρω την ακρίβεια.

## Πώς να ορίσετε τη γλώσσα OCR στο Aspose.OCR;
Ορίζετε τη γλώσσα OCR αντιστοιχίζοντας τον επιθυμητό κωδικό ISO‑639‑1 στην ιδιότητα `settings.Language` πριν καλέσετε το `engine.Recognize()`. Για παράδειγμα, χρησιμοποιήστε `"en"` για Αγγλικά, `"fr"` για Γαλλικά, ή μια λίστα διαχωρισμένη με κόμμα όπως `"en,es"` για να ενεργοποιήσετε ταυτόχρονη ανίχνευση αγγλικού και ισπανικού κειμένου. Η επιλογή της σωστής γλώσσας εξαλείφει περιττούς ελέγχους μοντέλων γλώσσας, μειώνοντας τον χρόνο επεξεργασίας κατά **15 %** κατά μέσο όρο.

## Πώς να αποκτήσετε άδεια Aspose OCR;
Αγοράστε μια μόνιμη ή προσωρινή άδεια από το κατάστημα Aspose, στη συνέχεια τοποθετήστε το αρχείο άδειας (`Aspose.OCR.lic`) στο ριζικό φάκελο της εφαρμογής σας. Φορτώστε το κατά την εκτέλεση με `License license = new License(); license.SetLicense("Aspose.OCR.lic");`. Μια προσωρινή άδεια 30 ημερών είναι διαθέσιμη για αξιολόγηση και μπορεί να ζητηθεί από το portal του Aspose χωρίς καμία πληροφορία πιστωτικής κάρτας.

## Βήμα 1: ρυθμίστε τον φάκελο εγγράφων σας

Καθορίστε το φάκελο που περιέχει την εικόνα που θέλετε να επεξεργαστείτε:

```csharp
string dataDir = "Your Document Directory";
```

## Βήμα 2: αρχικοποιήστε το Aspose.OCR

Δημιουργήστε μια παρουσία της μηχανής OCR:

```csharp
AsposeOcr api = new AsposeOcr();
```

## Βήμα 3: καθορίστε τη διαδρομή της εικόνας

Κατευθύνετε στο ακριβές αρχείο εικόνας που θέλετε να αναγνωρίσετε:

```csharp
string fullPath = dataDir + "sample.png";
```

## Βήμα 4: διαμορφώστε τις ρυθμίσεις αναγνώρισης

Ρυθμίστε τις παραμέτρους ώστε να ταιριάζουν στο σενάριό σας—είτε χρειάζεστε προεπιλεγμένη συμπεριφορά είτε προσαρμοσμένες επιλογές όπως η επιλογή γλώσσας για πολυγλωσσική αναγνώριση κειμένου:

```csharp
RecognitionSettings settings = new RecognitionSettings
{
    // Specify your recognition settings here
    // Example: Language = Language.English | Language.Spanish
};
```

## Βήμα 5: εκτελέστε την αναγνώριση εικόνας

Εκτελέστε τη διαδικασία OCR και καταγράψτε το αποτέλεσμα:

```csharp
RecognitionResult result = api.RecognizeImage(fullPath, settings);
```

## Βήμα 6: εκτυπώστε το αποτέλεσμα αναγνώρισης

Εμφανίστε την πλήρη έξοδο αναγνώρισης, η οποία περιλαμβάνει το εξαγόμενο κείμενο, πληροφορίες διάταξης, αναπαράσταση JSON και τυχόν προειδοποιήσεις:

```csharp
PrintRecognitionResult(result);
```
