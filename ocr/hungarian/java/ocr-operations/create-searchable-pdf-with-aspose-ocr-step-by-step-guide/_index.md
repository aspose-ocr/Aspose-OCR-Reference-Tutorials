# Kereshető PDF létrehozása – teljes programozási útmutató

Valaha szükséged volt már **kereshető PDF** fájlok létrehozására beolvasott képekből, de nem tudtad, hol kezdjed? Nem vagy egyedül. Sok dokumentum‑intenzív munkafolyamatban egy egyszerű, csak képet tartalmazó PDF halálpontra fut a keresés és az indexelés szempontjából.

A jó hír, hogy az Aspose OCR segítségével **konvertálhatod a beolvasott képek PDF‑jét** teljesen kereshető dokumentummá néhány Java sorral. Ez az útmutató végigvezet minden lépésen – az OCR motor inicializálásán, a magas tömörítésű PDF beállításainak konfigurálásán, egy rejtett szövegréteg beágyazásán, sőt a megfelelő OCR nyelv kiválasztásán.

A útmutató végére egy futtatható programod lesz, amely kereshető PDF‑et hoz létre, egy olyan fájlt, amelyet gond nélkül beilleszthetsz bármely keresőmotorba vagy dokumentumkezelő rendszerbe.

---

## Gyors válaszok
- **Mi jelent a „kereshető PDF”?** Egy vizuális képréteget kombinál egy láthatatlan szövegréteggel, amelyet az OCR generál.  
- **Melyik könyvtár kezeli a konverziót?** Aspose OCR for Java.  
- **Hogyan tarthatom alacsonyan a fájlméretet?** Használd a `setCompressionLevel(9)`‑t a magas tömörítésű PDF‑hez.  
- **Feldolgozhatok nem angol nyelvű dokumentumokat?** Igen – állítsd be a megfelelő `RecognitionLanguage` enum értéket.  
- **Szükségem van licencre a termeléshez?** Egy kereskedelmi Aspose OCR licenc szükséges a nem próbaverzióhoz.

---

## Mi az a kereshető PDF?
A kereshető PDF egy olyan PDF, amely tartalmazza az eredeti beolvasott képet és egy láthatatlan, gép‑olvasható szövegréteget, amelyet az OCR hoz létre. Ez a kettős réteg lehetővé teszi a felhasználók számára a szöveg kijelölését, másolását és indexelését, miközben továbbra is látható az eredeti oldal megjelenése.

---

## Miért használjuk az Aspose OCR‑t Java‑hoz?
Az Aspose OCR **több mint 30 nyelvet** támogat, és egy szabványos CPU‑n **akár 120 oldalt percenként** képes feldolgozni, így a leggyorsabb Java OCR motorok egyike. Beépített PDF írója **kilenc tömörítési szintet** kínál, lehetővé téve, hogy a nagy beolvasott dokumentumokat akár **80 %**‑kal is összenyomd az OCR pontosságának romlása nélkül.

---

## Előfeltételek
- Java 17 (vagy újabb) telepítve és konfigurálva.  
- Aspose OCR for Java JAR hozzáadva a projekted osztályútvonalához.  
- Egy beolvasott kép fájl (PNG, JPEG vagy TIFF), amelyet kereshető PDF‑vé szeretnél alakítani.  

---

## Hogyan hoz létre az Aspose OCR kereshető PDF‑et?
Töltsd be a forrásképet, engedélyezd a searchable‑PDF módot, állítsd be a kívánt tömörítési szintet, válaszd ki az OCR nyelvet, és mondd meg a motornak, hogy mentse az eredményt PDF‑ként. Az API elvégzi a nehéz munkát: futtatja az OCR‑t, létrehozza a rejtett szövegréteget, és egy lépésben írja ki a végleges PDF‑et.

---

## Beolvasott kép PDF konvertálása az Aspose OCR‑rel

**Az Aspose OCR motor** a fő komponens, amely képeket olvas, optikai karakterfelismerést végez, és különböző formátumokban állít elő kimenetet.  

A következő lépések illusztrálják a konverziós folyamatot:

- Hívd meg a `setCreateSearchablePdf(true)`‑t, hogy a motor beágyazza a rejtett szövegréteget.  
- Használd a `setCompressionLevel(9)`‑t a **magas tömörítésű PDF** kimenet eléréséhez, amely drámaian csökkenti a fájlméretet.  
- Add meg a `RecognitionLanguage.ENGLISH`‑t (vagy más nyelvet), hogy **beállítsd az OCR nyelvet** az optimális pontosság érdekében.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Step 1: Initialize the OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Step 2: Configure PDF save options to embed a searchable text layer
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // enable searchable PDF
        pdfSaveOptions.setCompressionLevel(9);        // optional: high compression

        // Step 3: Perform OCR on the scanned image and save the result as a searchable PDF
        ocrEngine.recognizeImageAndSave(
                "YOUR_DIRECTORY/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,                // set OCR language
                "YOUR_DIRECTORY/output.pdf",                // output PDF file
                pdfSaveOptions);                            // options defined above

        // Step 4: Indicate that the PDF has been created
        System.out.println("Searchable PDF created.");
    }
}
```

**Miért működik ez:**  
- `setCreateSearchablePdf(true)` azt mondja az Aspose‑nak, hogy generálja a rejtett szövegréteget, ezzel teljesítve a **embed text layer PDF** követelményt.  
- `setCompressionLevel(9)` a fájlt a **high compression PDF** tartományba helyezi, csökkentve a végső méretet az OCR pontosság feláldozása nélkül.  
- A `RecognitionLanguage.ENGLISH` argumentum megmutatja, hogyan **állítsd be az OCR nyelvet**; a forrásanyagtól függően kicserélheted francia, német stb. nyelvre.

---

## Magas tömörítésű PDF beállítások

**CompressionLevel** szabályozza, hogy a PDF író milyen erősen csökkenti a beágyazott képek és adatfolyamok méretét. Az értékek 0‑tól (nincs tömörítés) 9‑ig (maximális tömörítés) terjednek.  

Amikor a szintet 9‑re állítod, az Aspose OCR **veszteségmentes PNG tömörítést** alkalmaz a szövegre gazdag oldalakra, és **magas minőségű JPEG**‑et a fotó tartalomra, gyakran **70‑80 %**‑kal csökkentve a fájlméretet a tömörítetlen kimenethez képest.

```java
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.setCompressionLevel(9); // 9 = strongest compression
```

Néhány tipp:

- **Használj veszteségmentes képformátumokat** (PNG) a szövegre gazdag beolvasásokhoz; a JPEG jobb a fényképekhez.  
- **Engedélyezd a betűkészlet alhalmazolást**, ha egyedi betűket ágyazol be – az Aspose ezt automatikusan megteszi, amikor kereshető PDF‑et hozol létre.  
- **Teszteld a kimeneti méretet** minden változtatás után; néha a 8‑as szintű tömörítés 10 % méretcsökkenést eredményez elhanyagolható minőségveszteséggel a 9‑eshez képest.

---

## Szövegréteg beágyazása PDF‑be a kereshetőséghez

Ha kihagyod a `setCreateSearchablePdf(true)` hívást, a kapott fájl rendben fog kinézni, de nem lesz lehetőség a tartalom keresésére. A rejtett szövegréteget úgy hozza létre, hogy minden felismert karaktert a megfelelő oldalhelyére térképezi.

```java
pdfSaveOptions.setCreateSearchablePdf(true);
```

**Mire figyelj:**  
- **Vegyes nyelvű dokumentumok** – előfordulhat, hogy kétszer kell futtatni az OCR‑t, nyelvenként egyszer, majd össze kell fűzni a szövegrétegeket.  
- **Komplex elrendezések** (táblázatok, többoszlopos) – az Aspose elég jó munkát végez, de ellenőrizd a kimenetet egy olyan PDF‑nézővel, amely megjeleníti a rejtett szöveget (pl. az Adobe Acrobat „Edit PDF” módja).

---

## OCR nyelv beállítása a pontos felismeréshez

**RecognitionLanguage** egy felsorolás, amely megmondja az OCR motornak, milyen karakterkészletet várjon, drámaian javítva a pontosságot a nem latin írásrendszerek esetén.  

```java
ocrEngine.recognizeImageAndSave(
        "input.png",
        RecognitionLanguage.ENGLISH, // change to RecognitionLanguage.FRENCH, etc.
        "output.pdf",
        pdfSaveOptions);
```

**Mikor változtasd meg a nyelvet:**  
- A dokumentumok **nem latin írásrendszereket** tartalmaznak (cirill, arab) – válts a megfelelő `RecognitionLanguage`‑ra.  
- Vegyes nyelvű oldalak – meghívhatod a `recognizeImageAndSave`‑t kétszer, minden alkalommal más nyelvvel, majd összevonhatod a PDF‑eket.

---

## A teljes példa futtatása

Az alábbiakban a teljes, futtatható program látható. Cseréld ki a helyőrző útvonalakat a valós fájlhelyekre, győződj meg róla, hogy az Aspose OCR JAR a classpath‑on van, és futtasd.

```java
import com.aspose.ocr.AsposeOCR;
import com.aspose.ocr.PdfSaveOptions;
import com.aspose.ocr.RecognitionLanguage;

public class PdfSearchableExample {
    public static void main(String[] args) throws Exception {

        // Initialize OCR engine
        AsposeOCR ocrEngine = new AsposeOCR();

        // Configure PDF save options
        PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
        pdfSaveOptions.setCreateSearchablePdf(true);   // embed text layer PDF
        pdfSaveOptions.setCompressionLevel(9);        // high compression PDF

        // Perform OCR and save searchable PDF
        ocrEngine.recognizeImageAndSave(
                "C:/scans/input.png",                 // path to scanned image
                RecognitionLanguage.ENGLISH,          // set OCR language
                "C:/output/searchable.pdf",           // output PDF
                pdfSaveOptions);                      // options defined above

        System.out.println("Searchable PDF created.");
    }
}
```

**Várható kimenet:** Amikor futtatod a programot, a konzol kiírja:

```
Searchable PDF created.
```

Nyisd meg a `searchable.pdf`‑et bármely PDF‑nézőben, próbáld ki a szöveg kijelölését, és láthatod a láthatatlan réteg működését. Sikeresen **kereshető PDF‑et hoztál létre** egy beolvasott képből.

## Gyakori problémák és megoldások

- **Memory‑out‑of‑bounds nagy fájloknál** – engedélyezd a streaming módot a `OcrEngine.setUseStream(true)` hívásával.  
- **Helytelen nyelvfelismerés** – állítsd be kifejezetten a `RecognitionLanguage`‑t, ahelyett, hogy az automatikus felismerésre hagyatkoznál.  
- **Homályos beolvasások** – előfeldolgozd a képeket az Aspose Imaging‑gel, hogy növeld a kontrasztot az OCR előtt.

## Gyakran ismételt kérdések

**Q: Batch‑processzhetek egy teljes mappát képekből?**  
A: Igen. Iterálj a fájlokon, hívd meg ugyanazt az OCR konfigurációt mindegyikre, és fűzd össze a kapott PDF‑eket a `PdfDocument.merge()`‑val.

**Q: Támogatja az Aspose OCR a PDF‑bemenetet közvetlenül?**  
A: Igen. Használd a `OcrEngine.recognizePdfAndSave(inputPdfPath, outputPdfPath)`‑t és állítsd be a `setCreateSearchablePdf(true)`‑t.

**Q: Hogyan kezelem a jelszóval védett PDF‑eket?**  
A: Add meg a jelszót a `OcrEngine.setPassword("yourPassword")`‑nek az OCR metódus meghívása előtt.

**Q: Mi a maximális fájlméret, amelyet az Aspose OCR kezelni tud?**  
A: A motor **2 GB**‑ig képes PDF‑eket feldolgozni streaming engedélyezése esetén, csak a rendelkezésre álló RAM korlátozza.

**Q: Szükséges-e kereskedelmi licenc a termelési használathoz?**  
A: Igen. A próbaverzió értékelésre alkalmas, de egy teljes licenc eltávolítja a vízjeleket és feloldja az összes funkciót.

Mindezt áttekintettük, ami szükséges a **kereshető PDF** fájlok létrehozásához az Aspose OCR használatával:

- Az OCR motor inicializálása.  
- **Beolvasott kép PDF konvertálása** PNG/JPEG betáplálásával a `recognizeImageAndSave`‑be.
